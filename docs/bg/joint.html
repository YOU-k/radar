方向间交叉点

方法同时出现在 ≥2 个方向

  • JEPA / 隐空间预测式自监督：世界模型与自监督表征学习（I-JEPA、V-JEPA 2、DINO-WM、JEPA-DNA）↔ 单细胞与空间组学基础模型（RegFormer 用 Mamba 状态空间替代 Transformer）↔ 虚拟细胞（Chreode 一步式细胞世界模型）。世界模型方向：文献标题「JEPA-DNA：JEPA与生成目标结合的持续训练框架」「DINO-WM，基于DINOv2特征的隐空间世界模型」；虚拟细胞方向：文献标题「Chreode：一步式细胞世界模型预测状态转移」。
  • 扰动响应预测与评测：虚拟细胞 ↔ 单细胞与空间组学基础模型 ↔ 类器官与模式生物虚拟响应建模。三方向共享同一批数据（Replogle 2022 Perturb-seq、Norman 2019、Adamson、Tahoe-100M）与同一批判结论——虚拟细胞方向：文献标题「Deep-learning-based gene perturbation effect prediction does not yet outperform simple linear baselines」；单细胞方向：文献标题「Benchmarking foundation cell models for post-perturbation RNA-seq prediction」；类器官方向：文献标题「一项研究将 TabICL 和 TabPFN 与 PRESAGE、scGPT、scLAMBDA、STACK、Prophet 等专用模型对比，发现表格基础模型在伪 bulk 扰动预测上持续优于专用基线」。
  • 生成式序列建模 / 疾病轨迹：人群健康与多组学 AI（Foresight、ALADYNOULLI、Delphi-2M）↔ 心血管队列多组学与临床 AI（房颤/心衰轨迹、ECG 序列模型）。人群方向：文献标题「ALADYNOULLI 以概率混合而非混合概率的形式联合建模纵向 EHR 诊断、年龄与多基因风险」；心血管方向：文献标题「12导联ECG卷积神经网络+Cox模型」。
  • 多组学衰老时钟 / 生物年龄：多模态衰老时钟 ↔ 人群健康与多组学 AI（2.4 组学衰老时钟与纵向多组学动态）↔ 心血管队列多组学（蛋白组签名与代谢组）。共享 UKB Olink/PPP 与 MetaboAgeMort、PAC 类方法。
  • RLVR / 可验证奖励：LLM 科研智能体与 RLVR ↔ 单细胞与空间组学基础模型（CellDuality 自监督 RLVR）↔ 虚拟细胞（CellScientist 闭环精化）。智能体方向：文献标题「CellDuality：自监督RLVR，互补任务双向推理自验证」。
  • 跨物种 / 跨队列迁移：类器官与模式生物虚拟响应建模（神经最优传输、BrainBeacon）↔ 心血管队列（多 ancestry PRS、跨人群校准）↔ 人群健康（Pan-UK Biobank 跨祖源荟萃）。类器官方向：文献标题「Learning single-cell perturbation responses using neural optimal transport」。
  • 基础模型 + 临床读出的联合建模：心血管队列（ECG-FM、ECG+心脏 MRI 对比学习）↔ 单细胞与空间组学基础模型（OmiCLIP 双编码器、病理-单细胞配对）↔ 人群健康（EHR 基础模型）。

哪些方向的进展会直接改变另一方向的做法

  • 虚拟细胞/单细胞基础模型的评测批判（「未跑赢简单基线」+ 指标校准研究）会直接改写类器官虚拟响应的建模路线：如果表达谱相似度类指标被证明校准不良，类器官扰动预测必须转向空间/形态/功能读出，而不是再训更大的表达谱生成模型。
  • 人群健康方向的生成式轨迹模型（Foresight、ALADYNOULLI）会直接改变心血管队列的建模范式：从「单终点风险评分」转向「多病共存 + 纵向合成轨迹」，ChinaHEART 的结局建模可以不再只对标 China-PAR。
  • 世界模型方向的隐空间预测范式（DINO-WM 零样本规划、Flow-JEPA 流匹配生成未来潜状态）会改变类器官时序建模的做法：从「预测扰动后表达值」转向「在潜空间预测状态转移并做扰动组合规划」。
  • 多模态衰老时钟的跨队列泛化结论（MRIBAG 泛化差、CTBA 以白人为主、ProtBAG 受病理构成影响）会直接约束ChinaHEART 迁移的设计：跨人群迁移必须先做校准层，而不是直接套用 UKB 训练权重。
  • LLM 科研智能体的过程奖励与可验证奖励进展会改变方法储备的落地方式：把生信流程拆成可判分步骤，而不是期待端到端 agent 直接产出结论。

按应用线的联合行动

类器官多模态健康衰老模型（公共数据先做 demo）

项目 1：类器官扰动 + 空间读出的跨模态预测基准（公共数据 demo 版）

  • 目标：用公共类器官/扰动数据构建「扰动 → 空间/单细胞响应」的留出预测任务与统一评测，产出可复用 benchmark + 基线，作为合作项目新数据进来前的评测底座。
  • 用到的方向与具体方法/数据：类器官与模式生物虚拟响应建模（Perturb-FISH 的 CRISPR+空间同步读出范式、Stereo-seq 多类器官空间转录组基准、CINEMA-OT 因果扰动效应估计）；单细胞与空间组学基础模型（PerturBench、PertEval-scFM 评测框架、scGPT/Geneformer 冻结表征 + 轻量探针）；数据用 Tahoe-100M、Replogle 2022 Perturb-seq、Norman 2019、Adamson、CELLxGENE。
  • 为什么现在：类器官方向的评测/可复现性在雷达样本中仅 2 篇且均为 2026 年新出（单细胞/空间基础模型统一基准、VCBench），基准是稀缺品；同时虚拟细胞方向已出现「未跑赢简单基线」的硬证据，先做评测即占位。
  • 预期产出：一个可复用的类器官扰动响应 benchmark + 基线模型对比报告；直接对接合作项目的公共数据 demo 阶段。
  • 主要风险：公共类器官扰动数据的 readout 异质性大（不同癌种、不同平台），benchmark 可能被批评为「拼盘」；需明确限定任务边界。

项目 2：衰老背景下的类器官扰动响应表征（冻结表征 + 探针）

  • 目标：检验衰老相关扰动是否落在可预测的低维流形上，产出「扰动响应在衰老背景下的泛化衰减曲线」。
  • 用到的方向与具体方法/数据：多模态衰老时钟与生物年龄（单细胞免疫衰老时钟 sc-ImmuAging 的细胞类型分辨读出、空间免疫球蛋白相关衰老）；虚拟细胞（遗传互作流形、State 的 Cell-Eval 评估框架）；世界模型与自监督表征学习（JEPA 式隐空间预测、JEPA-DNA 接地到基因组基础模型）；数据用 CELLxGENE、Tabula Sapiens、scPerturb。
  • 为什么现在：单细胞/空间衰老图谱刚积累到可训练规模但尚无统一坐标；虚拟细胞方向明确把「跨情境泛化」列为未解问题，而衰老细胞正是天然的分布外情境。
  • 预期产出：一篇「衰老背景下扰动响应泛化衰减」的实证论文 + 可迁移到合作类器官数据的表征模型。
  • 主要风险：公共数据中「衰老 + 扰动」双标注的样本稀少，可能只能做细胞系 + 衰老诱导的近似；结论外推到原代类器官需谨慎。

人群队列 + 多组学 → 临床（UKB 等公共队列方法迁移到 ChinaHEART 心血管队列）

项目 1：中国/东亚队列上的多组学风险增益 + 跨人群校准

  • 目标：在 ChinaHEART 类队列的血浆组学/代谢组上，复现 UKB 蛋白组关联与蛋白组签名的预测增益，重点报告相对 China-PAR 的增量与校准斜率。
  • 用到的方向与具体方法/数据：心血管队列多组学与临床 AI（UKB-PPP 的 pQTL 图谱、蛋白组签名 5 蛋白媲美临床模型、多 ancestry PRS、重校准方法）；人群健康与多组学 AI（Pan-UK Biobank 跨祖源荟萃、48 个冠心病 PRS 在 All of Us/Penn/UCLA 的校准与区分度比较）；数据用 UK Biobank Pharma Proteomics Project、UK Biobank Olink Proteomics、China Kadoorie Biobank、ChinaHEART、ARIC、MESA、China-PAR。
  • 为什么现在：多 ancestry PRS 已把「跨人群」变成显式议题，但东亚组学层面的验证几乎空白，心血管方向的中国人群队列证据在雷达样本中仅 2 篇且无强验证——低成本高辨识度。
  • 预期产出：ChinaHEART 蛋白组/代谢组风险模型 + 相对 China-PAR 的增量与校准报告；可发表为心血管队列方法学论文。
  • 主要风险：ChinaHEART 组学数据尚未到位时只能先用 CKB 或公共东亚队列做方法验证；Olink 与 SomaScan 平台间迁移性未被系统检验，跨平台结论需标注不确定性。

项目 2：生成式疾病轨迹 + 组学衰老时钟的联合建模（公共队列 demo，ChinaHEART 落地）

  • 目标：以生成式轨迹模型为骨架，把纵向组学衰老指数作为时间依赖协变量或生成条件，产出「组学衰老加速 → 疾病轨迹偏移」的可解释生成模型，并预留 ChinaHEART 结局随访的接入接口。
  • 用到的方向与具体方法/数据：人群健康与多组学 AI（Foresight 的 243M 参数 Transformer 解码器、ALADYNOULLI 贝叶斯生成框架、Delphi-2M、FPCA+Cox 弹性网构建纵向蛋白衰老指数）；多模态衰老时钟与生物年龄（蛋白组时钟 PAC、器官年龄模型、GrimAge v2/DunedinPACE 的疾病关联谱）；心血管队列（China-PAR、SCORE2 作为对照基线）；数据用 UK Biobank、UKB-PPP、ChinaHEART、China Kadoorie Biobank。
  • 为什么现在：生成式轨迹刚爆发但尚未与纵向组学衰老时钟结合，窗口明确；心血管方向的多组学+AI 联合建模红利期判断还有 2–3 年。
  • 预期产出：一个「组学衰老 → 轨迹偏移」的生成模型 + 在 ChinaHEART 上的迁移方案；可发表为方法学论文，同时是合作项目的算法交付。
  • 主要风险：ChinaHEART 纵向组学随访深度未知，若只有基线组学则退化为横断面风险预测；生成式轨迹模型的外部验证与记录偏倚是共同短板，需预设校准与敏感性分析。

类器官 / 模式生物的虚拟扰动响应（从细胞系虚拟细胞走向组织与个体层面）

项目 1：跨物种扰动响应的「响应空间对齐」方法

  • 目标：以神经最优传输为骨架，输入小鼠/斑马鱼扰动单细胞数据、输出人源响应预测，用跨物种细胞图谱做同源锚点，产出跨物种扰动响应预测方法 + 在类器官数据上的验证。
  • 用到的方向与具体方法/数据：类器官与模式生物虚拟响应建模（神经最优传输做扰动响应预测、BrainBeacon 跨物种脑空间转录组基础模型、Microwell-seq 跨物种细胞图谱、Nicheformer 的独立基准复现问题）；世界模型与自监督表征学习（JEPA 式隐空间预测、跨模态联合嵌入）；单细胞与空间组学基础模型（SATURN 耦合基因表达与蛋白语言模型嵌入）；数据用 SpeciesCorpus、Tabula Sapiens、CELLxGENE。
  • 为什么现在：现有基础模型解决的是通用表征，没有解决「扰动响应」的跨物种外推；类器官方向判断跨物种迁移 + 类器官扰动建模的结合点窗口仅 1–2 年。
  • 预期产出：跨物种扰动响应预测方法 + 类器官验证；可发表为方法学论文。
  • 主要风险：跨物种迁移缺乏 ground truth，小鼠/斑马鱼到人的响应映射没有公认验证集，方法好坏难以判定——这是该方向最大不确定性，需先建立小规模人工验证集。

项目 2：类器官扰动 + 空间读出的主动实验选择（闭环验证）

  • 目标：用闭环智能体做主动实验选择（选哪些扰动最能把模型打崩），产出「主动学习 vs 随机采样」的增益证据，把世界模型当假设检验工具而非卖点。
  • 用到的方向与具体方法/数据：虚拟细胞（Chreode 一步式细胞世界模型、CellScientist 双空间分层编排的闭环精化、SCALE 条件传输模型）；LLM 科研智能体与 RLVR（过程奖励模型、AgentPRM 的步骤级过程奖励、BAVAR 预算自适应验证）；类器官方向（Perturb-FISH、Stereo-seq 类器官基准）；数据用 Tahoe-100M、Replogle 2022、合作类器官扰动数据。
  • 为什么现在：闭环工作刚出现、无人做严格对照；类器官方向评测基准几乎空白，主动学习增益证据可直接作为方法学贡献。
  • 预期产出：主动学习 vs 随机采样的对照实验 + 闭环扰动选择流程；可作为合作项目的实验设计工具交付。
  • 主要风险：闭环智能体在生物医学的可验证奖励天然稀缺（湿实验慢、噪声大），若只用公共数据回测，增益可能不迁移到真实类器官实验。

方法储备：世界模型 / 自监督表征、LLM 科研智能体——服务于上面三条，不单独立项

项目 1：把 JEPA 式隐空间预测接到类器官多组学时序上

  • 目标：用类器官发育/衰老时间序列的多组学（转录组+表观组+影像），把不同模态当作不同 view，做联合嵌入预测而非重构，产出可迁移到公共单细胞数据的衰老轨迹表征。
  • 用到的方向与具体方法/数据：世界模型与自监督表征学习（I-JEPA、V-JEPA 2、LeJEPA 的 SIGReg 正则、SiamJEPA 孪生编码器、Flow-JEPA 条件流匹配、JEPA-DNA）；多模态衰老时钟与生物年龄（多模态缺失模态对齐、跨队列校正）；单细胞与空间组学基础模型（RegFormer 的 Mamba 状态空间建模）；数据用 CELLxGENE、CELLxGENE Census、Tabula Sapiens、合作类器官时序数据。
  • 为什么现在：JEPA-DNA 刚证明 JEPA 可接地到基因组基础模型，而单细胞自监督的有效使用尚缺系统结论，两者之间的空白正好是类器官时序；世界模型方向判断向科学数据迁移刚起步、窗口 12–24 个月。
  • 预期产出：一个可迁移的类器官多组学衰老轨迹表征模型 + 在公共单细胞数据上的迁移验证；服务于应用线 1 和 3。
  • 主要风险：状态空间/线性注意力在生物多模态上的适配证据严重不足（雷达样本中仅 1 篇）；科学数据上的自监督缺乏统一基准，容易做出「看起来好但不可复现」的结果。

项目 2：把「单细胞注释/衰老轨迹判定」做成可验证奖励任务，复用 RLVR 配方

  • 目标：用公共单细胞图谱构造「给定 marker 与表达矩阵，判定细胞类型/衰老状态」的可自动判分任务，奖励用与 held-out 标注的一致性，方法上照搬 GRPO 的组相对优势估计，产出带可验证奖励的单细胞推理数据集 + 微调模型。
  • 用到的方向与具体方法/数据：LLM 科研智能体与 RLVR（GRPO 配方、Kimi k1.5 的简洁 RL 框架、CellDuality 自监督 RLVR、过程奖励模型 AgentPRM）；单细胞与空间组学基础模型（CellVoyager 自主探索 scRNA-seq 的 AI 智能体、scGPT/Geneformer 作为基线）；数据用 CELLxGENE、Tabula Sapiens、Human Cell Atlas 类图谱。
  • 为什么现在：RLVR 配方已在可验证任务上稳定有效，而单细胞推理刚被证明可被 RL 训练，赛道刚开、竞争者少；同时该方向对 RLVR 是否真扩展推理上界存在质疑，需在生物任务上给出独立证据。
  • 预期产出：带可验证奖励的单细胞推理数据集 + 微调模型；服务于应用线 1 的细胞类型/衰老状态判定环节。
  • 主要风险：可验证奖励在生物医学里天然稀缺，细胞类型标注本身有争议（造血与悬浮肾类器官存在转录扩散、单细胞注释困难），奖励信号可能引入标注噪声；RLVR 的推理增益在大 k pass@k 下被质疑，需预设基座模型对照。

不要做的事

  • 不要再训一个更大的单细胞/扰动基础模型去刷表达谱预测精度。依据：虚拟细胞方向已有「Deep-learning-based gene perturbation effect prediction does not yet outperform simple linear baselines」的硬证据，单细胞方向也报告差分空间的 Train Mean 基线优于 scGPT 与 scFoundation，且 2220 万细胞预训练 400 个模型未观察到明确数据缩放定律。该方向判断评测口径已从「刷榜」转向「是否真有用」，纯规模扩张的边际收益正在快速下降。
  • 不要把 Lp(a) 或 IL-6 轴当作「遗传学→试验已兑现」的支持性例子写进任何立项论证。依据：试验状态表显示 Lp(a)HORIZON（pelacarsen）已读出未达主要终点，ZEUS（ziltivekimab）已读出失败（MACE HR 0.99），IL-6 轴不能再作为支持性例子；HERMES/ARTEMIS 与 OCEAN(a)-Outcomes、ACCLAIM-Lp(a) 均尚未读出，表里没有的 2025 年后试验一律写「待核实」。
  • 不要在没有跨人群校准层的情况下直接把 UKB 训练的组学风险模型套到 ChinaHEART。依据：心血管方向报告 QRISK3 在 UK Biobank 中系统性高估 CVD 风险、老年参与者高估达 20%；CKB 吴忠子队列重校准后高风险组预测 48.4% 而实际 10 年风险 25.7%；新西兰与中国 T2D 队列对比显示标准重校准未能改善中国队列校准。跨人群迁移必须先做校准与敏感性分析，否则结论不可用。
