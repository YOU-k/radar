方向间交叉点

方法层交叉（同一方法被 ≥2 个方向当作核心工具）

  • JEPA / 隐空间预测：世界模型方向（「世界模型与自监督表征学习：JEPA-DNA」「世界模型与自监督表征学习：DINO-WM」）与单细胞方向（「单细胞与空间组学基础模型与虚拟细胞：CellWorld」，把预测目标从重建基因身份/表达改为潜在细胞表征）直接同源；虚拟细胞方向的「虚拟细胞与扰动响应预测：一步式细胞世界模型（Chreode）」是同一思路在扰动数据上的落地。这条线是唯一同时贯穿「方法储备」与三条应用线的方法骨架。
  • 分层分布外（OOD）评测与「不跑赢基线」批判：虚拟细胞方向（「虚拟细胞与扰动响应预测：Deep-learning-based gene perturbation effect prediction does not yet outperform simple linear baselines」「虚拟细胞与扰动响应预测：EL-PERTURB」）、单细胞方向（「单细胞与空间组学基础模型与虚拟细胞：PerturBench」「单细胞与空间组学基础模型与虚拟细胞：PertEval-scFM」）、类器官方向（「类器官与模式生物虚拟响应建模：EL-PERTURB」同一篇被两方向共用）三处重复出现。这是当前话语权最高、且三个方向共享同一套失败模式的位置。
  • 生成式轨迹 / 序列生成：人群方向（「人群健康与多组学 AI：ALADYNOULLI」「人群健康与多组学 AI：Foresight」「人群健康与多组学 AI：NOAH」）与虚拟细胞方向的流匹配/扩散/条件传输（「虚拟细胞与扰动响应预测：SCALE」「虚拟细胞与扰动响应预测：OCOO-T」「虚拟细胞与扰动响应预测：X-Cell」）在「条件生成 + 反事实推演」上是同一数学问题，只是状态空间不同（EHR 事件序列 vs 细胞表达谱）。
  • 可验证奖励 RL：科研智能体方向（「LLM 科研智能体与可验证奖励强化学习：DeepSeekMath/GRPO」「LLM 科研智能体与可验证奖励强化学习：Kimi k1.5」）与单细胞方向的 RL 训练单细胞推理解谜（该方向 tldr 提及的 RL 训练单细胞推理）已开始交汇；但「LLM 科研智能体与可验证奖励强化学习：Does Reinforcement Learning Really Incentivize Reasoning Capacity」对大 k pass@k 的质疑，直接约束这条线在生物医学的可宣称边界。
  • 知识注入 vs 规模叙事：虚拟细胞方向「虚拟细胞与扰动响应预测：scKITE」（179,067 预训练样本、不足先前强模型 0.5% 即超越 Geneformer/scGPT）与单细胞方向「单细胞与空间组学基础模型与虚拟细胞：GenePT」（简单基因文本嵌入即有竞争力）、「单细胞与空间组学基础模型与虚拟细胞：性能在数据规模远小于当前训练语料时趋于平台」构成同一组反证。

数据层交叉（同一资源被 ≥2 个方向使用）

  • Tahoe-100M / Tahoe-X1：虚拟细胞（「虚拟细胞与扰动响应预测：OCOO-T 在 Tahoe100M 上评测」）、单细胞（「单细胞与空间组学基础模型与虚拟细胞：Tahoe-x1 扩展到 30 亿参数」「跨模态继续预训练 70M 参数在 48,843 蛋白质组样本上匹配 1B/3B RNA-only 模型」）、类器官（资源登记中标为「虚拟扰动预训练与类器官 demo 核心数据」）三线共用。
  • Perturb-seq 三件套（Adamson / Norman / Replogle）：虚拟细胞与单细胞两方向共同的基准底座；类器官方向的 OSCAR、Perturb-FISH 是同一读出范式在类器官/空间上的延伸。
  • UK Biobank 及其蛋白组子集（UKB-PPP / Olink）：人群方向（pQTL、蛋白组时钟、暴露组）与衰老时钟方向（「多模态衰老时钟与生物年龄：2,897 个血浆蛋白、45,441 人的蛋白组时钟」）共用；同时是 ChinaHEART 迁移的唯一对标源。
  • CELLxGENE / Tabula Sapiens / 小鼠衰老单核图谱：衰老时钟方向（单细胞免疫衰老时钟、跨器官小鼠衰老）与单细胞方向（表征预训练）共用。
  • Cell Painting / JUMP / BBBC021：单细胞方向（形态与图像表型基础模型）与类器官方向（图像 profiling 预测凋亡、明场延时图像）共用同一评测语汇。

问题层交叉（一个方向的进展会直接改写另一个方向的做法）

  1. 虚拟细胞/单细胞的评测批判 → 直接改写类器官扰动建模的选题：若「不跑赢简单基线」在更多数据上被确认，类器官方向「再提一个扰动预测网络」的审稿门槛会快速抬高，必须转向分层 OOD 评测 + 失败归因。
  2. 人群方向的跨队列复现缺口 → 决定衰老时钟方向的落地价值：衰老时钟方向已有多篇「时钟→疾病终点」应用（该方向第 4 节判为成熟），但人群方向明确指出跨队列复现与评测证据几乎空白；谁先做出 UKB→All of Us/FinnGen 的复现基准，谁就同时给两个方向定标准。
  3. 世界模型的隐空间规划 → 改写虚拟细胞与类器官的「预测」定义：从「预测表达值」转向「在隐空间预测扰动后状态并做零样本扰动组合规划」，会使现有以 MSE/Pearson Δ 为核心的评测体系失效。
  4. 科研智能体的过程奖励 → 可能成为组学分析流程的自动化底座，但受限于「可验证奖励在生物医学天然稀缺」；短期内只对有 held-out 标注的任务（细胞类型注释、衰老状态判定）可用。
  5. 类器官方向的心脏/血管类器官证据空白 ↔ 人群方向的心血管临床终点：这是唯一能把「扰动实验」与「人群队列结局」接起来的接口，但两侧目前都没有对接工作，属于空白而非共识。

按应用线的联合行动

类器官多模态健康衰老模型（合作项目，公共数据先做 demo）

项目 1：JEPA 式隐空间预测做类器官衰老/分化时序表征（公共数据 demo） - 目标：把类器官发育/衰老时间序列的多组学（转录组 + 表观组 + 影像）当作不同 view，做联合嵌入预测而非重构，产出一个可迁移到公共单细胞数据的衰老轨迹表征。 - 用到的方向与具体方法/数据：世界模型方向「世界模型与自监督表征学习：JEPA-DNA」（JEPA 接地到基因组基础模型）、「世界模型与自监督表征学习：CellWorld 式潜在表征目标」；单细胞方向「单细胞与空间组学基础模型与虚拟细胞：逐层分析发现最优层在 60% 深度、轨迹推断比最终层高 31%」（直接决定你取哪一层嵌入）；数据用 CELLxGENE、Tabula Sapiens、小鼠跨器官衰老单核图谱做预训练/迁移，合作方类器官数据做下游。 - 为什么现在：JEPA 接地到基因组刚被证明，而单细胞自监督「有效使用」尚缺系统结论，两者之间的空白正是类器官时序；且「再训更大单细胞基础模型」的窗口已关闭，隐空间预测是少数还开着的口。 - 预期产出：一个类器官衰老轨迹表征模型 + 一篇「隐空间预测 vs 重建目标在类器官多组学时序上的对照」方法论文；对合作方交付一个可复用的表征与取层规范。 - 主要风险：类器官多模态配对样本量小，JEPA 类方法在小数据上易退化；表格领域的实证已显示 JEPA 臂在 147 个真实数据集上落后仅值目标臂（「世界模型与自监督表征学习」tldr），需预设「JEPA 不胜出」的负结果出口。

项目 2：类器官扰动的分层 OOD 评测框架（把评测做成方法学标签） - 目标：以「不跑赢基线」的基线协议为骨架，在类器官多组学扰动数据上按扰动类型、细胞类型未见程度、供体差异分层重做评测，并加入「超越表达」的指标。 - 用到的方向与具体方法/数据：虚拟细胞方向「虚拟细胞与扰动响应预测：EL-PERTURB 分层 OOD 划分」「虚拟细胞与扰动响应预测：Systema 超越表达的评测」；单细胞方向「单细胞与空间组学基础模型与虚拟细胞：PerturBench」「单细胞与空间组学基础模型与虚拟细胞：指标校准不良、良好校准下深度模型可优于无信息基线」（这条争议必须写进设计，否则结论会被审稿人用另一半证据打掉）；数据用 Adamson/Norman/Replogle + scPerturb + 合作方类器官扰动。 - 为什么现在：负面结论刚出、尚未有人在非细胞系体系上验证；类器官方向评测节已出现「扰动预测模型分布外失效」的负面基准，说明评测刚起步且已有实质争议，先做先定义标准。 - 预期产出：开源分层评测套件 + 一篇「基础模型在类器官扰动上何时失效」的实证论文；对合作方交付「哪些扰动值得做湿实验」的筛选准则。 - 主要风险：类器官扰动数据在证据中几乎没有以数据资源形式出现（该方向第 3 节仅 1 篇），模型能力受限于数据而非算法；若合作方数据未到位，demo 只能停在细胞系，说服力打折。

人群队列 + 多组学 → 临床（UKB 等公共队列方法迁移到 ChinaHEART 心血管队列）

项目 1：蛋白组年龄 → 疾病轨迹的条件生成模型（UKB 训练，跨队列外部验证） - 目标：用 UKB 血浆蛋白组 + EHR 纵向数据训练「蛋白组年龄 → 疾病轨迹」的条件生成模型，产出可解释的加速衰老—共病路径；再以 ChinaHEART 的血浆组学/随访做外部校准。 - 用到的方向与具体方法/数据：人群方向「人群健康与多组学 AI：ALADYNOULLI（贝叶斯生成、联合建模纵向诊断+年龄+多基因风险）」「人群健康与多组学 AI：Foresight（生成式预训练 Transformer 建模患者时间线）」作为两条对标路线；衰老时钟方向「多模态衰老时钟与生物年龄：2,897 个血浆蛋白、45,441 人、204 蛋白、r=0.94 的蛋白组时钟」提供年龄轴；数据用 UKB-PPP/Olink、UKB EHR、All of Us/FinnGen 做外部验证，ChinaHEART 做落点。 - 为什么现在：两条线各自已有强证据但尚未打通，交叉点空白；人群方向明确把「把衰老时钟接到生成式轨迹上」列为第一优先，且跨队列复现证据几乎为零，先做即占位。 - 预期产出：一个可解释的「蛋白组年龄—共病轨迹」生成模型 + 跨队列校准报告；对 ChinaHEART 交付一套可迁移的建模与校准流程。 - 主要风险：UKB 单队列结论能否在 All of Us/FinnGen 复现尚无系统证据；ChinaHEART 蛋白组学数据「后续可能有」，若模态缺失，需按衰老时钟方向的缺失模态方法做降级方案；另需注意人群方向已提示「群体 AUC 相似 ≠ 个体一致」（48 个冠心病 PRS 的 ICC/κ 低），不能用群体指标宣称临床可用。

项目 2：ChinaHEART 心血管风险模型相对传统评分的增益与校准（含中国人群迁移） - 目标：在 ChinaHEART 上构建深度/生成式风险模型，系统对标 China-PAR、PCE、SCORE2，重点报告校准与跨人群迁移而非仅 AUC。 - 用到的方向与具体方法/数据：人群方向「人群健康与多组学 AI：LightGBM 轨迹模型在 All of Us 297,861 人、12 项生物标志物 3 年轨迹上 AUROC 0.797 vs 静态汇总 0.755」（说明非生成式轨迹特征本身即携带独立信号，是必须打的基线）；「人群健康与多组学 AI：UKB 暴露组对死亡和 25 种年龄相关病解释度常高于基因组」（提示非组学变量不可省）；衰老时钟方向的多器官代谢组时钟（NMR/Nightingale 平台可迁移）；基线用资源登记中的 China-PAR、Pooled Cohort Equations。 - 为什么现在：中国人群大队列工作被明确列为优先；心血管大队列的 AI/多组学风险预测在打分规则里默认 ≥7 分；而跨人群校准与迁移正是人群方向指出的最大不确定性。 - 预期产出：ChinaHEART 风险模型 + 一份「相对 China-PAR/PCE/SCORE2 的增益与校准」报告；可发表点为校准/迁移方法学，而非又一个风险评分。 - 主要风险：纯临床队列统计关联若无方法新意会被压分（打分规则明确）；必须把方法学增量放在校准、迁移、缺失模态或轨迹建模上，否则退化为增量应用。涉及 2025 年后读出的心血管试验（如 Lp(a)HORIZON 已读出未达主要终点、ZEUS 失败）只能按试验状态表陈述，不得把 Lp(a)/IL-6 轴当作「遗传学→试验已兑现」的支持性例子（来源：试验状态表）。

类器官 / 模式生物的虚拟扰动响应（从细胞系虚拟细胞走向组织与个体层面）

项目 1：跨上下文迁移诊断——细胞系训练、类器官/原代零样本测试 - 目标：量化「上下文外推」的真实衰减，产出一个轻量适配器（不重训基础模型）。 - 用到的方向与具体方法/数据：虚拟细胞方向「虚拟细胞与扰动响应预测：State（1.67 亿细胞、效应区分度提升超 30%）」「虚拟细胞与扰动响应预测：X-Cell（X-Atlas/Pisces，2560 万扰动单细胞、16 种情境）」的跨上下文设定；「虚拟细胞与扰动响应预测：SCALE 条件传输」作为适配器骨架；数据用 Replogle/Adamson/Norman 训练，类器官/原代数据零样本测试。 - 为什么现在：这两篇都是 2026 年新工作、引用个位数，复现与压力测试的空白期最短；且虚拟细胞方向明确指出「类器官/原代体系上的扰动响应是否可迁移完全未知，而这恰好是合作项目的优势区」。 - 预期产出：迁移性诊断报告 + 轻量适配器；可发表点为「跨体系迁移的衰减曲线与失效模式」。 - 主要风险：类器官/原代扰动数据稀缺，零样本测试集可能过小导致结论不稳；需预先声明样本量与置信区间。

项目 2：模式生物→人的同源映射扰动响应（证据缺口明确，从可迁移部分切入） - 目标：在模式生物扰动数据上训练响应模型，用同源映射迁移到人，先在有配对同源数据的体系上验证。 - 用到的方向与具体方法/数据：类器官方向「类器官与模式生物虚拟响应建模：神经最优传输做单细胞扰动响应预测」（可复用方法骨架）、「类器官与模式生物虚拟响应建模：通用细胞嵌入与 Nicheformer」（跨体系表征，但非为扰动迁移专门设计）、「类器官与模式生物虚拟响应建模：跨物种细胞图谱提供同源映射底座」；单细胞方向「单细胞与空间组学基础模型与虚拟细胞：TranscriptFormer（1.12 亿细胞、12 物种）」「单细胞与空间组学基础模型与虚拟细胞：LucaCell（8500 万细胞、跨物种跨模态迁移）」；数据用 SpeciesCorpus、跨物种细胞图谱。 - 为什么现在：跨物种迁移在类器官方向被判为朝阳（方法社区驱动、CNS 占比仅 0.08、方法未定型），窗口存在；但模式生物扰动响应模型本身仅 3 篇、中位引用 1，属萌芽，必须先借道已有跨物种表征模型。 - 预期产出：一个跨物种扰动响应迁移的可行性报告 + 同源映射评测集；合作交付为「哪些模式生物扰动结果可信地指向人」的判定清单。 - 主要风险：证据缺口明确——斑马鱼/线虫/果蝇的剂量-时间响应预测基本没有成型工作，无对照基准、无社区共识读出；若坚持从零建模式生物响应模型，很可能做出一篇无人对标的工作。

方法储备：世界模型 / 自监督表征、LLM 科研智能体——服务于上面三条，不单独立项

项目 1：把「单细胞注释 / 衰老状态判定」做成可验证奖励任务，复用 RLVR 配方 - 目标：构造「给定 marker 与表达矩阵，判定细胞类型/衰老状态」的可自动判分任务，奖励用与 held-out 标注的一致性，照搬 GRPO 的组相对优势估计微调。 - 用到的方向与具体方法/数据：科研智能体方向「LLM 科研智能体与可验证奖励强化学习：DeepSeekMath/GRPO」「LLM 科研智能体与可验证奖励强化学习：Kimi k1.5（不依赖 MCTS、价值函数与过程奖励模型的简洁 RL 框架）」；数据用 Tabula Sapiens、CELLxGENE、小鼠跨器官衰老图谱构造训练/held-out 划分。 - 为什么现在：该配方在可验证任务上已稳定有效，而单细胞推理可被 RL 训练刚被证明，赛道刚开、竞争者少；同时它直接服务于类器官与人群两条线的表征质量。 - 预期产出：带可验证奖励的单细胞推理数据集 + 微调模型；作为方法储备沉淀，不单独作为立项主线。 - 主要风险：科研智能体方向已指出「RLVR 带来的推理能力源自并受限于基座模型上界」（大 k pass@k 时基座更高），不能宣称扩展了推理能力；且生物医学可验证奖励天然稀缺，任务设计稍松就会退化成记忆标注。

项目 2：组学分析流程的过程奖励模型（与过程级评测同步做） - 目标：把生信流程（QC→聚类→差异表达→通路富集）拆成步骤，用规则 + 专家脚本对中间步骤打分（聚类稳定性、富集显著性），训练过程奖励模型。 - 用到的方向与具体方法/数据：科研智能体方向「LLM 科研智能体与可验证奖励强化学习：AgentPRM 类步骤级过程奖励」「LLM 科研智能体与可验证奖励强化学习：过程级生物医学评测刚被提出」；评测侧借「LLM 科研智能体与可验证奖励强化学习：BLADE / BioDataLab」的基准设计思路。 - 为什么现在：长程 RL 已被证明可行，但过程奖励在生物医学几乎空白，评测与训练可同步做；且这条线直接提升类器官与人群两条线的分析可复现性。 - 预期产出：过程奖励模型 + 过程级评测基准；对合作方交付可审计的分析流程。 - 主要风险：过程奖励的规则设计高度依赖专家脚本，容易把「我的流程」编码成「正确流程」；需引入多套独立流程做交叉验证，否则评测基准本身不可信。

不要做的事

  1. 不要再训一个更大的单细胞基础模型，也不要把「更强的扰动预测网络」当主线。 依据：单细胞方向已判「纯再训更大基础模型的窗口基本关闭」，且 GenePT 类简单基线即可竞争；虚拟细胞方向最硬的结论是「深度学习扰动预测尚未跑赢简单线性基线」，并有「2220 万细胞预训练 400 个模型、性能在远小于现有语料时即达平台、无明确数据缩放定律」的直接反证。在这条线上投入算力，边际收益正在快速下降。
  2. 不要从零建模式生物扰动响应模型，也不要碰虚拟组织/数字孪生的概念性立项。 依据：类器官方向「模式生物扰动响应模型」仅 3 篇、中位引用 1；「虚拟组织与数字孪生建模」仅 1 篇概念性工作；「数据资源与基准」仅 1 篇且只是部分相关。无对照基准、无社区共识读出，做出来无人对标，也无法写进合作项目设计。
  3. 不要把纯临床队列统计关联（无方法新意、无公开数据）当产出，也不要把 LLM 科研智能体单独立项。 依据：打分规则明确此类为 0–3 分（心血管大队列与中国人群队列除外，按中档以上看，但前提是有方法学增量）；科研智能体方向的生物医学落地仅萌芽（该节 n=4），且「可验证奖励在生物医学里天然稀缺」是结构性约束。智能体只作为服务三条应用线的工具，不单独开题。
