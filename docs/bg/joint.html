方向间交叉点

方法层面同时出现在多方向的工作

  • JEPA / 隐空间预测：世界模型与自监督表征学习（「JEPA-DNA」把联合嵌入预测接地到基因组基础模型；「DINO-WM」在预训练特征上零样本规划）↔ 单细胞与空间组学基础模型（「CellWorld」以被掩码细胞潜在表征为预测目标，4600 万细胞、3 平台 11 器官）↔ 虚拟细胞（「Chreode」一步式细胞世界模型，240 万细胞小鼠胚胎图谱）。这是当前唯一一条同时被三个方向独立验证的架构线索，但三处都还没有在类器官/原代体系上验证。
  • 生成式轨迹建模：人群健康与多组学 AI（「Foresight」GPT 式患者时间线；「ALADYNOULLI」贝叶斯生成框架联合纵向 EHR 与多基因风险；「Foresight-England」6100 万人 EHR）↔ 虚拟细胞（流匹配/扩散/条件传输重构生成过程，「SCALE」条件传输、「D²R²」掩码离散扩散）。两边的生成范式同源，但人群侧用离散事件序列、细胞侧用表达向量，尚无工作把两者接起来。
  • 条件传输 / 最优传输做扰动：虚拟细胞（「SCALE」条件传输模型）↔ 类器官与模式生物虚拟响应（「神经最优传输做单细胞扰动响应预测」提供可复用方法骨架）。类器官侧的扰动预测目前仍以专用架构为主，最优传输路线尚未在类器官数据上系统比较。
  • 表格基础模型 vs 专用架构：类器官与模式生物虚拟响应（「TabICL/TabPFN 在伪 bulk 扰动预测上持续优于 PRESAGE、scGPT、scLAMBDA、STACK、Prophet 等专用架构」）↔ 单细胞与空间组学基础模型（「GenePT」用基因文本嵌入即达到可比效果；「2220 万细胞预训练 400 个模型」未观察到数据缩放定律）。三条独立证据都指向「专用大模型的架构红利在下降」，这对方法储备的选题优先级是直接信号。
  • 可验证奖励 / 过程奖励：LLM 科研智能体与可验证奖励强化学习（「Kimi k1.5」无 MCTS/价值函数/PRM 的简洁 RL 框架；「GRPO 隐含地就是过程奖励模型」；「大 k pass@k 显示 RLVR 增益受限于基座上界」）↔ 虚拟细胞与单细胞方向的评测需求（「EL-PERTURB」分层 OOD 划分、「Systema」超越表达的扰动响应评测）。扰动预测的评测天然是可自动判分的任务，是 RLVR 在生物医学里最现实的落地形态。
  • 分层分布外评测：虚拟细胞（「EL-PERTURB」在分层 OOD 划分下结论为扰动预测模型在真实 OOD 条件下泛化失败）↔ 类器官与模式生物虚拟响应（同一篇 EL-PERTURB 被两方向共同引用）↔ 单细胞基础模型（「PerturBench」、「未跑赢基线」）。同一套评测协议正在三个方向同时成为话语权中心。
  • 跨物种迁移：类器官与模式生物虚拟响应（「BrainBeacon」跨物种脑空间转录组基础模型；「Microwell-seq」跨物种细胞图谱；「跨物种小脑皮层单细胞空间图谱」）↔ 单细胞与空间组学基础模型（「TranscriptFormer」1.12 亿细胞、12 物种、15.3 亿年进化，零样本跨物种转移注释）↔ 世界模型（「SpeciesCorpus」1.31 亿细胞预训练）。TranscriptFormer 是唯一同时被类器官/模式生物与单细胞两方向登记的资源，是跨物种迁移最现成的底座。
  • 衰老时钟的纵向化：多模态衰老时钟（「OMICmAge」多队列验证；「Δage 每高 5 年全因死亡风险增加 21%」；「Lothian Birth Cohort 1936 三波测量中表观年龄加速不预测 70–76 岁功能下降」）↔ 人群健康与多组学 AI（「纵向蛋白组衰老指数预测死亡与多病」；「UKB 蛋白组衰老可被运动逆转」；「多器官代谢组生物学年龄关联心血管代谢病」）。两边都在做「组学年龄 → 结局」，但人群侧有纵向随访、衰老侧有跨组织泛化，合起来才够做「衰老加速 → 疾病轨迹」的因果链。
  • 心血管结局与组学：人群健康与多组学 AI（「53,026 人、2,920 种蛋白的图谱报告 168,100 个蛋白—疾病关联，183 种疾病判别 AUC>0.80，pQTL 确定 474 个因果蛋白」；「48 个冠心病 PRS 在个体层面一致性差」）↔ 多模态衰老时钟（「353 CpG 表观遗传时钟分析种族、性别与冠心病」）。PRS 个体层面不一致这条证据，直接约束 ChinaHEART 上任何遗传整合方案的设计。

进展会直接改变另一方向做法的

  • 虚拟细胞/单细胞的评测批判 → 类器官扰动建模：若「深度扰动预测未跑赢简单基线」在类器官数据上被复现，类器官应用线里所有「训一个预测模型」的选题都要改成「先建分层评测」。这是跨方向最强的单向影响。
  • 人群侧的生成式轨迹 → 衰老时钟：Delphi-2M / ALADYNOULLI 这类「1000+ 病种、20 年合成轨迹」一旦与蛋白组衰老指数结合，衰老时钟的评价口径会从「预测年龄误差」转向「预测疾病轨迹增益」，现有 MAE/R² 类指标会贬值。
  • 世界模型的隐空间预测 → 虚拟细胞：若 JEPA 式潜空间预测在扰动数据上被证明优于表达值重构，虚拟细胞当前的生成式（扩散/流匹配）主流路线会被部分替代。
  • LLM 智能体的过程奖励 → 所有组学分析流程：过程级奖励若在生信流程上跑通，会改变「谁来做分析」的分工，但生物医学可验证奖励天然稀缺是硬约束。
  • 试验状态表的负面读出 → 心血管多组学靶点叙事：ZEUS 失败（MACE HR 0.99，IL-6 轴不能再用作「遗传学→试验已兑现」的支持性例子）与 Lp(a)HORIZON 未达主要终点（来源：试验状态表），意味着 ChinaHEART 上做蛋白组/MR 找靶点时，IL-6 轴与 Lp(a) 轴不能再作为「机制已验证」的示范案例，这会改变选题的举例方式与预期管理。

按应用线的联合行动

类器官多模态健康衰老模型

项目 1：类器官衰老时序的 JEPA 式多模态表征（公共数据 demo） - 目标：在公共类器官/单细胞数据上，把转录组、表观组、明场影像当作不同 view，做联合嵌入预测而非重构，产出一个可迁移到公共单细胞图谱的衰老轨迹表征。 - 用到的方向与方法/数据：世界模型与自监督表征学习（JEPA 隐空间预测、SIGReg 类正则思路）；单细胞与空间组学基础模型（CELLxGENE 超 7000 万细胞、Tabula Sapiens 564,253 细胞作表征基准）；多模态衰老时钟（跨组织泛化与 Δage 概念作为读出）。数据侧优先用 Cell Painting Gallery 与 JUMP 做影像 view，避免一开始就依赖自有数据。 - 为什么现在：JEPA-DNA 刚证明 JEPA 可接地到基因组基础模型，CellWorld 已在 4600 万细胞上跑通潜空间预测，但类器官时序这一格是空的；同时「2220 万细胞预训练 400 个模型未观察到数据缩放定律」说明再堆规模不划算，换预测目标才是低成本切入点。 - 预期产出：一个类器官多模态衰老表征模型 + 在公共单细胞图谱上的迁移评测；可发表点在于「隐空间预测 vs 重构在衰老时序上的对照」。 - 主要风险：公共类器官多模态配对数据稀缺（类器官方向第 3 节数据资源仅 1 篇），可能只能做「影像+转录组」两模态；衰老标签在类器官上没有公认读出，需自建代理指标。

项目 2：类器官衰老背景下的扰动响应分层评测 - 目标：把「衰老状态」作为分层维度，重做一次扰动响应预测评测，回答「模型在衰老背景细胞上是否更差」。 - 用到的方向与方法/数据：虚拟细胞与扰动响应预测（EL-PERTURB 分层 OOD 划分协议、Systema 的「超越表达」指标）；类器官与模式生物虚拟响应（OSCAR 类器官单细胞 CRISPR 筛选、Perturb-FISH 的基因型×空间读出）；单细胞基础模型（scGPT、Geneformer、scFoundation 作被评对象）。 - 为什么现在：EL-PERTURB 已给出「真实 OOD 下泛化失败」的负面结论，但全部在细胞系上做；类器官 + 衰老背景是尚未被覆盖的分层维度，先做先定义标准。 - 预期产出：一个可复用的分层评测框架 + 一篇「基础模型在类器官衰老背景扰动上何时失效」的实证论文；对合作项目的交付是「哪些模型值得上自有数据」的决策依据。 - 主要风险：负面结论类论文的发表路径依赖期刊对 benchmark 的接受度；若自有类器官数据尚未到位，只能用公共数据，结论外推性受限。

人群队列 + 多组学 → 临床

项目 1：UKB 蛋白组衰老指数 × 生成式疾病轨迹的交叉模型，并向 ChinaHEART 迁移 - 目标：用 UKB 纵向 EHR 诊断序列 + Olink 血浆蛋白组，把生成式疾病自然史框架与纵向蛋白组衰老指数结合，产出「衰老加速 → 疾病轨迹偏移」的量化模型，再设计向 ChinaHEART 的迁移与校准方案。 - 用到的方向与方法/数据：人群健康与多组学 AI（Delphi-2M 作生成式轨迹基线、ALADYNOULLI 作可解释贝叶斯基线、UK Biobank Pharma Proteomics Project 约 5.4 万人/2900 蛋白、FPCA+Cox 弹性网构建纵向蛋白衰老指数）；多模态衰老时钟（Δage 与死亡风险的效应量作先验，蛋白组时钟 Boruta 筛选思路）；心血管队列（China-PAR、PCE 作传统评分基线）。 - 为什么现在：生成式轨迹与蛋白组衰老时钟的交叉窗口估计 1–2 年；且「48 个冠心病 PRS 在个体层面一致性差」这条证据说明遗传整合不能直接照搬，必须做跨队列校准，现在做正好占住「迁移与校准」这个位置而不是再刷一个 UKB 内部 SOTA。 - 预期产出：一个跨队列可迁移的「衰老加速—疾病轨迹」模型 + 一份 ChinaHEART 迁移诊断报告（校准曲线、人群基线差异、需要重估的参数）；可发表点在跨人群校准而非模型本身。 - 主要风险：ChinaHEART 蛋白组学数据「后续可能有」，当前只能做设计不做验证；UKB 单队列结论的跨祖源迁移证据稀少（人群方向最大不确定性即此）；试验状态表显示 IL-6 轴（ZEUS 失败）与 Lp(a) 轴（Lp(a)HORIZON 未达主要终点）不能作为机制已验证的举例（来源：试验状态表），选题叙事需避开。

项目 2：ChinaHEART 心血管风险的传统评分增益审计 - 目标：在 ChinaHEART 上系统量化「深度/生成式模型相对 China-PAR、SCORE2、PCE 的增益」，并把增益拆成「增量信息」与「过拟合队列特性」两部分。 - 用到的方向与方法/数据：人群健康与多组学 AI（「功能衰退预警」用 12 项生物标志物 3 年轨迹特征 + LightGBM，AUROC 0.797 vs 静态汇总 0.755 的对照设计；「AD/PD 亚型」在 CPRD Aurum 与 UKB 双队列复现的设计）；心血管队列（China-PAR、PCE 基线；ARIC、MESA 作外部验证参照）；多模态衰老时钟（Δage 作为附加特征）。 - 为什么现在：ChinaHEART 含问卷、体检、心电、血生化、随访结局，正是「纵向轨迹特征 vs 静态汇总」这套对照设计的理想数据；而人群方向评测层仅 2 篇，谁先做出可复现的增益审计谁定标准。 - 预期产出：一份 ChinaHEART 上的评分增益审计报告 + 可复用的评测脚本；合作交付是「哪些新模态值得加、加多少」的定量答案。 - 主要风险：纯增益审计若无方法新意会落入「纯临床队列统计关联」的低分档（中国人群大队列按中档以上看，但仍需方法包装）；随访时长与事件数决定能拆到多细的亚组。

类器官 / 模式生物的虚拟扰动响应

项目 1：跨体系扰动响应迁移的压力测试（细胞系 → 类器官 → 模式生物） - 目标：在公共 Perturb-seq 上训练，在类器官/原代数据上零样本测试，量化「上下文外推」的真实衰减，并给出轻量适配器方案。 - 用到的方向与方法/数据：虚拟细胞与扰动响应预测（State 的跨上下文状态迁移、X-Cell 的因果扰动预测规模化、Replogle 2022 >250 万细胞、Adamson 68,603 细胞、Norman 2019 组合扰动、Tahoe-100M 1 亿+细胞）；类器官与模式生物虚拟响应（神经最优传输方法骨架、OSCAR 类器官 CRISPR 筛选）；单细胞基础模型（TranscriptFormer 跨 12 物种作跨物种底座）；世界模型（SpeciesCorpus 1.31 亿细胞）。 - 为什么现在：State 与 X-Cell 都是 2026 年新工作、引用个位数，复现与压力测试的空白期最短；且类器官方向明确指出「心脏/血管类器官在证据中近乎空白，既是机会也是风险」——先做迁移衰减的量化，等于先给这个空白定标尺。 - 预期产出：一份迁移性诊断报告 + 一个不需重训基础模型的轻量适配器；可发表点在「跨体系衰减的定量刻画」。 - 主要风险：类器官/原代公共扰动数据规模远小于细胞系，零样本测试的统计功效可能不足；跨物种部分依赖 TranscriptFormer 权重可得性（登记为 unknown）。

项目 2：模式生物扰动响应的跨物种同源映射基准 - 目标：在小鼠/斑马鱼扰动数据上建一个「同源映射 + 响应预测」的最小基准，检验现有跨物种表征是否真的支持响应迁移（而非仅支持注释迁移）。 - 用到的方向与方法/数据：类器官与模式生物虚拟响应（BrainBeacon 跨物种脑空间转录组基础模型、Microwell-seq 跨物种细胞图谱、跨物种小脑皮层单细胞空间图谱）；单细胞与空间组学基础模型（TranscriptFormer 零样本跨物种转移注释）；世界模型（JEPA 式潜空间预测作对照方法）。 - 为什么现在：类器官方向第 2.2 节「模式生物扰动响应模型」仅 3 篇、中位引用 1，斑马鱼/线虫/果蝇的剂量-时间响应预测基本没有成型工作；而跨物种底座（TranscriptFormer、SpeciesCorpus）已经就位，缺的正是「响应」而非「注释」这一层的评测。 - 预期产出：一个跨物种扰动响应基准 + 一篇指出「注释可迁移 ≠ 响应可迁移」的实证论文。 - 主要风险：证据缺口明确——该应用线在模式生物侧几乎没有对照基准与社区共识读出，做出来可能无人对标；数据获取与伦理审批周期长。

方法储备

项目 1：把单细胞注释/衰老状态判定做成可验证奖励任务，复用 RLVR 配方 - 目标：用公共单细胞图谱构造「给定 marker 与表达矩阵，判定细胞类型/衰老状态」的可自动判分任务，奖励用与 held-out 标注的一致性，照搬 GRPO 的组相对优势估计做微调。 - 用到的方向与方法/数据：LLM 科研智能体与可验证奖励强化学习（Kimi k1.5 的简洁 RL 框架、GRPO 组相对优势、λ-GRPO 修正、「大 k pass@k」的上界诊断）；单细胞与空间组学基础模型（CELLxGENE、Tabula Sapiens 作标注源）；多模态衰老时钟（衰老状态标签体系）。 - 为什么现在：该方向明确指出「单细胞推理可被 RL 训练，赛道刚开、竞争者少」；同时「大 k 时基座模型 pass@k 更高」提示必须同时报告大 k 指标，否则增益会被质疑为基座上界内的采样效应——这个诊断设计本身就是方法贡献。 - 预期产出：一个带可验证奖励的单细胞推理数据集 + 微调模型 + 大 k 评测协议。 - 主要风险：可验证奖励在生物医学里天然稀缺，注释任务可能过于简单导致饱和快；「随机分配奖励的 GRPO 也能提升 21.4 点」这一现象提示增益可能不来自任务信号，需设计对照。

项目 2：生信分析流程的过程奖励模型与过程级评测 - 目标：把 QC→聚类→差异表达→通路富集拆成步骤，用规则+专家脚本对中间步骤打分（聚类稳定性、富集显著性），训练过程奖励模型，并同步建过程级评测基准。 - 用到的方向与方法/数据：LLM 科研智能体与可验证奖励强化学习（AgentPRM 的步骤级 promise/progress 过程奖励、GACA 的步级/回合级优势混合、「GRPO 隐含地就是过程奖励模型」的理论结果）；单细胞与空间组学基础模型（PerturBench、atlas-level 整合基准作步骤级真值参照）；虚拟细胞（EL-PERTURB 的分层划分思路可移植到流程步骤划分）。 - 为什么现在：该方向指出「过程奖励在生物医学几乎空白，而过程级评测需求刚被提出，评测与训练可同步做」；且「GRPO 隐含 PRM」的理论结果意味着过程奖励不必从零设计算法，重点是奖励信号本身。 - 预期产出：过程奖励模型 + 过程级评测基准；对三条应用线的交付是「分析流程自动化」的可信度评估。 - 主要风险：步骤级真值依赖专家脚本，主观性强、难复现；该方向第 2.4 节「智能体信用分配、验证与安全机制」证据不足（仅 2 篇），缺少可对标的前作。

不要做的事

  • 不要再训一个通用单细胞/扰动预测基础模型去刷表达拟合指标。 依据：单细胞与空间组学基础模型方向明确指出「深度学习扰动预测尚未跑赢基线」，虚拟细胞方向进一步给出「五种基础模型和两种深度学习模型在单/双基因扰动预测上没有任何模型优于简单线性基线」；同时「2220 万细胞预训练 400 个模型、6400 次实验未观察到明确数据缩放定律」、「GenePT 用 GPT-3.5 基因文本嵌入即达到与 Geneformer 相当甚至更优」、「表格基础模型在伪 bulk 扰动预测上持续优于专用架构」。架构红利在下降，规模红利未见，投入产出比最差。
  • 不要在 UKB 单队列上再刷一个 SOTA 然后声称可迁移。 依据：人群方向最大不确定性即「现有结论多来自 UK Biobank 单队列，FinnGen/All of Us 上的迁移与公平性证据稀少」；且「48 个冠心病 PRS 在群体水平表现相似但个体层面一致性差（ICC 与 Light κ 低）」。跨队列校准与个体层面一致性才是空白，单队列增益没有增量价值。
  • 不要把 LLM 科研智能体当独立方向做通用系统。 依据：画像已明确方法储备「服务于上面三条，不单独立项」；且该方向生物医学落地仅 n=4、评测基准互不兼容且饱和快，「The AI Scientist 验证仅限三个 ML 子领域且依赖自动评审器、未含真实同行评审」。只做能挂到具体应用线数据上的那一层（可验证奖励、过程奖励），不做通用 agent 框架。
  • 不要碰纯临床队列统计关联且无方法包装的心血管选题。 依据：画像低分信号明确列出「纯临床队列统计关联，无方法新意、无公开数据」（中国人群大队列按中档以上看，但仍需方法成分）；且试验状态表显示 IL-6 轴（ZEUS，MACE HR 0.99）与 Lp(a) 轴（Lp(a)HORIZON 未达主要终点）已不能作为机制已验证的举例（来源：试验状态表），沿这两条轴做 MR 找靶点的叙事风险显著上升。
