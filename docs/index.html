跨域趋势

  1. Agent 能力评估正在从"能不能做"转向"压力下还稳不稳"：RLVR-stress-test 这类工作说明社区开始系统性地质疑 RLVR 的鲁棒性，而不只是刷 benchmark。这对 agentic 科研工作流是必要的基础设施——如果 agent 在扰动下不可靠，就没法托付真实的科研 pipeline。

  2. 空间转录组分析代码正在快速"工具化/模板化"：HPV_OPC_spatial_transcriptomics 这类 repo 表明空转分析流程正从"每篇论文自己写"变成"可复用的分析模板"。方法迁移成本在下降，跨癌种/跨组织的空转方法复用窗口正在打开。

  3. 基础模型的"平台移植"成为独立工作类型：mlx-AuK 把语音基础模型搬到 MLX，本身与你的方向无关，但反映出一个信号——foundation model 的部署/移植/量化正在成为一类独立工程产出。对单细胞 foundation model 而言，类似"能在本地/边缘跑"的移植工作未来会变多，值得留意。

  4. GitHub 作为科研情报源的信噪比在下降：本周 5 条里 3 条是低分或无关，说明纯 GitHub 抓取 + 关键词粗筛的召回质量有限。趋势判断：需要引入更强的来源分层（如 papers with code、biorxiv、HF datasets/models）来平衡。

  5. "分子钟"类传统方法仍在被重新包装：molecularclock 这类老方法以新 repo 形式出现，提示关键词"clock"会持续带来噪声。aging clock 与分子钟定年是两个完全不同的领域，粗筛阶段需要更精确的消歧。

对多模态衰老模型合作的启发

  1. 数据层面——把空转分析模板纳入 demo 数据管线：HPV_OPC_spatial_transcriptomics 的分析代码可作为空转模态的"参考实现"，用来验证你多模态 demo 中空间转录组分支的预处理/对齐流程是否合理。具体动作：clone 下来，用公共衰老空转数据（如小鼠/人组织 aging atlas）跑一遍，检查其 QC、归一化、空间邻域构建步骤能否直接复用。

  2. 方法层面——把 RLVR 鲁棒性思路迁移到多模态整合的"缺失模态"场景：RLVR-stress-test 的核心是"在扰动下测试可靠性"。你的合作项目明确要处理缺失模态和跨队列校正，可以把"stress test"作为评估范式：人为 mask 掉某个模态（蛋白组/甲基化），看整合模型是否仍稳定。这是一个可直接写进方法学章节的评估设计。

  3. 实验设计层面——为"持续学习/增量学习"预留接口：合作方后续会陆续进新模态和新队列，本周信号（agent 鲁棒性、模型移植）都指向"系统要能持续演进"。建议在 demo 阶段就把模型设计成支持增量接入的架构（如 modality adapter + 冻结主干），而不是等新数据来了再重构。具体动作：先定义好模态注册接口和版本化数据 schema。

Same Encoder, Different Winner: A Paired-View Framework for Cell Painting Encoder Evaluation9.0
Cell Painting编码器配对评估基准，直接契合cell painting+ML合作方向。
arxiv · · Tim Treis, Nikita Moshkov, Johan Fredin Haslum, Shantanu Singh, Fabian J. Theis
深读笔记

总结

该文提出 CP-BG-Bench，一个"配对视图"评估框架：对同一细胞中心固定不变，生成原始裁剪（C）、分割（S）、密度增强（CD/SD）四种视图，在 JUMP-CP、RxRx1、RxRx3-core 三个 Cell Painting 数据集和三种编码器上，用四套社区标准协议（replicate mAP、scIB、CellProfiler 特征预测、跨批次扰动召回）评估，发现同一编码器在不同协议下排名系统性不一致。作者将分歧分解为三条正交轴：细胞 vs 背景、形态 vs 上下文、研究内 vs 跨批次，并指出单指标排名 Cell Painting 编码器高度依赖所选协议。

核心方法

核心是配对视图的受控干预设计：用 Cellpose-SAM 分割后，对每个单细胞裁剪保留同一细胞中心，分别生成 C（含背景）、S（掩膜外置零）、CD/SD（四角叠加编码局部细胞密度的 patch），从而把背景与密度从细胞形态中解耦。三种编码器（DINOv3 ViT-B/16、OpenPhenom、SubCell）在每种视图下用 LoRA + 多正样本对比目标（化合物用 ECFP4、基因扰动用 ESM2 条件）微调，共 36 个 checkpoint，再在四套协议下评估。

数据与代码可用性

作者承诺随最终版公开配对视图 JUMP-CP 数据集（CC0 v1.0，含 Croissant 元数据与 Responsible AI 字段）、RxRx1（CC BY-NC）与 RxRx3-core 的确定性重建管线（不重分发源图）、36 个训练 checkpoint、聚合的 well 级 embedding 以及完整评估套件。可直接拿来用的线索：JUMP-CP 配对视图数据 + 重建脚本 + checkpoint + 评估套件，适合作为方法学 baseline 或迁移到自有数据的评估模板；RxRx1/RxRx3-core 需自行跑重建管线。

局限

评估仅覆盖三种视觉编码器与三个 Cell Painting 数据集，结论对更广的 foundation model 与模态（如蛋白组、甲基化、空间转录组）的外推性未知；密度 patch 是显式人工编码而非学习得到，可能低估真实密度信号；CPM 基线为无监督特征、与有监督微调编码器对比，差距部分反映监督而非架构优势；跨批次召回在 JUMP-CP 上绝对数值很低，协议本身的判别力有限。

对多模态衰老模型合作的启发

这篇正好命中画像中"cell painting + ML"与"多模态整合方法学"的高分信号，且直接服务于多模态健康衰老模型的 demo 阶段：可先用其配对视图框架在公共 Cell Painting 数据上验证"背景/密度信号是否可跨批次迁移"，作为类器官成像模态进入合作项目前的评估预演。具体可执行：把 CP-BG-Bench 的四协议评估套件接入你现有的单细胞 foundation model 评测流程，作为"跨队列校正/缺失模态"方法学的对照基准；同时借鉴其"固定中心、切换上下文"的受控干预思路，设计类器官 + 组学数据中"模态缺失/模态替换"的配对评估，避免单一指标（如仅看整合后聚类）误判模型。
