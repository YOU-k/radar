  # 深读笔记：Intraindividual longitudinal changes of the proteome reveal dynamic markers of biological aging
  
  **总结**
  该研究基于 KORA 人群队列（4,100 人、9,105 份血浆样本、最多 3 个纵向时间点、25–88 岁），构建了纵向血浆蛋白质组衰老时钟，证明蛋白质组年龄加速是动态可变的，且与生活方式、心血管代谢风险因素、肾功能、血脂异常及全因死亡相关。核心结论是"生物学衰老对可改变风险因素具有动态响应性"，并用中介分析和孟德尔随机化把风险因素—衰老加速—死亡串成一条因果链。
  
  **核心方法**
  用 LC-MS 血浆蛋白质组（质谱，非 Olink/SomaScan 抗体 panel）在个体内纵向重复采样上训练年龄预测模型，输出"蛋白质组年龄加速"（proteomic age acceleration）；再做风险因素分层分析、个体内轨迹分析、中介分析（风险因素→年龄加速→死亡）和 MR 因果推断。方法学亮点是**个体内纵向建模**而非横截面时钟，能区分"个体间差异"与"个体内变化"。
  
  **数据与代码可用性**
  摘要未提数据/代码开放情况，KORA 属于受控访问的德国人群队列（通常需申请），LC-MS 原始数据一般存于 ProteomeXchange/PRIDE，代码可能随文补充。**不能直接拿来用**：需要去论文正文/补充材料确认是否有 GitHub 与数据 accession，KORA 数据大概率要走申请流程；但模型思路（纵向蛋白质组时钟 + 中介 + MR）可复现迁移。
  
  **局限**
  仅摘要可见：样本为德国 KORA 单一队列、欧洲人群，跨人群（尤其东亚/中国）校准与迁移未验证；LC-MS 蛋白质组通量与成本高，难以直接套到大队列常规检测；纵向仅最多 3 个时间点，动态建模的时间分辨率有限；MR 用的是遗传工具，与蛋白质组时钟的因果方向仍需谨慎解读。
  
  **对「类器官多模态健康衰老模型」的启发**
  最直接对应**应用线 1（类器官多模态健康衰老模型）**：这篇提供了"纵向、个体内、多时间点"的衰老建模范式，可把类器官的重复扰动/多时间点采样当作"个体内纵向"来设计——即每个类器官系/供体在多个时间点做多模态读出，训练"类器官衰老时钟 + 年龄加速"作为响应变量，而不是只做横截面比较。其次对**应用线 2（人群队列 + 多组学 → 临床）**有方法迁移价值：其"风险因素分层 + 中介 + MR"的分析框架可直接搬到 ChinaHEART 血浆蛋白组/代谢组上，检验心血管风险因素是否通过组学年龄加速影响结局。对**应用线 3（虚拟扰动响应）**的启发较弱，主要是"纵向动态响应"这一建模视角可借鉴，但本文不做扰动预测。**应用线 4（方法储备）**方面，其纵向时钟 + 中介/MR 的组合是可复用的分析模板，但非底层新范式。
