## 方向间交叉点

**方法层面**

- **「隐空间预测而非重构」同时出现在世界模型与虚拟细胞/单细胞基础模型**：世界模型方向：CellWorld 把预测目标改为潜在细胞表征（JEPA 式）；世界模型方向：JEPA-DNA 把联合嵌入预测架构接地到基因组基础模型；虚拟细胞方向：Chreode 作为一步式细胞世界模型在 240 万细胞小鼠胚胎图谱上预训练。这条线是「类器官时序 + 扰动」最直接的架构候选。
- **生成式序列建模同时出现在人群队列与 LLM 智能体**：人群健康方向：Delphi-2M 改造 GPT 架构、Foresight-England 用 243M 参数自回归 Transformer 解码器建模国家级 EHR；LLM 方向：GRPO/RLVR 配方（Kimi k1.5 报告不依赖 MCTS、价值函数与过程奖励模型的简洁 RL 框架）。前者提供任务形态，后者提供训练范式。
- **「评测效度批判」同时出现在虚拟细胞、单细胞基础模型、类器官扰动三个方向**：虚拟细胞方向：Deep-learning-based gene perturbation effect prediction does not yet outperform simple linear baselines、EL-PERTURB 分层 OOD 划分；单细胞方向：PerturBench 与「未跑赢基线」的批判性结果；类器官方向：EL-PERTURB 在必需基因与全基因组 Perturb-seq 上压力测试 20 个模型、结论为真实 OOD 下泛化失败。**同一批判在三处独立出现，说明这是当前最稳的方法学站位。**
- **条件传输 / 流匹配同时出现在虚拟细胞与类器官扰动**：虚拟细胞方向：SCALE 条件传输模型、OCOO-T 极简流匹配 Transformer；类器官方向：DiRL 把分化建模为目标条件序列决策问题。类器官的分化/扰动轨迹天然适合这类生成范式。
- **跨物种迁移同时出现在类器官/模式生物与单细胞基础模型**：类器官方向：神经最优传输做单细胞扰动响应预测、BrainBeacon 跨物种脑空间转录组基础模型；单细胞方向：TranscriptFormer（12 物种、跨越 15.3 亿年进化）、LucaCell 跨物种跨模态迁移、Speciesformer 在 1.31 亿细胞 SpeciesCorpus 上预训练。
- **表格基础模型 vs 专用架构的对比出现在类器官扰动与人群队列两侧**：类器官方向：TabICL/TabPFN 在伪 bulk 扰动预测上持续优于 PRESAGE、scGPT、scLAMBDA、STACK、Prophet 等专用架构；人群健康方向：LifeLong Digital Twin 在 25 个疾病终点、4 个语言模型上报告 16 个模型-读出比较全部提升。**「表格/结构化数据基础模型」是被低估的共用底座。**

**数据层面**

- **UK Biobank 是四个方向的共用底座**：多模态衰老时钟（2,897 个血浆蛋白、45,441 人的蛋白组时钟；274,247 人的代谢组时钟）、人群健康（Pharma Proteomics Project 54,219 人 2,923 蛋白；外显子测序 454,787 人）、心血管应用线（ChinaHEART 迁移参照）、世界模型/自监督（评测基准的潜在下游任务来源）。
- **Perturb-seq 家族同时服务虚拟细胞、单细胞基础模型、类器官扰动**：Replogle 2022（>250 万人类细胞）、Norman 2019、Tahoe-100M（1 亿+细胞/50 细胞系/379 化合物）、scPerturb 聚合库。**同一批数据在三处被当作训练集与基准，意味着跨方向的评测协议可以共用。**
- **类器官多模态配对数据是明确缺口**：类器官方向第 3 节（数据资源与基准）仅 1 篇，且为发育海马图谱对基础模型的基准；现有类器官数据多为药敏 + 明场图像（31,360 张明场图、988 个类器官 117,249 张明场延时图像）或单一组学，缺「扰动 × 多组学 × 时序」配对。

**问题层面**

- **「跨队列/跨上下文泛化」在三个方向是同一个问题**：多模态衰老时钟的跨队列校正、人群健康的跨生物库复现（ALADYNOULLI 跨队列组成保留中位 80%）、虚拟细胞的跨上下文迁移（State 训练于 1.67 亿细胞、Tahoe-x1 扩展至 30 亿参数）。**方法可共用，只是「队列」的定义从人群换成细胞体系。**
- **「缺失模态处理」是多模态衰老时钟与类器官多模态的共同瓶颈**：前者明确写「缺失模态与跨队列校正没有公认方案」；后者合作项目本身就要面对「后续可能有蛋白质组、甲基化、空间转录组」的增量模态。

**进展会直接改变另一方向做法的**

- **虚拟细胞/单细胞方向的评测批判 → 直接改变类器官扰动建模的选题**：一旦「不跑赢基线」在更多数据上被确认，类器官方向纯预测型工作的审稿门槛会快速抬高（类器官方向自身也已指出这一点）。
- **世界模型的隐空间预测 → 直接改变类器官多模态衰老模型的架构选择**：若 JEPA 式目标在组学时序上被验证，则「重构式多模态整合」的路线会被替代。
- **人群健康的生成式轨迹模型 → 直接改变 ChinaHEART 应用线的建模目标**：从「风险评分」升级为「个体化轨迹 + 多病发生时间」，但前提是跨人群校准先解决。
- **LLM 智能体的过程奖励 → 可能改变所有方向的日常分析流程**，但目前生物医学落地仅萌芽（该节 n=4），短期不宜作为项目主线。

## 按应用线的联合行动

### 类器官多模态健康衰老模型

**项目 1：类器官时序的隐空间预测表征（JEPA 式多模态融合）**

- **目标**：在公共类器官/单细胞多组学数据上，把转录组、表观组、影像当作不同 view，做联合嵌入预测而非重构，产出一个可迁移到公共单细胞数据的衰老轨迹表征；同时把「缺失模态」作为训练时的显式场景（随机丢弃模态），为后续新数据进来做增量适配留接口。
- **用到的方向与具体方法/数据**：世界模型与自监督表征学习（JEPA 式潜空间预测、LeJEPA 的 SIGReg 正则、SiamJEPA 的孪生编码器 + EMA 教师）；单细胞与空间组学基础模型（CellWorld 把预测目标改为潜在细胞表征、CellFM 1 亿人类细胞预训练、TranscriptFormer 跨物种）；数据用 CELLxGENE（超 7000 万细胞）、Tabula Sapiens（564,253 细胞）、scPerturb。
- **为什么现在**：世界模型方向：JEPA-DNA 刚证明 JEPA 可接地到基因组基础模型，而单细胞方向：对单细胞自监督「有效使用」尚缺系统结论（世界模型方向亦指出该节证据不足）；两者之间的空白正好是类器官时序。且多模态衰老时钟方向明确写「缺失模态与跨队列校正没有公认方案」，先做先占位。
- **预期产出**：一个可复用的多模态融合框架 + 跨队列泛化 benchmark（可发表点：方法学论文，对标多模态衰老时钟方向的窗口）；对合作项目交付一个「新模态进来即可增量适配」的表征底座。
- **主要风险**：类器官多模态配对数据在证据中几乎不存在（类器官方向第 3 节仅 1 篇），demo 阶段只能用公共单细胞数据近似，**「类器官」标签可能名不副实**；JEPA 在表格/组学数据上的实证有反例（世界模型方向：JEPA 臂在 147 个真实表格数据集上落后仅值目标臂，分类 32:70 胜负），需先做小规模对照再押注。

**项目 2：类器官扰动的分层效度评测（把批判做成方法学标签）**

- **目标**：以虚拟细胞方向的基线协议为骨架，在类器官/原代体系上重做一次分层评测（按扰动类型、细胞类型未见程度、供体差异分层），回答「基础模型在类器官扰动上何时失效」。
- **用到的方向与具体方法/数据**：虚拟细胞与扰动响应预测（EL-PERTURB 分层 OOD 划分、Systema 的「超越表达」指标、Deep-learning-based gene perturbation effect prediction does not yet outperform simple linear baselines 的基线协议）；单细胞基础模型（PerturBench、PertEval-scFM 标准化扰动效应预测评估框架）；类器官方向（Perturb-FISH 的 MERFISH + gRNA 原位扩增读出、OSCAR 的调控网络活性读出）；数据用 Replogle 2022、Norman 2019、Tahoe-100M、Virtual Cell Challenge。
- **为什么现在**：负面结论刚出且尚未有人在非细胞系体系上验证（虚拟细胞方向明确写「类器官/原代体系上的扰动响应是否可迁移完全未知，而这恰好是博后合作项目的优势区」）；类器官方向自身也指出评测节已出现实质性争议、属萌芽期。
- **预期产出**：一个可复用的分层评测框架 + 一篇「基础模型在类器官扰动上何时失效」的实证论文；对合作项目交付「选哪个基线、用什么指标」的决策依据。
- **主要风险**：类器官扰动 + 空间 + 影像的多模态配对数据在证据中几乎没有以数据资源形式出现，评测可能因数据不足而只能做小样本结论；且评测类工作引用窗口好但**不产生新模型**，对需要算法交付的合作方说服力需提前沟通。

### 人群队列 + 多组学 → 临床（UKB 方法迁移到 ChinaHEART）

**项目 1：纵向多组学衰老时钟 + 疾病轨迹的联合模型，并以 ChinaHEART 为迁移落点**

- **目标**：用 UKB 重复测量蛋白组/代谢组 + EHR 诊断序列，输出「个体化衰老轨迹 → 多病发生时间」的生成式预测；再把该框架迁移到 ChinaHEART 的问卷、体检、心电、血生化、随访结局上，重点解决跨人群校准。
- **用到的方向与具体方法/数据**：人群健康与多组学 AI（Delphi-2M 的 GPT 式疾病进展与竞争风险建模、ALADYNOULLI 的贝叶斯生成框架联合建模纵向诊断与多基因风险、FPCA + Cox 弹性网构建纵向蛋白衰老指数、UKB Pharma Proteomics Project 的 pQTL 图谱）；多模态衰老时钟（蛋白组时钟 PAC、5 个器官 MetBAG、Boruta 筛选 204 蛋白的蛋白组时钟）；心血管应用线基线用 China-PAR、Pooled Cohort Equations；数据用 UKB、UKB-PPP（约 5.4 万人 · 约 2,900 蛋白）、ChinaHEART、China Kadoorie Biobank（约 51 万成人）作对照。
- **为什么现在**：人群健康方向明确写两条线「各自已有可信起点但尚未合并，合并处正是空白」；且该方向窗口期估计 12–24 个月，一旦 EHR 基础模型在 UKB/All of Us 上出现统一基准，早期方法学红利会迅速转为增量竞争。ChinaHEART 是画像里的目标队列，越早建立 UKB→ChinaHEART 的迁移管线越占位。
- **预期产出**：一个跨队列可迁移的「衰老轨迹 → 多病时间」生成式框架 + 一份 UKB→ChinaHEART 的校准诊断报告（可发表点：方法学论文，对标 Nature Medicine / Nature Genetics 级别）；对合作方交付 ChinaHEART 上的基线对照结果（相对 China-PAR / PCE 的增益与校准）。
- **主要风险**：**ChinaHEART 的血浆组学/遗传数据是「后续可能有」，当前只能做问卷+体检+心电+血生化**，蛋白组迁移部分需先以 UKB-PPP 内部跨祖源验证代替；生成式轨迹模型缺乏统一评测与跨队列可复现性证据（人群健康方向第 5 节雷达样本仅 2 篇），审稿时需自带评测；数据访问受控（UKB controlled、ChinaHEART controlled），时间成本高。

**项目 2：心血管多组学风险预测的跨人群校准与迁移诊断**

- **目标**：以 UKB 血浆蛋白组 pQTL 图谱为骨架，构建冠心病/心衰/房颤/卒中的蛋白组风险评分，系统量化迁移到中国人群时的精度衰减与校准偏移，并给出校正方案（而非再刷一个预测模型）。
- **用到的方向与具体方法/数据**：人群健康与多组学 AI（LASSO Cox + CatBoost 整合蛋白、PRS 与传统风险、pQTL 精细映射、跨祖源 PRS 精度随血统分歧线性下降的结论）；多模态衰老时钟（器官特异 MetBAG 的多器官思路可迁移到多器官 CVD 终点）；数据用 UKB-PPP、Pan-UK Biobank（多祖源 GWAS 汇总）、GBMI（23 库 220 万人 14 终点）、ARIC（蛋白组心衰/衰弱队列）、MESA（多模态 CVD 队列外部验证）、ChinaHEART。
- **为什么现在**：人群健康方向指出「跨队列复现」是方法学卖点、且该方向评测缺口明显；心血管应用线明确要求「相对 PCE / SCORE2 / China-PAR 的增益、跨人群尤其中国/东亚的校准与迁移」，这是可直接对上的题目。中国人群大队列工作在画像里一律优先。
- **预期产出**：一份跨人群蛋白组风险评分的迁移诊断报告 + 一套校准校正方法（可发表点：Nature Cardiovascular Research / EHJ 级别的方法+验证论文）；对合作方交付 ChinaHEART 上可用的校准后评分与不确定性估计。
- **主要风险**：ChinaHEART 蛋白组数据未到位前，只能用 CHARLS（中国中老年队列，registration）或 China Kadoorie Biobank 做部分替代验证，**结论外推强度受限**；纯迁移/校准工作若无可复现的增益数字，易被归入「纯临床队列统计关联」而压分，需自带方法新意（如缺失模态下的校准）。

### 类器官 / 模式生物的虚拟扰动响应

**项目 1：跨体系扰动响应的迁移性诊断（细胞系 → 类器官/原代）**

- **目标**：拿 State 与 X-Cell 的跨上下文设定，在公开 Perturb-seq 上训练、在类器官/原代数据上零样本测试，量化「上下文外推」的真实衰减，并给出一个轻量适配器（不重训基础模型）。
- **用到的方向与具体方法/数据**：虚拟细胞与扰动响应预测（State 细胞嵌入训练于 1.67 亿细胞、X-Cell 的 X-Atlas/Pisces 2560 万扰动单细胞 16 种情境、SCALE 条件传输、Tahoe-x1 扩展至 30 亿参数）；类器官与模式生物（神经最优传输做单细胞扰动响应预测、DiRL 的目标条件序列决策、Perturb-FISH 的空间读出）；单细胞基础模型（Tahoe-x1 跨模态继续预训练仅 70M 参数即在多数基准匹配 1B/3B RNA-only 模型）；数据用 Replogle 2022、Tahoe-100M、Norman 2019、scPerturb、SpeciesCorpus（1.31 亿细胞）。
- **为什么现在**：State 与 X-Cell 都是 2026 年新工作、引用个位数，**复现与压力测试的空白期最短**；且虚拟细胞方向明确写「类器官/原代体系上的扰动响应是否可迁移完全未知」。
- **预期产出**：一个迁移性诊断报告 + 一个轻量适配器（可发表点：实证论文，对标虚拟细胞方向的方法学窗口）；对合作项目交付「哪些扰动结论可以从细胞系外推到类器官」的判定准则。
- **主要风险**：类器官侧缺配对的扰动 + 多组学数据，零样本测试可能只能落在少数公开类器官药敏数据集上，**样本量不足以支撑分层结论**；且若「不跑赢基线」的结论在类器官上同样成立，项目产出会变成负面结论——需提前与合作方对齐「负面结论也是交付」。

**项目 2：跨物种扰动响应的同源映射与迁移（模式生物 → 人）**

- **目标**：在模式生物（小鼠、斑马鱼）扰动数据上训练响应模型，通过同源映射迁移到人类类器官/原代体系，量化跨物种迁移的衰减并识别可迁移的响应模块。
- **用到的方向与具体方法/数据**：类器官与模式生物（跨物种细胞图谱提供同源映射底座、BrainBeacon 跨物种脑空间转录组基础模型、表格基础模型跨体系做扰动预测的尝试）；单细胞与空间组学基础模型（TranscriptFormer 12 物种、LucaCell 跨物种跨模态迁移、Speciesformer 在 1.31 亿细胞 SpeciesCorpus 上预训练）；世界模型与自监督（JEPA 式隐空间预测可绕开物种间表达值不可比的问题）；数据用 SpeciesCorpus、Tabula Sapiens、CELLxGENE。
- **为什么现在**：类器官方向明确写「模式生物扰动响应模型」处于萌芽（仅 3 篇且中位引用 1）、「斑马鱼/线虫/果蝇的剂量-时间响应预测基本没有成型工作」；跨物种迁移方法路线仍在竞争（该节 CNS 占比仅 0.08、中位引用 72，方法社区驱动而非顶刊驱动），**正处方法未定型的窗口**。
- **预期产出**：一个跨物种扰动响应迁移框架 + 可迁移响应模块清单（可发表点：方法学论文）；对合作项目交付「用哪种模式生物做前置筛选、结论能外推到人的比例」的量化依据。
- **主要风险**：**证据最薄的一节**——模式生物扰动响应模型仅 3 篇、虚拟组织仅 1 篇、数据资源与基准仅 1 篇，几乎无对照基准与社区共识读出；跨物种同源映射本身误差可能淹没扰动信号，需先做阴性对照。

### 方法储备：世界模型 / 自监督表征、LLM 科研智能体

**项目 1：组学分析流程的过程奖励模型 + 过程级评测基准**

- **目标**：把生信分析流程（QC→聚类→差异表达→通路富集）拆成步骤，用规则 + 专家脚本对中间步骤打分（聚类稳定性、富集显著性），训练过程奖励模型，并同步构建过程级评测基准。
- **用到的方向与具体方法/数据**：LLM 科研智能体与可验证奖励强化学习（GRPO 组相对优势估计、Kimi k1.5 的简洁 RL 框架、AgentPRM 的步骤级 promise/progress 过程奖励、GACA 的步级/回合级优势混合、过程级生物医学评测的刚提出需求）；单细胞与空间组学基础模型（CellVoyager 基于 LLM 自主探索 scRNA-seq 的智能体可作基线）；数据用公共单细胞图谱（CELLxGENE、Tabula Sapiens）构造可自动判分任务。
- **为什么现在**：LLM 方向明确写「过程奖励在生物医学几乎空白，而过程级评测需求刚被提出，**评测与训练可同步做**」；且该方向生物医学落地仅萌芽（n=4），竞争者少。
- **预期产出**：过程奖励模型 + 过程级评测基准（可发表点：基准/方法论文）；对三条应用线交付一个能自动跑标准分析流程并自检的智能体原型。
- **主要风险**：LLM 方向指出「可验证奖励在生物医学里天然稀缺（湿实验慢、噪声大、组学结论常不可二值判定）」，过程奖励的规则设计容易被质疑为主观；且该方向评测可信度问题（现有基准多为静态问答，无法验证长程实验闭环的真实增益）会连带影响本项目的说服力。

**项目 2：世界模型式扰动预测 demo（隐空间预测 + 零样本扰动组合规划）**

- **目标**：拿公共 Perturb-seq / 药物扰动数据，训练一个在隐空间预测「扰动后状态」的世界模型，而不是直接预测表达值；产出可零样本规划（选扰动组合）的 demo。
- **用到的方向与具体方法/数据**：世界模型与自监督表征学习（DINO-WM 在预训练视觉特征上做零样本规划、Flow-JEPA 用条件流匹配生成未来潜状态序列、D-JEPA 的决策对齐隐世界模型、LeJEPA 的 SIGReg 正则）；虚拟细胞与扰动响应预测（Chreode 一步式细胞世界模型、SCALE 条件传输）；数据用 Tahoe-100M、Replogle 2022、Norman 2019、scPerturb。
- **为什么现在**：世界模型方向明确写「DINO-WM 已证明在预训练特征上做零样本规划可行，这套思路迁到扰动数据上尚无人做」；且该方向向科学数据迁移刚起步（该节 n=7、近两年占比 0.71），方法未定。
- **预期产出**：一个隐空间扰动世界模型 + 零样本扰动组合规划 demo（可发表点：方法学论文，同时服务类器官扰动与虚拟细胞两条应用线）；对合作项目交付「扰动组合筛选」的候选生成器。
- **主要风险**：世界模型方向给出明确反例——JEPA 臂在 147 个真实表格数据集上落后仅值目标臂（分类 32:70 胜负、回归 8:24），且需 1.42 倍步数与 1.66 倍墙钟达平台；**在组学数据上可能重演这一结果**，需先做小规模对照。另需注意虚拟细胞方向的负面结论：现有深度模型在扰动预测上尚未跑赢简单基线，规划能力的宣称必须有严格基线对照。

## 不要做的事

- **不要再训一个更大的单细胞基础模型，也不要把「更大规模预训练」当作项目卖点。** 依据：单细胞与空间组学基础模型方向明确写「纯『再训一个更大的单细胞基础模型』的窗口基本关闭」——该方向 2.1 节已成熟收敛，GenePT 用简单基因文本嵌入即取得有竞争力效果；且虚拟细胞方向有「用 2220 万细胞预训练 400 个模型、6400 次实验后发现性能在数据规模远小于当前训练语料时就趋于平台，未观察到明确的数据缩放定律」的直接反证。算力投入与产出不成比例。
- **不要做纯预测型（无评测、无失败归因）的扰动响应模型，尤其不要以「我们的模型更好」为唯一卖点。** 依据：虚拟细胞方向：Deep-learning-based gene perturbation effect prediction does not yet outperform simple linear baselines；单细胞方向：四个 Perturb-seq 数据集的差分空间里 Train Mean 基线优于 scGPT 与 scFoundation，随机森林加 GO 特征最佳；类器官方向：EL-PERTURB 在分层 OOD 划分下结论为扰动预测模型在真实 OOD 条件下泛化失败。**同一批判在三个方向独立出现，纯预测型工作的审稿门槛会快速抬高。**
- **不要把 LLM 科研智能体当作独立主线立项，也不要在生物医学场景上宣称长程实验闭环能力。** 依据：LLM 科研智能体方向生物医学场景应用仅萌芽（该节 n=4），可验证奖励在生物医学里天然稀缺；The AI Scientist 验证仅限三个 ML 子领域且依赖自动评审器、未含真实同行评审；Kosmos 综合陈述准确率仅 57.9% 且需科学家指定目标与数据集；Robin 为半自主、需实验室闭环验证且仅体外验证。**该方向只应作为方法储备服务三条应用线**，与画像「不单独立项」一致。
