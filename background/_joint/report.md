## 方向间交叉点

### 一、方法同时出现在 ≥2 个方向

**1. JEPA / 隐空间预测式自监督（世界模型 ↔ 单细胞基础模型 ↔ 衰老时钟）**
- 世界模型方向：V-JEPA 2、I-JEPA、DINO-WM、LeJEPA/SIGReg、JEPA-DNA、RegFormer。
- 单细胞方向：RegFormer（融合基因调控层级与 Mamba 的单细胞基础模型）、scPRINT-2、Geneformer/scGPT 的表征层评估。
- 衰老方向：单细胞时钟 sc-ImmuAging、scAgeClock、LLM 时钟，均依赖"细胞表征 + 线性探针"这一同一评测范式。
- **判断：世界模型方向的防坍塌机制（SIGReg、EMA 教师）与掩码隐空间预测，可直接替换单细胞基础模型的 MAE 式原始计数重构损失，这是目前无人占位的交叉。**

**2. 线性探针 / 冻结表征评测协议（世界模型 ↔ 单细胞基础模型 ↔ 衰老时钟）**
- 世界模型：ImageNet-1k 线性评估、ModelNet40/ScanObjectNN 线性探测。
- 单细胞：HVG/Harmony/scVI 基线对比、逐层评估（中间层在轨迹推断中优于最终层 31%）。
- 衰老：单细胞时钟"三者参照系不同、精度数字不宜直接横向比较"。
- **判断：三个方向都在用线性探针，但协议不统一；统一协议本身就是可发表贡献。**

**3. 过程级可验证奖励 / 中间步骤判定（科研智能体 ↔ 单细胞分析流程 ↔ 多组学基准）**
- 科研智能体：PURE 最小形式信用分配、TreeRL、BAVAR、R-Judge、VPRM 规则确定性验证器。
- 单细胞：Cell-o1 单细胞推理题式任务、BixBench 计算生物学任务、PerturbBench/PertEval-scFM 扰动预测基准。
- 衰老：ClockBase Agent 评估 43,602 个干预-对照比较。
- **判断：单细胞/组学流程天然有 ground-truth marker 与已知扰动，是构造过程奖励的最佳土壤，而科研智能体方向 2.4 仅 2 条证据、其中一篇 0 引用。**

**4. 生成式轨迹建模 / 世界模型式状态转移（人群健康 ↔ 世界模型 ↔ 衰老时钟）**
- 人群健康：ALADYNOULLI 贝叶斯生成框架、Delphi-2M、Foresight、EHR-MPC 数字孪生 + 模型预测控制。
- 世界模型：DINO-WM、Dreamer 式规划、Chreode 一步式细胞世界模型、Test-time 世界模型适配。
- 衰老：类器官/重编程时序多组学、LivAge 小鼠干预评估、ClockBase Agent 干预筛选。
- **判断：EHR-MPC 的"数字孪生 + 模型预测控制"骨架与 DINO-WM 的"预训练特征上建世界模型"骨架，可直接搬到类器官干预规划。**

**5. LLM 语义嵌入 / 文本-组学对齐（人群健康 ↔ 科研智能体 ↔ 单细胞）**
- 人群健康：GRASP 用 LLM 语义嵌入在英芬美超 100 万人上做跨编码体系风险预测；EHRAgent 自主代码生成。
- 科研智能体：ToolMaker 从论文代码自动生成工具、MatClaw 每步 API 调用准确率约 99%。
- 单细胞：GenePT 基于 ChatGPT 嵌入的基础模型、LLM 时钟以"细胞句子"微调。
- **判断：GRASP 已证明"编码语义统一不必依赖标准化"，这条结论对单细胞注释本体（cell ontology）与衰老表型本体同样适用。**

### 三、哪些方向的进展会直接改变另一方向的做法

1. **单细胞基础模型的"信任危机"直接决定衰老单细胞时钟的可信度。** scContam 检测到 PBMC 3k 与胰腺胰岛图谱中 80.4%/77.0% 细胞指纹与预训练语料显著重叠，MIA AUROC 随模型容量数据比从 0.494 升至 0.881——**如果衰老单细胞时钟建立在 Geneformer/scGPT 嵌入上，其"预测年龄"可能部分是在回忆预训练语料中的年龄标签。**

2. **世界模型的防坍塌机制会改写单细胞基础模型的训练目标。** 目前单细胞基础模型主流仍是 MAE 式重构或自回归，而世界模型方向已证明 SIGReg 各向同性高斯约束可在 60+ 架构上稳定训练；**若把重构损失换成隐空间预测 + SIGReg，可能同时解决单细胞基础模型的"零样本不如 HVG"问题。**

3. **科研智能体的过程奖励会重塑衰老干预筛选的证据等级。** ClockBase Agent 目前只能做"干预-对照比较"的终点判定，若引入 PURE/TreeRL 式步级信用分配，**可把"某干预降低生物年龄"拆解为可验证的中间步骤（如特定通路甲基化位点变化），直接回应"无法单独区分衰老与疾病特异效应"的困境。**

4. **人群健康的 PRS 个体一致性结论会波及衰老时钟的临床解读。** 171,095 人、48 个冠心病 PRS 显示群体表现相似但个体一致性差（ICC 与 Light κ 低）——**同理，多种衰老时钟在群体层面 MAE 相近，不代表对同一个体能给出一致结论；这是目前衰老时钟领域尚未系统检验的盲区。**

5. **世界模型方向"数据与基准 n=0"与单细胞方向"评测信任危机"合流，指向同一个机会：生物多模态表征的严格基准。**

## 联合行动建议

### 项目 1：跨模态隐空间预测的单细胞衰老表征（JEPA × 单细胞 × 衰老时钟）

**目标**：把 JEPA 式隐空间预测搬到 CITE-seq / 10x Multiome（RNA+ATAC）或类器官时序多组学，做跨模态掩码预测而非原始计数重构，在衰老标签上做线性探针评测。

**用到的方向与具体方法/数据**：
- 世界模型方向：I-JEPA 的联合嵌入预测架构、LeJEPA 的 SIGReg 各向同性高斯正则、V-JEPA 2 的规模化验证经验。
- 单细胞方向：RegFormer（融合基因调控层级与 Mamba）、scPRINT-2（350M 细胞预训练）、逐层评估发现"中间层在轨迹推断中优于最终层 31%"。
- 衰老方向：sc-ImmuAging（130 万 PBMC 五类免疫细胞）、scAgeClock（超 7000 万细胞）、hUSI 的 OCLR 通用衰老指数。
- 数据：公共 CITE-seq / 10x Multiome、PBMC scRNA-seq、类器官时序多组学（合作项目）。

**为什么现在**：世界模型方向 2.1 有 29 条证据、79% 近两年，方法组件现成；而科学迁移侧仅 7 条证据、median_citations=0，JEPA-DNA 刚出现说明这条路刚被打开。单细胞方向零样本评估显示 Geneformer/scGPT 多数不如 HVG/Harmony/scVI，**换损失函数是最直接的改进杠杆**。

**预期产出**：一个跨模态隐空间预测的表征模型 + 在衰老标签（细胞衰老评分、供体年龄回归）上的线性探针评测；可发表为方法论文或作为类器官项目的表征 backbone。

**主要风险**：单细胞数据的批次效应远强于图像，SIGReg 的各向同性假设可能不成立；需先在小规模 PBMC 上验证防坍塌是否有效。

---

### 项目 2：单细胞/组学分析流程的过程级可验证奖励（科研智能体 × 单细胞 × 衰老）

**目标**：把"聚类注释、批次校正、差异表达、衰老评分"每一步做成可自动判定的中间奖励，用 GRPO 训练一个带过程奖励的组学分析智能体，而非只看最终答案。

**用到的方向与具体方法/数据**：
- 科研智能体方向：PURE 最小形式信用分配（仅 30% 步数达可验证奖励方法相当性能）、TreeRL 的 EPTree 在线树搜索、BAVAR 的预算自适应验证（安全验证成功率 72.6%、成本降 45.5%）、VPRM 规则确定性验证器。
- 单细胞方向：Cell-o1 单细胞推理题式任务、BixBench 计算生物学任务、PerturbBench/PertEval-scFM 扰动预测基准。
- 衰老方向：ClockBase Agent 的 43,602 个干预-对照比较框架。
- 数据：公共 PBMC scRNA-seq、Perturb-seq、类器官多组学。

**为什么现在**：科研智能体方向 2.2 有 40 条证据但 CNS 占比仅 0.03、median_citations=0，说明过程奖励在通用域尚未定型；而 2.4 仅 2 条证据、其中一篇 0 引用，是整张表最空的一格。**生物域的过程可验证性天然更强（有 ground-truth marker、有已知扰动）。**

**预期产出**：带过程奖励的 GRPO 训练脚本 + 在 BixBench 上的对照结果；可直接用于类器官项目的自动化分析流水线。

**主要风险**：过程奖励的构造本身需要领域专家标注，成本可能高于预期；需先用规则确定性验证器（VPRM 路线）降低标注依赖。

---

### 项目 3：类器官时序多组学的世界模型式干预规划（世界模型 × 衰老 × 类器官合作项目）

**目标**：把类器官/细胞重编程的时序多组学当作可动作条件化的轨迹，用 DINO-WM 式"在预训练特征上建世界模型"或 Dreamer 式规划，预测干预（部分重编程因子、senolytics）后的状态。

**用到的方向与具体方法/数据**：
- 世界模型方向：DINO-WM（基于 DINOv2 特征的隐空间世界模型，368 引）、Dreamer 式规划、Chreode 一步式细胞世界模型、Test-time 世界模型适配、Sandwich-Residuals（冻结世界模型仅学预测器前后残差）。
- 衰老方向：LivAge 小鼠转录组干预评估、ClockBase Agent 干预筛选、二甲双胍干预食蟹猴多组学时钟。
- 人群健康方向：EHR-MPC 的"生成式数字孪生 + 模型预测控制"骨架（8 家医院 ICU 脓毒症队列）。
- 数据：公共单细胞扰动图谱（Tahoe-100M、Perturb-seq）、类器官时序多组学（合作项目）。

**为什么现在**：世界模型方向 2.1 有 79% 近两年、方法组件现成，但**没有任何一条证据把它用在衰老/类器官时序上**；同时 test-time 适配刚出现单条证据，说明"世界模型 + 测试时计算"是下一个接口。

**预期产出**：可做干预规划的潜空间动力学模型 + 湿实验可验证的预测假设；对合作项目是直接的方法学交付。

**主要风险**：类器官时序数据的样本量通常远小于视频/机器人数据，世界模型可能过拟合；需先用公共 Perturb-seq 做 demo 验证可行性。

### 项目 4：生物多模态表征的严格基准（世界模型 × 单细胞 × 衰老，抢占 n=0 空地）

**目标**：复现 MAE / DINO / 对比学习 / JEPA 四类范式在统一单细胞数据上的表现，控制预训练数据规模、批次效应、下游任务（细胞类型注释、扰动预测、衰老轨迹）。

**用到的方向与具体方法/数据**：
- 世界模型方向：**3 数据与基准 n=0**，是最大结构性缺口；5 评测板块 cns_share=0.5、病理 SSL 临床基准已拿到 78 引。
- 单细胞方向：scContam 的 MinHash 指纹 + MIA 审计框架（PBMC 3k 80.4%、胰腺胰岛 77.0% 重叠）、无参数线性流程在分布外任务上超越 TranscriptFormer、PerturbBench/PertEval-scFM。
- 衰老方向：ComputAgeBench（可靠时钟应能区分健康与衰老加速疾病个体）、LongevityBench（17 项任务、5 个生物数据域、18 个前沿 AI 系统）。
- 数据：公共单细胞图谱、Perturb-seq、衰老队列。

**为什么现在**：世界模型方向 **3 数据与基准 n=0**，单细胞方向只有一篇方法学批判（39 引）远未饱和，衰老方向 LongevityBench 刚提出"组学年龄预测最困难"。**三方向合流指向同一个空白，且这类工作引用寿命长。**

**预期产出**：开源基准 + 负面结果报告，直接支撑你自己后续的方法选择；可发表为 benchmark 论文。

**主要风险**：基准工作算力消耗大、周期长；建议先做单细胞单模态版本，再扩展到多模态。

### 项目 5：衰老时钟的个体一致性与预测偏差审计（衰老时钟 × 人群健康 × 科研智能体）

**目标**：把人群健康方向"48 个冠心病 PRS 个体一致性差"的检验框架，搬到衰老时钟上——检验多种衰老时钟在群体 MAE 相近时，对同一个体是否给出一致结论；同时复现"预测脑龄越大认知越好"式虚假关联。

**用到的方向与具体方法/数据**：
- 衰老方向：TranslAGE 评估 18 种时钟发现生物学可靠性低至中等且与技术重现性脱节；系统预测偏差（需约束优化回归框架校正）；rentosertib 2a 期试验中六种蛋白时钟一致预测治疗组生物年龄更低但无法区分衰老与疾病特异效应。
- 人群健康方向：171,095 人、48 个冠心病 PRS 的 ICC 与 Light κ 评估；ATM 在 282,957 + 211,908 人中识别 52 种共病异质性疾病。
- 科研智能体方向：R-Judge 风险判定框架（最佳模型 GPT-4o 仅 74.42%）、Strategic Verification 长程验证。
- 数据：UKB 蛋白组/代谢组、Generation Scotland DNAm 队列、公共 DNAm 数据集。

**为什么现在**：衰老方向已明确"跨队列泛化是普遍短板"、"系统预测偏差可能扭曲下游关联"，但**尚无系统性的个体一致性审计**；人群健康方向已有成熟方法可直接迁移。这是低成本、高引用潜力的批判性工作。

**预期产出**：一篇批判性 benchmark/审计论文 + 一套可复用的时钟一致性评估工具。

**主要风险**：需要访问多个受限队列（UKB、Generation Scotland），数据申请周期长；建议先用公开 DNAm 数据集做 demo。

## 不要做的事

**1. 不要再造一个通用 JEPA 变体或通用单细胞基础模型。**
依据：世界模型方向 2.1 已有 29 条证据、79% 近两年，V-JEPA 2 单篇 725 引，但 **cns_share=0.0、median_citations=0**，说明方法未收敛且大量新工作尚未被验证；单细胞方向已有 Geneformer、scGPT、CellFM、SCimilarity、scPRINT-2 等，且零样本评估显示**多数不如 HVG/Harmony/scVI 等简单基线**，数据缩放定律在 2220 万细胞、400 个模型、6400 次实验上被证伪。**纯方法增量会迅速拥挤，且窗口期仅剩 6–12 个月。**

**2. 不要追 RLVR/GRPO 的纯算法增量。**
依据：科研智能体方向 2.2 已有 40 条证据、recent_share 0.95，DeepSeekMath、DeepSeek-R1、Kimi k1.5 已把范式推到 CNS 级；更关键的是，**虚假奖励与单样本 RLVR 实验显示随机甚至负相关奖励仍使 MATH-500 提升 21.4 点（接近真实奖励 29.1 点），单样本 RLVR 使 MATH500 从 36.0% 升至 73.6%**，提示增益可能主要来自策略梯度对既有行为的放大而非能力扩展。**若 [84] 的质疑成立，许多"能力提升"叙事会被重估。**

**3. 不要用单一队列的蛋白组-疾病关联结果直接宣称临床可用性。**
依据：人群健康方向 UK Biobank 53,026 人、2,920 种蛋白关联 406 种现患与 660 种新发疾病、183 种疾病 AUC>0.80，但**该结果在同一人群、中位随访 14.8 年、缺乏外部验证条件下取得**；Foresight-England 虽有 243M 参数、约 6100 万人训练数据，却因 NHS England 暂停数据访问导致定量结果不可得；NOAH 与 MiGHT-EHR 均主要基于 MIMIC。**跨医疗体系泛化性普遍未验证，是系统性短板而非个别问题。**
