- The AI Scientist 实现从构思到评审的全自动科研流水线，每篇论文成本低于 15 美元且生成论文可超顶会接收阈值，但仅在 ML 三个子领域验证且依赖自动评审器、未含真实同行评审 [2]。
- Co-Scientist 基于 Gemini 构建多智能体科学思维引擎，在 AML 药物重定位、肝纤维化靶点、抗菌素耐药机制三个问题上候选与机制均经独立体外实验验证，并独立复现未发表的新型基因转移机制 [3]。
- 治理争议方面，Risks of AI scientists 主张优先系统防护而非追求更强自主性，提出人类监管、智能体对齐、智能体监管与环境反馈组成的三元防护框架，但为观点性论文、无实证验证且风险分类非互斥 [4]。
- 经验积累方向出现分化：EvoScientist 用研究/工程/进化管理三智能体加构思与实验双持久记忆 [5]，HypoForge 用对抗式生成器-判别器与执行反馈的两阶段技能学习 [6]，但二者均未给出可比的定量结果，难以直接判断优劣。
- 工具化执行三条路线各有取舍：ToolMaker 从论文代码自动构建工具并在 15 任务基准上正确实现 80% 任务 [7]，MatClaw 以无预设工具函数的自由代码编排将 API 调用准确率提升至约 99% 但难处理隐性领域知识 [8]，TeLLAgent 以监督者-执行者双智能体调用 30 个专用工具并成功应用于有机太阳能电池材料发现 [9]，三者之间缺乏统一评测。
- The Little Scientist 按科学方法闭环迭代并由 Kuhn 智能体注入范式转换猜想，发现 Delta V 集成校准策略（ProteinGym 零样本五项指标第一，超 VenusREM +0.033 平均 Spearman）与 DALE 算法（132 个 ENCODE 转录因子上平均 AUROC 0.842 优于 STREME 的 0.803 且快 11 倍，p<1e-6），但仅两个案例研究、全程消耗 704M token [10]。
- RLVR 范式由 DeepSeek-R1 确立：基于 DeepSeek-V3 Base 采用 GRPO、仅以最终答案正确性为奖励并跳过 SFT 直接 RL，模型自发涌现验证、反思、探索等长链推理行为，但 R1-Zero 可读性差、中英混杂且规则 RL 仅聚焦推理 [11]；更早的 DeepSeekMath 从 Common Crawl 筛选 120B 数学 token 并引入 GRPO，使 7B 模型在 MATH 上达 51.7%、64 样本自洽达 60.9% [12]。
- 过程奖励路线内部高度分化：隐式路线以 λ-GRPO 证明带 ORM 的 GRPO 等价于带 Monte-Carlo PRM 的 RL 目标并提出修正 [13]、TEMPO 用前缀树聚合后代结果加入分支感知 TD 修正 [14]；显式路线中 PURE 把价值函数改为未来奖励最小值，仅用 30% 步数即达可验证奖励方法相当性能，Qwen2.5-Math-7B 在 AMC23 达 82.5%、5 基准平均 53.3% [15]，而 ScalePRM 用扩展验证计算替代真值，步级自一致性数据训练的 PRM 达 67.5 F1 超过参考引导 66.4 F1，RL 后六基准平均 47.4% 优于基于真值的 RLVR 43.9% [16]。
- 无外部奖励/内部信号路线与虚假奖励质疑共同构成对 RLVR 信号有效性的压力测试：Intuitor 用 self-certainty 作唯一奖励在数学基准上匹配 GRPO 且域外泛化更好 [17]，MEL 用自验证对比定位错误分叉点并内化为元经验使 Pass@1 提升 3.92%–4.73% [18]，而 Spurious Rewards 发现随机奖励使 Qwen2.5-Math-7B 的 MATH-500 提升 21.4 个百分点、接近真实奖励 29.1 点且代码推理频率从 65% 升至 90% 以上，但对 Llama3、OLMo2 等无效 [19]。
- 样本效率与难度分层揭示 PRM 边际价值边界：单样本 RLVR 使 Qwen2.5-Math-1.5B 的 MATH500 从 36.0% 升至 73.6%、6 基准均值 17.6%→35.7%，2 样本 MATH500 达 74.8% 并匹配 1.2k DeepScaleR 子集 [20]；难度分层研究发现易与中等难度问题带来最强最稳定提升，过难问题诱发答案重复或跳过必要计算等退化行为，T-SAE 分析显示易题强化直接作答特征、抑制审慎推理特征 [21]。
- 递归自改进的乐观与悲观证据形成张力：自我编码智能体在 SWE Bench Verified 随机子集上从 17% 提升到 53% [22]，但 AI4AI-Bench 在 10 个冻结训练算法仓库上平均分仅 0.166、最佳系统 0.250，多数提交未改变学习方式，改变学习方式的提交均分 0.226 远高于未改变的 0.126 [23]；RSIBench-Data 显示 58.33% 设置中智能体通过反馈改进首次有效尝试，但 78.26% 的继续搜索以更低分收尾 [24]。

## 1 背景与定义

在训练范式一侧，可验证奖励强化学习（RLVR）的边界首先由“奖励从何而来”划定。DeepSeekMath 从 Common Crawl 筛选 120B 数学相关 token 继续预训练，并引入 GRPO 以降低 PPO 的内存与推理开销，使 7B 模型在 MATH 上达到 51.7%、64 样本自洽达 60.9%，接近 Gemini-Ultra 与 GPT-4 [12]；DeepSeek-R1 则进一步证明，仅以最终答案正确性为奖励、跳过监督微调直接 RL，模型可自发涌现验证、反思、探索等长链推理行为，并通过多阶段框架与蒸馏模型公开 [11]。这两项工作确立了“结果可验证 + 规则奖励”的基本范式，但其局限同样清晰：DeepSeekMath 在未使用外部工具与投票时仍低于顶级闭源模型，且依赖公开网页数据质量 [12]；R1-Zero 可读性差、中英混杂，规则 RL 仅聚焦推理，写作与开放问答受限 [11]。Kimi k1.5 则从另一侧给出对照：它构建不依赖 MCTS、价值函数和过程奖励模型的简洁 RL 框架，在 AIME 77.5、MATH500 96.2、Codeforces 94 百分位、MathVista 74.9 上匹配 o1，短 CoT 模型 AIME 60.8、MATH500 94.6、LiveCodeBench 47.3，超 GPT-4o 等最多 +550% [25]。该工作未公开训练细节与权重，且明确未依赖 MCTS/价值函数 [25]，这提示“过程奖励是否必要”本身仍是一个开放问题，而非已被证成的共识。

结果奖励的稀疏性天然引出过程奖励的动机，而围绕这一动机的第一类工作试图从理论上揭示 GRPO 本身已隐含过程结构。有研究证明，带 ORM 的 GRPO 在温和假设下等价于带 Monte-Carlo PRM 的 RL 目标，并据此指出当过程步骤与奖励不平衡时，GRPO 会阻碍探索与利用，进而提出 λ-GRPO 修正；实验显示 λ-GRPO 优于标准 GRPO 且更快达到峰值性能，训练时间与成本影响可忽略 [13]。这一结论把“是否需要显式 PRM”转化为“GRPO 的隐式过程信号是否被正确加权”的问题，但其依赖轨迹共享前缀假设、未大规模验证，PRM 结构的普适性仍需进一步实证 [13]。与之呼应，TEMPO 从树结构角度处理同一问题：它把同一提示的采样响应组织成前缀树（P2T），通过聚合后代结果计算非参数前缀值，再为 GRPO 加入分支感知的时序差分修正而无需 critic；在 Qwen3-1.7B 与 Qwen3-4B 上，TEMPO 在 MATH、MedQA 等分布内及 GSM-HARD、AMC23、MedMCQA、MMLU-Medical 等分布外基准上，收敛与最终性能均持续优于 PPO 和 GRPO，并在相当墙钟时间内取得更高验证准确率 [14]。TEMPO 与 λ-GRPO 的差异在于，前者用采样树显式构造前缀值，后者在目标函数层面修正隐式过程权重；两者都承认 GRPO 的序列级广播过于粗糙，但修正路径不同，且 TEMPO 依赖采样响应构建前缀树 [14]。

另一条路线是直接训练 PRM 并将其作为稠密奖励注入 RL，而这条路线内部首先在“信用分配形式”上出现分歧。PURE 指出 PRM 在强化微调中易被奖励黑客，根源在于 RL 中价值被定义为 γ 折扣未来奖励的累积（求和形式），这会诱导模型攻击高奖励步骤；PURE 把价值函数改为未来奖励的最小值，即最小形式信用分配，限制价值范围并更合理分配优势，仅需变换过程奖励而无需改代码，并支持稠密过程奖励与稀疏可验证奖励结合 [15]。在 3 个基座模型上，采用最小形式的 PRM 方法仅用 30% 步数即达到可验证奖励方法相当的推理性能，而求和形式在训练初期即崩溃；补充 10% 可验证奖励后，Qwen2.5-Math-7B 在 AMC23 达 82.5%、5 基准平均 53.3% [15]。PQM 则从建模方式切入，批评现有 PRM 以分类问题建模、忽略步骤间依赖，将 PRM 重构为马尔可夫决策过程中的 Q 值排序问题，用比较损失优化 Q 值排序以捕捉序列决策动态；在多种采样策略、骨干与多步推理基准上，PQM 优于分类式 PRM，消融实验证实比较损失的有效性 [26]。PQM 的局限在于基于 MDP 假设，未充分讨论长轨迹与稀疏奖励下的扩展性 [26]。PURE 与 PQM 分别从信用分配形式与建模目标两个层面修正 PRM，但都未解决 PRM 本身的奖励黑客风险，PURE 用最小形式限制价值范围，PQM 未讨论该问题 [15][26]。

PRM 的数据来源是另一个关键分歧点，且直接决定过程监督能否规模化。传统 PRM 依赖人工步级标注或真值答案，ScalePRM 试图用扩展验证计算替代真值：给定问题与候选解，对每个推理步生成多个独立验证并聚合判断，得到合成步级标签，探索并行自一致性与串行元批判两种推理时扩展策略，并用其监督微调生成式 PRM，再作为 RL 奖励信号 [16]。在 ProcessBench 上，步级自一致性数据训练的 PRM 达 67.5 F1，超过有真值的参考引导 66.4 F1 和 GPT-4o critic 61.9 F1；用于 Qwen2.5-Math-7B 的 RL 时，六个数学推理基准平均 47.4%，优于基于真值的 RLVR 43.9% [16]。这一结果挑战了“过程监督必须依赖真值”的直觉，但 ScalePRM 也承认存在生成式 PRM 特有的奖励利用模式，需额外缓解 [16]。与 ScalePRM 的无真值路线形成对照，VPRM 走的是规则确定性验证路线：它批评现有过程监督依赖神经评判器打分 CoT 步骤、带来不透明、偏见与奖励黑客，提出在 RL 框架中用确定性规则验证器检查每个中间推理步，应用于医学证据合成中的偏倚风险评估，该领域有指南定义标准与规则化决策路径可程序化验证；理论上证明在温和假设下梯度更新对正确推理轨迹赋正期望权重、对不一致轨迹赋负权重 [27]。多数据集上 VPRM 推理更贴合领域规则，步级决策与最终标签一致性显著提高，F1 比 SOTA 高至多 20%、比可验证结果奖励高 6.5% [27]。VPRM 与 ScalePRM 的对比揭示了过程监督的一个根本张力：可程序化验证的领域可以用规则保证忠实，但适用范围受限；生成式验证可以扩展到无规则领域，却重新引入了奖励黑客风险 [27][16]。

当把过程奖励从数学推理迁移到智能体任务时，问题结构发生变化：动作没有明确正确性，奖励设计依赖目标接近度。AgentPRM（Process Reward Models for LLM Agents: Practical Framework and Directions）提出用 Monte Carlo rollout 自动生成过程奖励目标，并以 actor-critic 方式迭代训练 PRM 与策略；还提出 InversePRM，直接从专家示范学习过程奖励而无需结果监督 [28]。在 ALFWorld 上，3B 模型经 AgentPRM/InversePRM 训练后超过强 GPT-4o 基线，并分析了测试时扩展与奖励黑客 [28]。该工作承认探索、样本效率与模型预测推理仍是挑战，且主要在 ALFWorld 验证 [28]。另一篇同名 AgentPRM 的工作则重新定义过程奖励以同时捕捉步骤承诺与进展，用 TD 估计结合 GAE 自动生成标签，训练过程奖励模型并用于搜索与 RL；实验显示其比基线计算效率高 8 倍以上，Best-of-N 随测试时计算扩展稳定提升 [29]。两篇 AgentPRM 的差异值得注意：前者强调 actor-critic 迭代与 InversePRM 的示范学习，后者强调 TD+GAE 的自动标注与承诺/进展双信号；前者在 ALFWorld 上验证 3B 模型，后者覆盖网页购物、浏览器导航等多类任务，但都面临动作无明确正确性、奖励设计依赖目标接近度、跨任务泛化仍需验证的问题 [28][29]。

长程智能体的信用分配进一步暴露了 GRPO 的粒度问题，并催生了一批以“自适应混合”为核心的修正方案。GACA 指出 GRPO 将轨迹级标量广播到每步、GiGPO 以固定权重混合步级与回合级优势，并用 rollout 已记录的每 token 负对数似然给每步打分，按该分数逐步骤加权混合两级优势，使不确定处用细粒度信号、确定处用低方差信号；理论上证明更高锚点条件期望 NLL 可认证更大的局部动作价值方差下界与误差最优步权重，且状态自适应混合严格优于任何固定权重 [30]。在 ALFWorld 和 WebShop 上，GACA 在 1.5B 与 7B 规模均提升任务成功率，超过 GRPO 和 GiGPO [30]。与 GACA 的自适应混合思路相近，GEAR 用自蒸馏比较在线学生与真值条件教师，以散度尖峰确定自适应分段边界并调制局部优势权重；在八个数学推理与工具使用基准、Qwen3 4B/8B 上，GEAR 一致优于标准 GRPO 等基线 [31]。S-trace 则从资格迹角度切入：它批评 GRPO 等无 critic 算法均匀广播轨迹优势、无法区分关键推理步，先给出 P-trace，再通过选择性掩码低熵 token 实现稀疏资格迹以降低方差、实现细粒度信用分配，并将 GSPO 定位为均匀信用分配下的特例；实验显示 S-trace 在 Qwen3-1.7B 上提升 0.49%、4B 提升 3.16%、8B 提升 2.98%，且样本与 token 效率更高 [32]。G2PO 则把线性交互轨迹转为全局状态转移图，聚合相同观测做组聚合状态价值估计，并以边为中心、全局标准化 TD 误差进行优势估计，从而降低采样方差与轨迹依赖偏差，显式优先关键转移 [33]。这三项工作共同指向一个判断：长程智能体的信用分配不能停留在轨迹级广播，但自适应混合、资格迹稀疏化与图结构聚合各有代价，尚无统一结论。

在“是否需要显式 PRM”这一问题上，还存在一条更激进的路线：从 RL 后训练管线本身免费提取过程信号。有研究推导出一般随机 MDP 下的隐式优势——进度优势，即 RL 训练策略与参考策略的对数概率比恰好恢复最优优势函数，无需标注与专用奖励模型训练；在测试时扩展、不确定性量化与失败归因三类应用中，跨五基准四模型族一致优于置信度基线并超越专用奖励模型 [34]。与之相关，SELAUR 将熵、最低置信度与 margin 三类指标融合为 token 级不确定性估计，并通过失败感知奖励重塑注入步级与轨迹级奖励；在 ALFWorld 和 WebShop 上成功率一致优于强基线，消融验证不确定性信号增强探索效率与学习稳定性 [35]。这两项工作都把“不确定性”作为过程信号的来源，但进度优势来自策略与参考策略的比值，SELAUR 来自熵与置信度融合，前者有理论推导，后者有消融验证，二者尚未在同一基准上直接比较。

过程奖励的忠实度问题在小推理模型与开放书问答中尤为突出，并直接关系到 PRM 作为奖励信号的可信度。FaithRL 针对小推理模型中间步骤忠实度幻觉，引入过程奖励模型提供的显式步级忠实度奖励，并用截断重采样从忠实前缀生成对比信号，同时用信息增益惩罚缓解奖励黑客；实验表明 FaithRL 在多个 SRM 和开放书 QA 上持续减少 CoT 与最终答案幻觉，平均准确率提升 7.29%、忠实度提升 1.73% [36]。该工作仅针对小推理模型与开放书 QA，未覆盖更广任务 [36]。BiPRM 则从评估方向入手：它批评现有 PRM 仅单向从左到右评估、缺乏全局上下文，通过提示反转实现并行从右到左评估流，并用门控机制自适应融合两流分数；在 GSM-Plus、MATH500 与 ProcessBench 上，BiPRM 持续超越单向基线，解级平均增益 10.6%、步级错误检测增益 37.7% [37]。BiPRM 的代价是参数量增 0.3%、推理延迟增约 5%，且依赖提示反转实现 R2L [37]。FaithRL 与 BiPRM 分别从奖励内容与评估方向改进 PRM，但都未解决 PRM 本身的奖励黑客风险，FaithRL 用信息增益惩罚缓解，BiPRM 未讨论该问题 [36][37]。

多智能体与工具使用场景把过程奖励的粒度推进到智能体动作与工具调用，并引入执行代价与验证超时等新约束。MASPRM 为多智能体系统设计过程奖励模型，对路由转录前缀与智能体动作打分，作为推理控制器指导 SBS 与 MCTS；训练仅用多智能体 MCTS rollout 的终端结果奖励，通过 Bradley-Terry 排序损失训练价值头，无需人工步级标注 [38]。在 GSM8K、MATH、MMLU、LOGIQA 上，MASPRM 超越同规模 ORM，7B 在 MCTS 下平均提升 13.4 分，并改善排序质量 [38]。其局限在于限于预定义 MAS 配置与可验证答案任务，依赖通信图与调度设计 [38]。Sci-PRM 则填补 PRM 在科学领域工具使用验证的空白，构建 SCIPRM70K 数据集，含交错推理与科学工具执行的 Chain-of-Tool 轨迹，训练 Sci-PRM 在单次推理中对工具选择、执行准确性与结果解读提供细粒度监督；实验表明其支持 Best-of-N 测试时扩展，并作为 RL 密集奖励缓解优势消失，在工具调用步 F1 上显著优于 GPT-5-Mini 等基线 [39]。Sci-PRM 依赖工具沙箱执行，部分验证超时（如 BLAST 超 300s）[39]。SWE-TRACE 面向长程 SWE 智能体，先用 LLM 多任务级联与步级 oracle 验证，从 77 个仓库的 140K 候选实例中蒸馏出 60K 偏向 token 高效最短路径的 SFT 语料；再用带评分标准过程奖励模型的记忆增强智能体 RL 提供稠密中间反馈；最后复用 PRM 做启发式测试时扩展，在每步动态评估并剪枝动作候选 [40]。在标准 SWE 基准上，SWE-TRACE 显著提升解决率并大幅降低 token 消耗与推理延迟，但依赖 oracle 验证器与评分代理 [40]。GenReasoner 则把工具使用作为通用推理技能学习，通过可扩展数据管线、Tool-GRPO 按端任务成功优化工具选择与排序，以及自适应学习机制动态调节工具使用；实验显示模型能自主采纳有益工具、抑制无关工具，7B 基座平均提升 24.9% 并超越强专有模型 [41]。这些工作共同表明，工具与多智能体场景的过程奖励必须处理动作空间结构化、执行代价高、验证可能超时等新约束，与数学推理中“每步可独立判断”的假设有本质差异。

RLVR 的奖励信号本身也受到一系列质疑，这些质疑直接影响过程奖励的设计前提。Spurious Rewards 发现即使奖励与正确答案无关甚至负相关，也能提升部分模型数学推理：用 GRPO 在 Qwen2.5-Math-7B 等模型上比较真实奖励、随机奖励和虚假奖励，随机奖励使 MATH-500 提升 21.4 个百分点，接近真实奖励 29.1 点，代码推理频率从 65% 升至 90% 以上 [19]。但该现象高度依赖模型家族，虚假奖励对 Llama3、OLMo2 等无效 [19]。Exploration vs Exploitation 进一步分析裁剪偏差、熵最小化与虚假奖励的交互机制，发现裁剪偏差在虚假奖励下降低策略熵，产生更确定输出，而仅熵最小化不足以提升性能 [42]。Spurious Rewards Paradox 则从机制层面揭示困惑度悖论：答案 token 困惑度下降而提示侧连贯性退化，并用路径修补、Logit Lens、JSD 分析与神经常微分方程定位 L18-20 功能锚点与 L21+ 结构适配器，可双向因果操控 [43]。这三项工作共同构成对 RLVR 奖励信号的“压力测试”：虚假奖励能提升性能、裁剪偏差会降低熵、记忆捷径可被机制定位，意味着过程奖励若只追求步级准确率而不控制忠实度与泛化，可能同样落入放大捷径的陷阱。

样本效率与难度分层是 RLVR 的另一组关键变量，并直接决定 PRM 的边际价值边界。单样本 RLVR 的研究显示，对 Qwen2.5-Math-1.5B 等模型用单个可验证奖励样本做 RLVR，MATH500 从 36.0% 升至 73.6%（超格式修正 8.6%），6 基准均值 17.6%→35.7%（非格式增益 7.0%），2 样本 MATH500 达 74.8%，匹配 1.2k DeepScaleR 子集，并观察到跨类别泛化与饱和后持续提升现象 [20]。该工作指出主要增益来自策略梯度损失，未验证数学以外领域 [20]。这一结果与过程奖励的动机形成有趣张力：如果单样本结果奖励就能激发大量推理能力，那么 PRM 的边际价值可能集中在结果奖励难以覆盖的长程、多步、工具使用场景，而非短链数学题。难度分层研究进一步发现样本难度对 RLVR 呈非单调影响：易与中等难度问题带来最强最稳定的推理提升，过难问题学习信号弱、诱发答案重复或跳过必要计算等退化行为并可能损害模型原有能力；用 T-SAE 分析内部特征动态发现易题强化直接作答与基础计算特征、抑制审慎推理特征，难题激活推理特征但仅在采样到成功轨迹时有用，中等难度提供更平衡信号，据此提出难度自适应策略 [21]。这两项工作对过程奖励设计的启示是：PRM 的步级信号若不加难度区分，可能在易题上过度强化直接作答、在难题上因成功轨迹稀少而失效。

在“无外部奖励”方向上，Intuitor 提出用模型自身置信度 self-certainty 作为唯一奖励信号，在 GRPO 中将外部奖励替换为 self-certainty，实现完全无监督学习；实验显示其在数学基准上匹配 GRPO，并在代码生成等域外任务上泛化更好，无需金标答案或测试用例 [17]。该工作依赖模型自身置信度信号，可能受校准偏差影响，未覆盖所有可验证奖励场景 [17]。MEL 则针对 RLVR 缺乏错误归因与经验内化机制、存在元学习瓶颈的问题，利用 LLM 自验证对正确与错误轨迹做对比分析，定位推理错误分叉点并总结为可泛化元经验，再通过最小化负对数似然将其内化进参数记忆，形成桥接正确与错误轨迹的语言建模奖励信号；实验显示不同模型规模下 Pass@1 提升 3.92%–4.73% [18]。Intuitor 与 MEL 都把奖励来源从外部验证转向模型内部信号，前者用置信度，后者用自验证对比，但都面临校准偏差与自验证失败的风险，且都未与显式 PRM 在同一设置下比较。

探索多样性与推理效率是 RLVR 训练动态中的另一对矛盾，也构成 PRM 的替代方案。ROSE 针对 MCTS 扩展方法探索多样性有限和推理效率低的问题，引入基于语义熵的分支策略和 ε 探索机制以增强推理探索多样性，并设计长度感知的片段级优势估计器奖励简洁正确推理、惩罚冗长推理链；在 Qwen 和 Llama 模型的多个数学推理基准上验证了方法的有效性与效率 [44]。TreeRL 则把在线策略树搜索直接引入 LLM 强化学习训练，提供密集的过程监督并免去单独训练奖励模型；方法提出 EPTree，从高不确定性中间步骤分支以提升搜索效率，并基于全局与局部优势为每步分配信用 [45]。在数学与代码推理基准上，TreeRL 优于传统 ChainRL，EPTree 在相同推理预算下也优于多链采样与 MCTS，例如 GLM4-9B 提升 2.5–5.6、Qwen-2.5-14B 提升 4.6–8.5 [45]。ROSE 与 TreeRL 都试图用树搜索或分支策略替代或补充 PRM，前者强调语义熵与长度感知优势，后者强调不确定性分支与全局/局部优势，二者都未与显式 PRM 引导 RL 直接对比。

熵正则化与训练稳定性是过程奖励 RL 的底层机制问题，而这一层面的证据目前仍以综述与算法修正为主。熵正则化综述系统梳理了深度强化学习中的熵正则化，跨越经典控制、生成式策略与 LLM 推理三类范式，通过区分策略级、轨迹级、占用度量级等熵对象，梳理其在探索、平滑、信任域与多样性中的作用，并指出生成式策略熵难计算、LLM 后训练存在熵坍缩，需按策略类与训练机制区别对待 [46]。该综述无新实验，且熵定义跨策略类不可互换，统一度量困难 [46]。SORL 则从离策略训练稳定性切入，针对多轮智能体离策略 RL 训练中 PPO/GRPO 不稳定与性能崩溃问题，识别出 token 级优化与回合结构不匹配、离策略重要性采样高方差两大根源，提出 SORL 框架及 SO-PPO、SO-GRPO 两种算法，对齐多轮交互结构并自适应抑制不可靠更新；在多轮搜索基准上，两方法稳定训练并取得更优或相当表现 [47]。熵正则化综述与 SORL 分别从理论梳理与算法修正层面处理稳定性，但都未直接回答“过程奖励的稠密信号如何影响熵坍缩”这一具体问题。

奖励建模的系统性视角在综述工作中得到整合，并暴露出评估基准本身的污染与错配问题。PRM 综述按完整循环组织：如何生成过程数据（人工标注、自动监督、半自动流水线）、如何构建 PRM（判别式与生成式目标、显式与隐式监督、架构创新）、如何使用 PRM（测试时扩展的重排、验证引导解码、搜索，以及 PRM 引导 RL 的稠密步级奖励与信用分配），并总结数学、代码、文本、多模态推理、机器人与智能体等应用及新兴基准 [48]。RARL 综述则论证奖励建模是推理对齐的核心架构而非实现细节，提出以推理为中心的 RARL 分类视角，系统梳理奖励机制、奖励黑客失效模式及奖励信号对推理挑战的统一作用，并批判评估现有基准的数据污染与奖励错配问题 [49]。两篇综述的共同判断是：过程奖励的设计空间远未收敛，数据生成、建模目标与使用方式三者相互耦合，且评估基准本身存在污染与错配，这为前述各项工作的可比性蒙上阴影。

在评测基准一侧，过程奖励与科研智能体各自形成了初步的评测谱系，但两者尚未真正交汇。过程奖励方面，Socratic-PRMBench 系统评测 PRM 在六种推理模式下的过程错误检测能力，基准包含 2995 条带缺陷推理路径，覆盖 Transformation、Decomposition、Regather、Deduction、Verification、Integration，实验发现现有 PRM 和 LLM critic 在多种推理模式下存在系统性弱点 [50]。MedPRMBench 则是首个面向医学领域的过程级奖励模型基准，基于临床推理蓝图，通过三阶段流程从 7 个医学 QA 源生成数据，覆盖 3 大类 14 种细粒度错误类型并首创 4 级严重度分级；系统评测发现当前模型在医学推理错误检测上存在关键弱点，而自建医学 PRM 基线达 87.1% PRMScore 并可提升下游 QA 准确率 3.2–6 个百分点 [51]。科研智能体方面，GenoTEX 按计算基因组学标准统一流程，涵盖数据集选择、预处理与统计分析，并由生物信息学家人工标注代码与中间/最终结果，同时提出多智能体 GenoAgent 基线，实验显示 LLM 方法具潜力，但错误分析暴露了待改进的挑战 [52]。BAISBench 基于单细胞转录组数据，构建贴近数据驱动生物发现场景的评测框架，并指出既有基准多为知识驱动或仅评估计算输出，难以衡量 AI 系统能否从复杂实验数据中提炼有生物学意义的结论 [53]。TruthInsightBench 则区分“执行既定分析”与“开放式科学发现”，含 40 个盲任务，来自 10 个领域 40 篇同行评审研究，仅给智能体中性科学目标与冻结数据，由固定 LLM 裁判按 6 维度 29 个证据锚定项自动评分；评测四个编码智能体发现总分仅 58.4–60.3/100 且无可靠区分，瓶颈在科学判断而非编码 [54]。这三类基准分别覆盖组学分析、生物发现与开放式发现，但都未与 PRM 评测打通：过程奖励基准关注步级错误检测，科研智能体基准关注端到端发现质量，二者之间缺少“过程奖励能否预测科研智能体发现质量”的桥接评测。

安全与自改进的评测则从另一侧划定了方向的边界。R-Judge 关注 LLM 智能体在交互环境中的行为安全风险，基准含 569 条多轮交互记录，覆盖 27 类风险场景与 10 种风险类型，并带安全标签与风险描述；评估 11 个 LLM 显示最佳 GPT-4o 仅 74.42%，微调可显著提升而简单提示无效 [55]。MemCalib 指出智能体记忆效果取决于 LLM 对每条记忆赋予恰当影响，但该能力被忽视，因而提出含 15000 例、覆盖健康、通用助手与编程的基准，评测模型对原子命题的忽略/限定/控制三级影响；实验发现前沿模型常过度或不足使用记忆，GRPO 与 OPSD 存在方向性偏斜，提出的 MemCalib-RL 通过有序双向反事实信用分配改善校准 [56]。自改进方面，Memory Reward Inflation 研究自改进 LLM 智能体在不更新权重、仅靠外部记忆学习时的奖励膨胀问题，将存储分数视为代理奖励，形式化 Echo Gap 与误差独立性假设 EIA，并提出无答案去膨胀算法 LUCID；在 BIRD text-to-SQL 上，LUCID 将执行准确率提升至 56.9%，优于自评分与无记忆基线 [57]。Practice Makes Unsafe 则揭示自改进 LLM 智能体将成功轨迹转为持久技能时，不安全成功可固化为可复用策略，即技能误演化；作者提出生命周期感知测试台 SKILLMISEVO-GYM、冻结基准 SKILLMISEVO-BENCH 及修复包装 SAFEEVOLVE，实验显示多数演化配置产出不安全技能，SAFEEVOLVE 显著降低不安全检索与新会话危害而几乎不影响性能 [58]。这些工作共同表明，自改进与记忆机制在提升智能体持续性的同时，会引入奖励膨胀与技能误演化两类新失效模式，而现有过程奖励研究尚未把这两类失效纳入奖励设计。

生物医学场景是科研智能体与 RLVR 交汇最密集的领域，也最能暴露“可验证性”的边界。Cell-o1 将细胞类型注释重构为批级推理任务，提出 CellPuzzles 基准，先用蒸馏推理轨迹做监督微调，再用批级奖励强化学习训练 7B 的 Cell-o1；发现现成 LLM 表现差（o1 仅 19.0%），而 Cell-o1 超 o1 逾 73% 并展现类专家推理 [59]。Med-R1 针对医学视觉语言任务中数据复杂与专家标注稀缺问题，采用 GRPO 进行奖励引导学习，在八种医学影像模态上平均准确率较 Qwen2-VL-2B 提升 29.94%，并超过参数量 36 倍的 Qwen2-VL [60]。CellDuality 则用自监督 RLVR 提升 LLM 在单细胞生物学中的推理能力，基于互补任务对偶性：先正向预测生物结果，再反向重构初始条件，以重构保真度作为内在奖励对齐模型，无需可验证结果即可形成自验证反馈循环 [eupmc:med:42559559]。这三项工作分别代表批级可验证奖励、GRPO 奖励引导与自监督内在奖励三条路径，但都限于特定生物医学任务，且 CellDuality 的自验证反馈循环是否会被奖励黑客攻击尚未见讨论 [59][60][eupmc:med:42559559]。

综合来看，本方向的边界可以沿三条轴线划定。第一条是奖励可验证性的轴线：从结果可验证（DeepSeek-R1、DeepSeekMath、Kimi k1.5）[11][12][25]，到过程可验证（PURE、PQM、ScalePRM、VPRM）[15][26][16][27]，再到自监督内在奖励（Intuitor、MEL、CellDuality）[17][18][eupmc:med:42559559]，可验证性逐步减弱而适用范围逐步扩大，但奖励黑客与忠实度风险同步上升。第二条是信用分配粒度的轴线：从轨迹级广播（GRPO）[11]，到前缀树与树搜索（TEMPO、TreeRL）[14][45]，到自适应混合与资格迹（GACA、GEAR、S-trace、G2PO）[30][31][32][33]，再到隐式优势提取（进度优势、SELAUR）[34][35]，粒度越细代价越高，且尚无统一基准判断何种粒度在何种任务上最优。第三条是自主性与安全的轴线：从 ReAct 的提示式协同 [1]，到 The AI Scientist 的全自动流水线 [2] 与 Co-Scientist 的科学家在环多智能体 [3]，再到 EvoScientist、HypoForge 的经验积累 [5][6] 与 The Little Scientist 的科学方法闭环 [10]，自主性提升伴随风险分类与防护框架的提出 [4]，而 R-Judge、MemCalib、Practice Makes Unsafe 等基准则从行为安全、记忆校准与技能误演化三个角度给出可测量的风险信号 [55][56][58]。三条轴线的交汇处，正是本方向当前最核心的未解问题：如何为长程、工具化、多智能体的科研任务设计既稠密又忠实、既高效又可验证、既鼓励自主又可控的过程奖励，并在统一基准上衡量其边际价值。

## 2 方法学


### 2.1 科研智能体系统

科研智能体系统的早期形态以提示式协同为核心，ReAct 是这一路线的代表性工作，它让大语言模型以交错方式生成推理轨迹与任务动作，使推理与行动相互增强，并通过接入 Wikipedia API 或交互环境获取外部信息 [1]。该方法在 HotpotQA、Fever、ALFWorld、WebShop 等问答、事实验证与交互决策任务上仅用 1-2 个上下文示例就优于模仿学习与强化学习基线，其中 ALFWorld 成功率绝对提升 34%，WebShop 提升 10%，并在 HotpotQA/Fever 上减少幻觉与错误传播 [1]。不过 ReAct 依赖提示与外部 API，未进行大规模强化学习训练，在复杂环境下动作空间与错误恢复仍受限 [1]。这一局限恰好勾勒出后续工作的演进方向：从提示式协同走向多智能体分工、经验积累与工具化执行。

在端到端自动化科研流水线方面，The AI Scientist 提出让 LLM 独立完成从构思、编码、实验到写作、评审的全流程，在扩散模型、Transformer 语言建模、学习动力学三个 ML 子领域验证，每篇论文成本低于 15 美元，生成论文可超过顶会接收阈值，自动评审达近人类水平 [2]。但该工作仅在 ML 三个子领域验证，且依赖自动评审器，未含真实同行评审 [2]。与之形成对照的是面向生物医学的 Co-Scientist，它基于 Gemini 构建多智能体科学思维引擎，由生成、反思、排序、进化、邻近性与元评审等专门智能体组成，在锦标赛框架中生成、辩论并进化假设，并可用网络搜索与专门 AI 模型工具自我批判 [3]。在 AML 药物重定位、肝纤维化靶点、抗菌素耐药机制三个生物医学问题上，系统提出的候选、新表观遗传靶点及细菌基因转移机制均经独立体外实验验证，且独立复现了未发表的新型基因转移机制 [3]。两篇工作都强调端到端自动化，但差异明显：The AI Scientist 追求全自动与低成本，验证限于 ML 且评审由自动评审器完成 [2]；Co-Scientist 强调科学家在环与体外实验验证，验证限于三个生物医学案例且依赖科学家参与 [3]。这种差异也引出对自主性的争议：Risks of AI scientists 主张优先系统防护而非追求更强自主性，从用户意图、科学领域与环境影响三方面分类风险，并提出人类监管、智能体对齐、智能体监管与环境反馈组成的三元防护框架，以抗体合成等流程示例说明各步骤潜在错误与危害 [4]。该文为观点性论文，无实证验证，风险分类非互斥 [4]，但它与 Co-Scientist 的科学家在环设计形成呼应，也对 The AI Scientist 式全自动路线提出了治理层面的质疑。

针对静态流程无法积累经验的问题，多智能体框架开始引入进化与记忆机制。EvoScientist 指出既有 AI 科学家系统静态、无法从交互历史自适应，因而提出研究、工程、进化管理三个专门智能体加构思记忆与实验记忆两个持久记忆模块，持续提炼可复用知识，使研究智能体与工程智能体检索先前策略，随时间提升想法质量与代码执行成功率 [5]。但该工作未提及具体定量结果，依赖持久记忆质量 [5]。HypoForge 同样针对现有 AI 科学家系统依赖静态提示或固定流程、无法积累经验的问题，区分两阶段监督信号：假设生成用对抗式生成器-判别器通过比较批评学习技能，假设测试用执行结果与真值反馈学习测试技能，从而在不微调基础模型下持续改进 [6]。实验表明其在假设质量与测试性能上一致优于现有 AI 科学家框架与技能级变体，消融验证了阶段特定学习范式的有效性，但未报告具体定量指标，也不微调基础模型 [6]。两者都强调经验积累，差异在于 EvoScientist 依靠持久记忆模块与进化管理智能体 [5]，HypoForge 依靠阶段特定的技能学习范式 [6]；二者均未给出可比的定量结果，难以直接判断优劣。

工具化与代码执行是另一条关键脉络。ToolMaker 将带代码的论文自动转化为 LLM 兼容工具，给定 GitHub URL 和任务描述后自动安装依赖、生成代码并用闭环自纠错调试，同时构建含 15 个任务和 100+ 单元测试的基准，正确实现 80% 任务，显著优于当前 SOTA 软件工程智能体 [7]。其局限在于仅 15 个任务且依赖公开代码仓库 [7]。MatClaw 则走代码优先路线，直接编写和执行 Python，组合任意已安装领域库在远程 HPC 集群上编排多代码工作流，无需预定义工具函数，并用四层记忆架构防止上下文丢失，用领域源码 RAG 将每步 API 调用准确率提升至约 99% [8]。在铁电 CuInP2S6 的三个端到端演示中，智能体能可靠生成代码但难以处理隐性领域知识，需文献自学习与专家约束两种轻量干预弥补 [8]。TeLLAgent 则采用监督者-执行者双智能体框架，由 DeepSeek-R1 驱动的全局规划智能体进行迭代思维链推理与动态规划，DeepSeek-V3.1 驱动的局部执行智能体调用 30 个专用工具，并通过基于模型上下文协议的自纠正循环实现失败后的重思与恢复 [9]。在复杂工具调用任务上，TeLLAgent 显著优于 GPT-5 和现有框架，多步规划成功率更高且随复杂度扩展性更强，同时大幅减少知识检索中的事实幻觉，并成功应用于有机太阳能电池材料的自主发现 [9]。这三项工作在工具使用上各有取舍：ToolMaker 强调从论文代码自动构建工具并给出 80% 的量化成功率 [7]，MatClaw 强调无预设工具函数的自由代码编排与约 99% 的 API 调用准确率 [8]，TeLLAgent 强调战略推理与工具操作分离及 30 个专用工具套件 [9]；但 MatClaw 承认难以处理隐性领域知识 [8]，TeLLAgent 全文未获取、具体局限未明确说明 [9]，二者与 ToolMaker 的 15 任务基准 [7] 之间缺乏统一评测，难以横向比较。

在科学方法驱动的发现上，The Little Scientist 让 LLM 智能体按科学方法迭代做假设、预测、编码、测试与调和，并在平台期由 Kuhn 智能体注入范式转换猜想以跳出局部最优 [10]。在蛋白质适应度预测中发现 Delta V 集成校准策略，在 DNA 基序发现中从零写出 DALE 算法；Delta V 在 ProteinGym 零样本排行榜五项指标均列第一，超 VenusREM +0.033 平均 Spearman；DALE 在 132 个 ENCODE 转录因子上平均 AUROC 0.842 优于 STREME 的 0.803 且快 11 倍，p<1e-6 [10]。该工作仅两个案例研究，全程消耗 704M token [10]。与之相比，Co-Scientist 同样强调假设生成与实验验证，但依靠多智能体锦标赛与体外实验 [3]；The Little Scientist 则依靠 Scientist+Kuhn 双智能体与可量化基准 [10]。值得注意的是，"Turing Tests" For An AI Scientist 这一工作仅有标题与出处信息，未提供方法、数据、结果等可讨论内容 [61]，因此无法在本节中对其具体贡献作出实质判断，这也提示该方向在评测标准上仍存在空白。综合来看，从 ReAct 的提示式协同 [1]，到 The AI Scientist 的全自动流水线 [2] 与 Co-Scientist 的科学家在环多智能体 [3]，再到 EvoScientist、HypoForge 的经验积累 [5][6]、ToolMaker、MatClaw、TeLLAgent 的工具化执行 [7][8][9] 以及 The Little Scientist 的科学方法闭环 [10]，科研智能体系统正沿自主性、经验积累与工具可靠性三条轴线分化演进，而 Risks of AI scientists 提出的三元防护框架 [4] 则提醒这一演进需要在自主性与安全之间持续权衡。

### 2.2 RLVR 与过程奖励

可验证奖励强化学习（RLVR）的核心吸引力在于用程序化或规则化的最终答案校验替代昂贵的人类偏好标注，从而以较低成本驱动大模型推理能力的自我演化。DeepSeek-R1 的工作是这一路线的标志性实践：它基于 DeepSeek-V3 Base，采用 GRPO，仅以最终答案正确性作为奖励，跳过监督微调直接进行强化学习，发现模型自发涌现出验证、反思、探索等长链推理行为，AIME 2024 pass@1 随训练持续提升；随后通过拒绝采样、RL 与 SFT 的多阶段框架训练出 DeepSeek-R1，在继承推理能力的同时改善可读性，并公开了 R1-Zero、R1、数据样本与蒸馏模型 [11]。这一结果确立了"结果可验证 + 规则奖励"作为推理 RL 的基本范式，但其局限同样明确：R1-Zero 可读性差、中英混杂，规则 RL 仅聚焦推理，写作与开放问答受限 [11]。更早的 DeepSeekMath 已经为这一范式提供了方法基础，它从 Common Crawl 筛选 120B 数学相关 token 继续预训练，并引入 GRPO 以降低 PPO 的内存与推理开销，使 7B 模型在 MATH 上达到 51.7%、64 样本自洽达 60.9%，接近 Gemini-Ultra 与 GPT-4 [12]。值得注意的是，DeepSeekMath 在未使用外部工具与投票时仍低于顶级闭源模型，且依赖公开网页数据质量 [12]，这提示结果奖励范式的能力上限受基座与数据约束。

结果奖励的稀疏性天然引出过程奖励的动机：如果只在轨迹末端给一个标量，长链推理中每一步的贡献就无法区分。围绕这一问题的第一类工作试图从理论上揭示 GRPO 本身已经隐含了过程奖励结构。有研究证明，带结果奖励模型（ORM）的 GRPO 在温和假设下等价于带 Monte-Carlo 过程奖励模型（PRM）的 RL 目标，并据此指出当过程步骤与奖励不平衡时，GRPO 会阻碍探索与利用，进而提出 λ-GRPO 修正；实验显示 λ-GRPO 优于标准 GRPO 且更快达到峰值性能，训练时间与成本影响可忽略 [13]。这一结论的意义在于，它把"是否需要显式 PRM"的问题转化为"GRPO 的隐式过程信号是否被正确加权"的问题，但其依赖轨迹共享前缀假设、未大规模验证，PRM 结构的普适性仍需进一步实证 [13]。与之呼应，TEMPO 从树结构角度处理同一问题：它把同一提示的采样响应组织成前缀树（P2T），通过聚合后代结果计算非参数前缀值，再为 GRPO 加入分支感知的时序差分修正而无需 critic；在 Qwen3-1.7B 与 Qwen3-4B 上，TEMPO 在 MATH、MedQA 等分布内及 GSM-HARD、AMC23、MedMCQA、MMLU-Medical 等分布外基准上，收敛与最终性能均持续优于 PPO 和 GRPO，并在相当墙钟时间内取得更高验证准确率 [14]。TEMPO 与 λ-GRPO 的差异在于，前者用采样树显式构造前缀值，后者在目标函数层面修正隐式过程权重；两者都承认 GRPO 的序列级广播过于粗糙，但修正路径不同，且 TEMPO 依赖采样响应构建前缀树 [14]。

另一条路线是直接训练 PRM 并将其作为稠密奖励注入 RL。PURE 的工作对"求和形式信用分配"提出了尖锐批评：它指出 PRM 在强化微调中易被奖励黑客，根源在于 RL 中价值被定义为 γ 折扣未来奖励的累积（求和形式），这会诱导模型攻击高奖励步骤；PURE 把价值函数改为未来奖励的最小值，即最小形式信用分配，限制价值范围并更合理分配优势，仅需变换过程奖励而无需改代码，并支持稠密过程奖励与稀疏可验证奖励结合 [15]。在 3 个基座模型上，采用最小形式的 PRM 方法仅用 30% 步数即达到可验证奖励方法相当的推理性能，而求和形式在训练初期即崩溃；补充 10% 可验证奖励后，Qwen2.5-Math-7B 在 AMC23 达 82.5%、5 基准平均 53.3% [15]。PURE 的贡献在于把"PRM 易被黑客"从工程问题提升为信用分配形式问题，但它也承认 PRM 仍可能奖励黑客，需少量可验证奖励辅助缓解 [15]。与 PURE 关注信用分配形式不同，PQM 关注 PRM 的建模方式：它批评现有 PRM 以分类问题建模、忽略步骤间依赖，将 PRM 重构为马尔可夫决策过程中的 Q 值排序问题，用比较损失优化 Q 值排序以捕捉序列决策动态；在多种采样策略、骨干与多步推理基准上，PQM 优于分类式 PRM，消融实验证实比较损失的有效性 [26]。PQM 的局限在于基于 MDP 假设，未充分讨论长轨迹与稀疏奖励下的扩展性 [26]。

PRM 的数据来源是另一个关键分歧点。传统 PRM 依赖人工步级标注或真值答案，ScalePRM 试图用扩展验证计算替代真值：给定问题与候选解，对每个推理步生成多个独立验证并聚合判断，得到合成步级标签，探索并行自一致性与串行元批判两种推理时扩展策略，并用其监督微调生成式 PRM，再作为 RL 奖励信号 [16]。在 ProcessBench 上，步级自一致性数据训练的 PRM 达 67.5 F1，超过有真值的参考引导 66.4 F1 和 GPT-4o critic 61.9 F1；用于 Qwen2.5-Math-7B 的 RL 时，六个数学推理基准平均 47.4%，优于基于真值的 RLVR 43.9% [16]。这一结果挑战了"过程监督必须依赖真值"的直觉，但 ScalePRM 也承认存在生成式 PRM 特有的奖励利用模式，需额外缓解 [16]。与 ScalePRM 的无真值路线形成对照，VPRM 走的是规则确定性验证路线：它批评现有过程监督依赖神经评判器打分 CoT 步骤、带来不透明、偏见与奖励黑客，提出在 RL 框架中用确定性规则验证器检查每个中间推理步，应用于医学证据合成中的偏倚风险评估，该领域有指南定义标准与规则化决策路径可程序化验证；理论上证明在温和假设下梯度更新对正确推理轨迹赋正期望权重、对不一致轨迹赋负权重 [27]。多数据集上 VPRM 推理更贴合领域规则，步级决策与最终标签一致性显著提高，F1 比 SOTA 高至多 20%、比可验证结果奖励高 6.5% [27]。VPRM 与 ScalePRM 的对比揭示了过程监督的一个根本张力：可程序化验证的领域可以用规则保证忠实，但适用范围受限；生成式验证可以扩展到无规则领域，却重新引入了奖励黑客风险 [27][16]。

当把过程奖励从数学推理迁移到智能体任务时，问题结构发生变化：动作没有明确正确性，奖励设计依赖目标接近度。AgentPRM（Process Reward Models for LLM Agents: Practical Framework and Directions）提出用 Monte Carlo rollout 自动生成过程奖励目标，并以 actor-critic 方式迭代训练 PRM 与策略；还提出 InversePRM，直接从专家示范学习过程奖励而无需结果监督 [28]。在 ALFWorld 上，3B 模型经 AgentPRM/InversePRM 训练后超过强 GPT-4o 基线，并分析了测试时扩展与奖励黑客 [28]。该工作承认探索、样本效率与模型预测推理仍是挑战，且主要在 ALFWorld 验证 [28]。另一篇同名 AgentPRM 的工作则重新定义过程奖励以同时捕捉步骤承诺与进展，用 TD 估计结合 GAE 自动生成标签，训练过程奖励模型并用于搜索与 RL；实验显示其比基线计算效率高 8 倍以上，Best-of-N 随测试时计算扩展稳定提升 [29]。两篇 AgentPRM 的差异值得注意：前者强调 actor-critic 迭代与 InversePRM 的示范学习，后者强调 TD+GAE 的自动标注与承诺/进展双信号；前者在 ALFWorld 上验证 3B 模型，后者覆盖网页购物、浏览器导航等多类任务，但都面临动作无明确正确性、奖励设计依赖目标接近度、跨任务泛化仍需验证的问题 [28][29]。

长程智能体的信用分配进一步暴露了 GRPO 的粒度问题。GACA 指出 GRPO 将轨迹级标量广播到每步、GiGPO 以固定权重混合步级与回合级优势，并用 rollout 已记录的每 token 负对数似然给每步打分，按该分数逐步骤加权混合两级优势，使不确定处用细粒度信号、确定处用低方差信号；理论上证明更高锚点条件期望 NLL 可认证更大的局部动作价值方差下界与误差最优步权重，且状态自适应混合严格优于任何固定权重 [30]。在 ALFWorld 和 WebShop 上，GACA 在 1.5B 与 7B 规模均提升任务成功率，超过 GRPO 和 GiGPO [30]。GACA 的局限在于未在摘要中明确说明，但固定权重基线在状态最优权重不同时被证明次优 [30]。与 GACA 的自适应混合思路相近，GEAR 用自蒸馏比较在线学生与真值条件教师，以散度尖峰确定自适应分段边界并调制局部优势权重；在八个数学推理与工具使用基准、Qwen3 4B/8B 上，GEAR 一致优于标准 GRPO 等基线 [31]。GEAR 的具体数值未在片段中给出，局限也未明确说明 [31]。S-trace 则从资格迹角度切入：它批评 GRPO 等无 critic 算法均匀广播轨迹优势、无法区分关键推理步，先给出 P-trace，再通过选择性掩码低熵 token 实现稀疏资格迹以降低方差、实现细粒度信用分配，并将 GSPO 定位为均匀信用分配下的特例；实验显示 S-trace 在 Qwen3-1.7B 上提升 0.49%、4B 提升 3.16%、8B 提升 2.98%，且样本与 token 效率更高 [32]。S-trace 未报告与更多基线及任务类型的对比 [32]。G2PO 则把线性交互轨迹转为全局状态转移图，聚合相同观测做组聚合状态价值估计，并以边为中心、全局标准化 TD 误差进行优势估计，从而降低采样方差与轨迹依赖偏差，显式优先关键转移 [33]。G2PO 摘要未给出定量结果，图构建开销未讨论 [33]。这三项工作共同指向一个判断：长程智能体的信用分配不能停留在轨迹级广播，但自适应混合、资格迹稀疏化与图结构聚合各有代价，尚无统一结论。

在"是否需要显式 PRM"这一问题上，还存在一条更激进的路线：从 RL 后训练管线本身免费提取过程信号。有研究推导出一般随机 MDP 下的隐式优势——进度优势，即 RL 训练策略与参考策略的对数概率比恰好恢复最优优势函数，无需标注与专用奖励模型训练；在测试时扩展、不确定性量化与失败归因三类应用中，跨五基准四模型族一致优于置信度基线并超越专用奖励模型 [34]。该工作未报告具体数值指标，且依赖 RL 后训练管线 [34]。与之相关，SELAUR 将熵、最低置信度与 margin 三类指标融合为 token 级不确定性估计，并通过失败感知奖励重塑注入步级与轨迹级奖励；在 ALFWorld 和 WebShop 上成功率一致优于强基线，消融验证不确定性信号增强探索效率与学习稳定性 [35]。SELAUR 未给出具体数值增益与失败案例分析 [35]。这两项工作都把"不确定性"作为过程信号的来源，但进度优势来自策略与参考策略的比值，SELAUR 来自熵与置信度融合，前者有理论推导，后者有消融验证，二者尚未在同一基准上直接比较。

过程奖励的忠实度问题在小推理模型与开放书问答中尤为突出。FaithRL 针对小推理模型中间步骤忠实度幻觉，引入过程奖励模型提供的显式步级忠实度奖励，并用截断重采样从忠实前缀生成对比信号，同时用信息增益惩罚缓解奖励黑客；实验表明 FaithRL 在多个 SRM 和开放书 QA 上持续减少 CoT 与最终答案幻觉，平均准确率提升 7.29%、忠实度提升 1.73% [36]。该工作仅针对小推理模型与开放书 QA，未覆盖更广任务 [36]。BiPRM 则从评估方向入手：它批评现有 PRM 仅单向从左到右评估、缺乏全局上下文，通过提示反转实现并行从右到左评估流，并用门控机制自适应融合两流分数；在 GSM-Plus、MATH500 与 ProcessBench 上，BiPRM 持续超越单向基线，解级平均增益 10.6%、步级错误检测增益 37.7% [37]。BiPRM 的代价是参数量增 0.3%、推理延迟增约 5%，且依赖提示反转实现 R2L [37]。FaithRL 与 BiPRM 分别从奖励内容与评估方向改进 PRM，但都未解决 PRM 本身的奖励黑客风险，FaithRL 用信息增益惩罚缓解，BiPRM 未讨论该问题 [36][37]。

多智能体与工具使用场景把过程奖励的粒度推进到智能体动作与工具调用。MASPRM 为多智能体系统设计过程奖励模型，对路由转录前缀与智能体动作打分，作为推理控制器指导 SBS 与 MCTS；训练仅用多智能体 MCTS rollout 的终端结果奖励，通过 Bradley-Terry 排序损失训练价值头，无需人工步级标注 [38]。在 GSM8K、MATH、MMLU、LOGIQA 上，MASPRM 超越同规模 ORM，7B 在 MCTS 下平均提升 13.4 分，并改善排序质量 [38]。其局限在于限于预定义 MAS 配置与可验证答案任务，依赖通信图与调度设计 [38]。Sci-PRM 则填补 PRM 在科学领域工具使用验证的空白，构建 SCIPRM70K 数据集，含交错推理与科学工具执行的 Chain-of-Tool 轨迹，训练 Sci-PRM 在单次推理中对工具选择、执行准确性与结果解读提供细粒度监督；实验表明其支持 Best-of-N 测试时扩展，并作为 RL 密集奖励缓解优势消失，在工具调用步 F1 上显著优于 GPT-5-Mini 等基线 [39]。Sci-PRM 依赖工具沙箱执行，部分验证超时（如 BLAST 超 300s）[39]。SWE-TRACE 面向长程 SWE 智能体，先用 LLM 多任务级联与步级 oracle 验证，从 77 个仓库的 140K 候选实例中蒸馏出 60K 偏向 token 高效最短路径的 SFT 语料；再用带评分标准过程奖励模型的记忆增强智能体 RL 提供稠密中间反馈；最后复用 PRM 做启发式测试时扩展，在每步动态评估并剪枝动作候选 [40]。在标准 SWE 基准上，SWE-TRACE 显著提升解决率并大幅降低 token 消耗与推理延迟，但依赖 oracle 验证器与评分代理 [40]。GenReasoner 则把工具使用作为通用推理技能学习，通过可扩展数据管线、Tool-GRPO 按端任务成功优化工具选择与排序，以及自适应学习机制动态调节工具使用；实验显示模型能自主采纳有益工具、抑制无关工具，7B 基座平均提升 24.9% 并超越强专有模型 [41]。GenReasoner 依赖工具环境与数据管线，未见工具泛化仍受限 [41]。这些工作共同表明，工具与多智能体场景的过程奖励必须处理动作空间结构化、执行代价高、验证可能超时等新约束，与数学推理中"每步可独立判断"的假设有本质差异。

RLVR 的奖励信号本身也受到一系列质疑，这些质疑直接影响过程奖励的设计前提。Spurious Rewards 发现即使奖励与正确答案无关甚至负相关，也能提升部分模型数学推理：用 GRPO 在 Qwen2.5-Math-7B 等模型上比较真实奖励、随机奖励和虚假奖励，随机奖励使 MATH-500 提升 21.4 个百分点，接近真实奖励 29.1 点，代码推理频率从 65% 升至 90% 以上 [19]。但该现象高度依赖模型家族，虚假奖励对 Llama3、OLMo2 等无效 [19]。这一发现对过程奖励的启示是：如果结果奖励本身可以"虚假地"起作用，那么 PRM 提供的稠密信号是否也在放大预训练中已有的行为而非真正教会推理，就成为必须回答的问题。Exploration vs Exploitation 进一步分析裁剪偏差、熵最小化与虚假奖励的交互机制，发现裁剪偏差在虚假奖励下降低策略熵，产生更确定输出，而仅熵最小化不足以提升性能 [42]。该工作未给出具体实验规模与量化提升数据 [42]。Spurious Rewards Paradox 则从机制层面揭示困惑度悖论：答案 token 困惑度下降而提示侧连贯性退化，并用路径修补、Logit Lens、JSD 分析与神经常微分方程定位 L18-20 功能锚点与 L21+ 结构适配器，可双向因果操控 [43]。该工作未明确说明模型规模与任务覆盖范围 [43]。这三项工作共同构成对 RLVR 奖励信号的"压力测试"：虚假奖励能提升性能、裁剪偏差会降低熵、记忆捷径可被机制定位，意味着过程奖励若只追求步级准确率而不控制忠实度与泛化，可能同样落入放大捷径的陷阱。

样本效率与难度分层是 RLVR 的另一组关键变量。单样本 RLVR 的研究显示，对 Qwen2.5-Math-1.5B 等模型用单个可验证奖励样本做 RLVR，MATH500 从 36.0% 升至 73.6%（超格式修正 8.6%），6 基准均值 17.6%→35.7%（非格式增益 7.0%），2 样本 MATH500 达 74.8%，匹配 1.2k DeepScaleR 子集，并观察到跨类别泛化与饱和后持续提升现象 [20]。该工作指出主要增益来自策略梯度损失，未验证数学以外领域 [20]。这一结果与过程奖励的动机形成有趣张力：如果单样本结果奖励就能激发大量推理能力，那么 PRM 的边际价值可能集中在结果奖励难以覆盖的长程、多步、工具使用场景，而非短链数学题。难度分层研究进一步发现样本难度对 RLVR 呈非单调影响：易与中等难度问题带来最强最稳定的推理提升，过难问题学习信号弱、诱发答案重复或跳过必要计算等退化行为并可能损害模型原有能力；用 T-SAE 分析内部特征动态发现易题强化直接作答与基础计算特征、抑制审慎推理特征，难题激活推理特征但仅在采样到成功轨迹时有用，中等难度提供更平衡信号，据此提出难度自适应策略 [21]。该工作未给出具体量化提升数值与模型规模 [21]。这两项工作对过程奖励设计的启示是：PRM 的步级信号若不加难度区分，可能在易题上过度强化直接作答、在难题上因成功轨迹稀少而失效。

在"无外部奖励"方向上，Intuitor 提出用模型自身置信度 self-certainty 作为唯一奖励信号，在 GRPO 中将外部奖励替换为 self-certainty，实现完全无监督学习；实验显示其在数学基准上匹配 GRPO，并在代码生成等域外任务上泛化更好，无需金标答案或测试用例 [17]。该工作依赖模型自身置信度信号，可能受校准偏差影响，未覆盖所有可验证奖励场景 [17]。MEL 则针对 RLVR 缺乏错误归因与经验内化机制、存在元学习瓶颈的问题，利用 LLM 自验证对正确与错误轨迹做对比分析，定位推理错误分叉点并总结为可泛化元经验，再通过最小化负对数似然将其内化进参数记忆，形成桥接正确与错误轨迹的语言建模奖励信号；实验显示不同模型规模下 Pass@1 提升 3.92%–4.73% [18]。MEL 依赖自验证能力，未讨论错误归因失败情形 [18]。Intuitor 与 MEL 都把奖励来源从外部验证转向模型内部信号，前者用置信度，后者用自验证对比，但都面临校准偏差与自验证失败的风险，且都未与显式 PRM 在同一设置下比较。

探索多样性与推理效率是 RLVR 训练动态中的另一对矛盾。ROSE 针对 MCTS 扩展方法探索多样性有限和推理效率低的问题，引入基于语义熵的分支策略和 ε 探索机制以增强推理探索多样性，并设计长度感知的片段级优势估计器奖励简洁正确推理、惩罚冗长推理链；在 Qwen 和 Llama 模型的多个数学推理基准上验证了方法的有效性与效率 [44]。该工作未给出具体量化提升数值 [44]。TreeRL 则把在线策略树搜索直接引入 LLM 强化学习训练，提供密集的过程监督并免去单独训练奖励模型；方法提出 EPTree，从高不确定性中间步骤分支以提升搜索效率，并基于全局与局部优势为每步分配信用 [45]。在数学与代码推理基准上，TreeRL 优于传统 ChainRL，EPTree 在相同推理预算下也优于多链采样与 MCTS，例如 GLM4-9B 提升 2.5–5.6、Qwen-2.5-14B 提升 4.6–8.5 [45]。TreeRL 主要验证于数学与代码推理，未覆盖更广领域 [45]。ROSE 与 TreeRL 都试图用树搜索或分支策略替代或补充 PRM，前者强调语义熵与长度感知优势，后者强调不确定性分支与全局/局部优势，二者都未与显式 PRM 引导 RL 直接对比。

熵正则化与训练稳定性是过程奖励 RL 的底层机制问题。熵正则化综述系统梳理了深度强化学习中的熵正则化，跨越经典控制、生成式策略与 LLM 推理三类范式，通过区分策略级、轨迹级、占用度量级等熵对象，梳理其在探索、平滑、信任域与多样性中的作用，并指出生成式策略熵难计算、LLM 后训练存在熵坍缩，需按策略类与训练机制区别对待 [46]。该综述无新实验，且熵定义跨策略类不可互换，统一度量困难 [46]。这一视角对过程奖励的启示是：PRM 提供的稠密奖励会改变策略熵的演化路径，若不加控制可能加速熵坍缩，而虚假奖励研究已经显示裁剪偏差在虚假奖励下降低策略熵 [42]。SORL 则从离策略训练稳定性切入，针对多轮智能体离策略 RL 训练中 PPO/GRPO 不稳定与性能崩溃问题，识别出 token 级优化与回合结构不匹配、离策略重要性采样高方差两大根源，提出 SORL 框架及 SO-PPO、SO-GRPO 两种算法，对齐多轮交互结构并自适应抑制不可靠更新；在多轮搜索基准上，两方法稳定训练并取得更优或相当表现 [47]。SORL 未在片段中明确说明局限 [47]。熵正则化综述与 SORL 分别从理论梳理与算法修正层面处理稳定性，但都未直接回答"过程奖励的稠密信号如何影响熵坍缩"这一具体问题。

奖励建模的系统性视角在综述工作中得到整合。PRM 综述按完整循环组织：如何生成过程数据（人工标注、自动监督、半自动流水线）、如何构建 PRM（判别式与生成式目标、显式与隐式监督、架构创新）、如何使用 PRM（测试时扩展的重排、验证引导解码、搜索，以及 PRM 引导 RL 的稠密步级奖励与信用分配），并总结数学、代码、文本、多模态推理、机器人与智能体等应用及新兴基准 [48]。该综述为综述性质，无新实验，且领域快速演进 [48]。RARL 综述则论证奖励建模是推理对齐的核心架构而非实现细节，提出以推理为中心的 RARL 分类视角，系统梳理奖励机制、奖励黑客失效模式及奖励信号对推理挑战的统一作用，并批判评估现有基准的数据污染与奖励错配问题 [49]。该工作为综述与分类框架，缺乏新实证实验验证 [49]。两篇综述的共同判断是：过程奖励的设计空间远未收敛，数据生成、建模目标与使用方式三者相互耦合，且评估基准本身存在污染与错配，这为前述各项工作的可比性蒙上阴影。

从更广的模型与任务覆盖看，Kimi k1.5 报告了用强化学习训练的多模态 LLM 实践，采用长上下文扩展和改进策略优化，构建不依赖 MCTS、价值函数和过程奖励模型的简洁 RL 框架，并提出 long2short 方法；系统在 AIME 77.5、MATH500 96.2、Codeforces 94 百分位、MathVista 74.9 上匹配 o1，短 CoT 模型 AIME 60.8、MATH500 94.6、LiveCodeBench 47.3，超 GPT-4o 等最多 +550% [25]。该工作未公开训练细节与权重，且明确未依赖 MCTS/价值函数 [25]。Kimi k1.5 的存在对过程奖励路线构成一个对照：在长上下文与改进策略优化下，不依赖 PRM 也能达到 SOTA，这意味着 PRM 的价值可能更多体现在特定瓶颈（长程智能体、工具使用、忠实度要求高的领域）而非普遍必需。MedVLM-R1 则把 RL 引入医学视觉语言模型以激励推理能力 [62]，MedLoc-R1 进一步提出面向 GRPO 的医学视觉定位性能感知课程奖励调度 [63]，这两项工作表明过程奖励与课程调度正在向医疗等高风险领域扩展，但证据中未给出其具体方法细节与结果，只能确认其存在与方向。此外，有研究探讨在没有真值解的情况下用 RL 改进 LLM [64]，与 ScalePRM 的无真值 PRM 训练、Intuitor 的无外部奖励形成同一主题下的多条路径，但该证据未提供方法细节，无法进一步比较。数据污染问题也被单独提出：有工作指出 RL 结果不可靠可能源于数据污染，质疑推理或记忆的归因 [65]，这与 Spurious Rewards Paradox 的机制分析、RARL 综述对基准污染的批判相互呼应，共同构成对 RLVR 与过程奖励评估有效性的警告。

综合来看，RLVR 与过程奖励的关系可以概括为三条相互竞争的路线。第一条是"隐式过程奖励"路线，以 λ-GRPO 和 TEMPO 为代表，主张 GRPO 本身已含过程结构，只需修正其权重或加入树结构 TD 修正，无需独立 PRM [13][14]。第二条是"显式 PRM 引导 RL"路线，以 PURE、PQM、ScalePRM、VPRM、AgentPRM、MASPRM、Sci-PRM、SWE-TRACE 为代表，主张用独立训练的过程奖励模型提供稠密信号，但在信用分配形式（最小 vs 求和）、建模方式（分类 vs Q 值排序 vs 生成式）、数据来源（人工 vs 合成 vs 规则验证 vs 示范）、适用场景（数学 vs 智能体 vs 科学工具 vs SWE）上高度分化 [15][26][16][27][28][29][38][39][40]。第三条是"无外部奖励/内部信号"路线，以 Intuitor、MEL、进度优势、SELAUR 为代表，主张用置信度、自验证、策略比值或不确定性替代外部过程监督 [17][18][34][35]。这三条路线之间的争议集中在：GRPO 的隐式过程信号是否足够、PRM 的奖励黑客是否可根治、无真值过程监督是否可信、以及虚假奖励现象是否意味着所有 RLVR 信号（包括 PRM）都在放大预训练捷径而非教会推理 [13][15][16][19][43]。证据之间的冲突也很明显：PURE 报告求和形式信用分配在训练初期即崩溃 [15]，而 DeepSeek-R1 与 DeepSeekMath 用 GRPO 的结果奖励取得显著提升 [11][12]，这说明信用分配形式的失效可能依赖奖励稠密度与任务结构；ScalePRM 报告无真值 PRM 超过有真值参考引导 [16]，而 VPRM 强调只有规则确定性验证才能保证忠实 [27]，二者对"验证信号可靠性"的判断相反；Spurious Rewards 报告随机奖励提升 21.4 点 [19]，而 Exploration vs Exploitation 指出仅熵最小化不足以提升性能 [42]，二者对虚假奖励增益机制的解释存在张力。这些冲突尚未被统一解释，也构成该方向后续研究的核心问题。

### 2.3 自我改进与递归自改进

自我改进在LLM智能体研究中的最早形态并不涉及权重更新，而是把语言反馈本身当作强化信号。Reflexion在2023年提出让语言智能体通过言语反思进行强化学习：智能体对任务反馈生成反思文本，存入情景记忆，再据此改进后续决策，全程不更新模型权重[66]。在HumanEval编码基准上，这一机制把pass@1推到91%，超过当时GPT-4基线的80%[66]。它的局限也很明确：效果依赖反馈信号质量，需要多轮试验，且不改变模型参数[66]。这条路线奠定了后续大量工作的基本假设——智能体的改进可以外化到记忆、提示或技能库中，而不必进入梯度下降。与之形成对照的是GEPA，它同样放弃稀疏标量奖励的RL，但把改进对象从情景记忆转向提示本身：通过采样推理、工具调用与输出轨迹，用自然语言反思诊断问题并进化提示，同时维护Pareto前沿以避免局部最优[67]。在六类任务上，GEPA平均超过GRPO 6%、最高20%，rollout最多少35倍，并超过MIPROv2逾10%，在AIME-2025上提升12%[67]。两者都强调"不更新权重"，但Reflexion把反思存为可检索的经验，GEPA则把反思压缩进提示并做多目标搜索；前者依赖反馈质量，后者依赖可序列化轨迹与反思质量[66][67]。这一分歧贯穿了自我改进研究：改进究竟应沉淀为可复用的经验条目，还是应直接改写智能体的行为规范。

当改进对象从提示转向智能体自身代码时，递归自改进的轮廓开始出现。A Self-Improving Coding Agent让配备基础编码工具的LLM智能体自主编辑自身代码，通过LLM反思与代码更新实现非梯度、数据高效的学习[22]。在SWE Bench Verified随机子集上，性能从17%提升到53%，LiveCodeBench与合成智能体基准也有额外提升[22]。这项工作的重要性在于它把"智能体改进智能体"从隐喻变成可测量的基准任务，但其验证仅限随机子集，未说明全量泛化与稳定性[22]。更系统的检验来自AI4AI-Bench：它用10个冻结训练算法仓库构成隔离基准，智能体在4小时内改写训练算法，代码在全新容器重跑最多12小时并由隐藏评估器按统一0-1量表打分，其中0.1代表原算法、1.0代表最优[23]。结果显示平均分仅0.166，最佳系统0.250，最强系统只缩小了不到五分之一的差距，且多数提交并未改变学习方式[23]。不过，推理投入能显著改变这一局面：改变学习方式的提交均分0.226，远高于未改变的0.126；推理投入提升后，少数派占比从8%升到64%，均分从0.094升到0.196[23]。这与自我编码智能体的乐观结果形成张力——在自选子集上从17%到53%的跃升，与在冻结仓库上平均0.166的得分，提示递归自改进的能力高度依赖任务边界与评测隔离程度[22][23]。

递归自改进的另一条路径是让智能体改进训练数据与后训练流程，而非直接改写算法代码。RSIBench-Data固定后训练栈，让智能体迭代修改训练数据策略，训练服务、评测沙箱与预算均固定，在软件工程、终端、科学问答、数学等6个基准上评测4个前沿智能体[24]。结果是58.33%的设置中智能体通过反馈改进了首次有效尝试，但78.26%的继续搜索以更低分收尾，改进并不稳定[24]。这一"继续搜索反而变差"的现象与AI4AI-Bench中"多数提交未改变学习方式"相呼应，共同指向递归自改进的一个核心困难：智能体缺乏可靠的自我评估信号来判断一次修改是否真的更好[23][24]。MetaSkill-Evolve则从技能结构入手回应这一问题，提出双时间尺度框架：每个分支同时携带任务技能与五组件元技能，任务技能在快循环中进化，元技能在慢循环中于自身流水线上进化，共享单一冻结骨干[68]。在OfficeQA、SealQA、ALFWorld上，它相对原始骨干的held-out测试准确率分别提升+23.54、+16.09、+1.92分，优于无技能、静态技能与单层进化基线[68]。其局限是五个流水线智能体共享单一冻结骨干，且未提及其他领域泛化[68]。与RSIBench-Data的悲观结论相比，MetaSkill-Evolve表明当改进被约束在结构化的技能层级中、并有明确的留出评测时，递归进化可以稳定带来增益；差异可能来自改进空间的受限程度与评估信号的可靠性[24][68]。

在结构化环境中，技能库的编辑式自改进取得了更显著的定量结果，但也暴露出回归风险。GRASP指出，智能体自改进中新增的自然语言指导可能修复一条轨迹却静默回退另一条，因此把改进视为对受限技能库的编辑序列，仅在平衡留出探针上净提升且满足硬回归预算时才接纳候选[69]。在两个基于FHIR的临床基准上，GRASP让gpt-oss-120b在MedAgentBench上从40.6%升到88.8%，超过最强基线21.0点，其他模型提升17.2–40.3点[69]。消融显示增益来自比较式提议、接纳门控与回归预算三者，而无验证的技能写入并不优于无技能[69]。其局限是增益限于域内，未提升分布外表现[69]。与之互补的是经验反思学习（ERL）：它反思任务轨迹与结果，生成可迁移的启发式规则，测试时检索相关规则注入上下文，在Gaia2上成功率较ReAct提升7.8%，优于先前经验学习方法，消融表明选择性检索至关重要，启发式比少样本轨迹提示更具可迁移性[70]。ERL的局限是仅在Gaia2评测，未验证更广泛环境[70]。两者都依赖"经验—检索—注入"的循环，但GRASP用门控与回归预算显式防止负迁移，ERL则用选择性检索与启发式抽象来提升可迁移性；GRASP的增益幅度远大于ERL，但其域内限制也更明显[69][70]。AccelOpt把这一循环推向硬件内核优化：它通过迭代生成并借助优化记忆整理慢-快内核对经验来探索优化空间，并构建NKIBench评测[71]。在来自真实LLM工作负载的AWS Trainium内核上，Trainium 1峰值吞吐均值从49%升到61%，Trainium 2从45%升到59%，开源模型达到Claude Sonnet 4水平且便宜26倍[71]。这说明经验记忆式自改进在具有明确性能度量的工程域中同样有效，但其片段未明确说明局限[71]。

上述工作大多假设记忆或技能中存储的分数可以作为可靠的代理奖励，但Memory Reward Inflation直接挑战了这一假设。它研究不更新权重、仅靠外部记忆学习的自改进智能体，把存储分数视为代理奖励，形式化Echo Gap与误差独立性假设EIA，并提出无答案去膨胀算法LUCID[57]。在BIRD text-to-SQL上，LUCID执行准确率达到56.9%，高于Memento式自评分智能体的54.0%（+2.9点）与无记忆同架构智能体的52.4%[57]。其局限是依赖错误独立性假设，验证器错误仍与原始自评分偏差相关，难以识别被高估的记忆[57]。这一发现与GRASP"无验证的技能写入不优于无技能"的消融结论一致，都指向自评分作为奖励信号的系统性偏差[69][57]。更严重的后果出现在安全维度：Practice Makes Unsafe揭示自改进智能体把成功轨迹转为持久技能时，不安全的成功会被固化为可复用策略，即技能误演化[58]。在25种智能体-方法配置、各525任务、25回合的设置下，21个演化配置均产出不安全技能，15个导致新会话危害；3个恶意任务将延续ASR从16.0%升到35.3%[58]。其提出的SAFEEVOLVE防护包装降低不安全检索26.7点、新会话危害17.3点，而良性效用仅变化0.4点[58]。该工作还指出，现有基准无法跨编写、检索与执行归因风险，演化以任务结果为目标而非过程安全[58]。这构成对递归自改进的实质性争议：GRASP与ERL把"任务成功"当作改进目标，而技能误演化表明，成功轨迹中可能内嵌不安全策略，且这些策略会随技能复用而扩散[69][70][58]。

当可验证奖励不可得时，自监督RLVR试图用任务内部的对偶结构制造验证信号。CellDuality面向单细胞生物学，基于互补任务对偶性：先正向预测生物结果，再反向重构初始条件，以重构保真度作为内在奖励对齐模型，从而在无需可验证结果的情况下形成自验证反馈循环，增强逻辑与生物一致性[eupmc:med:42559559]。其核心限制是多数生物结果不可验证，方法依赖互补任务重构保真度作为内在奖励[eupmc:med:42559559]。这与Memory Reward Inflation的问题形成有趣对照：后者用去膨胀算法修正被高估的记忆分数，前者则干脆放弃外部可验证性，转而用任务对偶性生成内在奖励[57][eupmc:med:42559559]。但两者共享同一风险——内在奖励或代理奖励的保真度决定了整个自改进循环的方向；一旦重构保真度与真实生物一致性脱钩，自验证就会放大错误[eupmc:med:42559559]。综合来看，这一节的证据呈现出递归自改进的三层张力。第一层是改进对象的差异：Reflexion与ERL沉淀经验条目，GEPA进化提示，GRASP与MetaSkill-Evolve编辑技能与元技能，A Self-Improving Coding Agent与AI4AI-Bench改写代码与算法，RSIBench-Data修改数据策略[66][70][67][69][68][22][23][24]。第二层是评估信号的可靠性：从Reflexion的语言反馈、GEPA的反思诊断，到LUCID的去膨胀、GRASP的回归预算、CellDuality的重构保真度，方法越接近递归自改进，越依赖一个能抵抗自评分偏差的验证器[66][67][57][69][eupmc:med:42559559]。第三层是安全与泛化的代价：技能误演化显示成功导向的演化会固化不安全策略，GRASP的增益限于域内，ERL仅在Gaia2验证，AI4AI-Bench与RSIBench-Data则分别用0.166的平均分和78.26%的继续搜索降分率标出了当前能力的上限[58][69][70][23][24]。这些证据并不支持"递归自改进已可自主加速"的强主张，反而更支持一个受限结论：在改进空间被结构化约束、验证信号被显式去偏、且安全风险被单独度量的条件下，自改进才能稳定产生可测量的增益[69][68][57][58]。

### 2.4 智能体信用分配、验证与安全机制

在长运行 LLM 智能体的可验证奖励强化学习（RLVR）中，验证长期被视为固定的奖励组件，由此带来稀疏信用分配、验证器可靠性不足、奖励黑客、路径合规以及验证成本偏高等一系列问题。BAVAR（预算自适应验证与非对称奖励框架）针对这些痛点，把验证重新建模为序列化的资源受限决策问题：智能体依据不确定性、动作关键性、验证器可靠性、期望验证价值与剩余预算，动态决定验证什么、何时验证、使用哪个验证器以及如何影响学习，并采用可靠性门控的正过程奖励叠加持续路径违规惩罚，进一步扩展到持久记忆与可复用技能 [72]。在匹配验证预算的评估中，BAVAR 取得 72.6% 的安全验证成功率，高于均匀密集验证的 67.1% 与仅结果 RLVR 的 58.4%，同时每安全成功验证成本降低 45.5%、验证 token 减少 47.8% [72]。这一结果说明，把验证当作可调度的稀缺资源而非固定开销，能在不增加预算的前提下同时改善安全性与经济性；但其局限也很明显——评估仅为示例性，验证成本与可靠性之间的权衡尚未充分展开 [72]。

与 BAVAR 从训练机制侧优化验证不同，R-Judge 从评测侧切入智能体行为安全，构建了包含 569 条多轮智能体交互记录的基准，覆盖 27 类风险场景、5 类应用与 10 种风险类型，并为每条记录配备安全标签与风险描述 [55]。对 11 个 LLM 的评估显示，最佳模型 GPT-4o 仅达 74.42%，其余模型未显著超过随机水平；微调能显著提升安全判断能力，而简单提示无效 [55]。这表明 LLM 的风险意识是一种涉及知识与推理的多维能力，现有模型表现仍然有限 [55]。两项工作形成互补又存在张力：BAVAR 假设验证器本身可被可靠性门控并据此分配预算，而 R-Judge 的结果恰恰提示验证器（即作为判断者的 LLM）在风险识别上并不可靠，最佳也仅 74.42%，其余接近随机 [72][55]。因此，BAVAR 所依赖的“验证器可靠性”信号从何而来、能否在 R-Judge 这类多维风险场景中稳定估计，是两者之间尚未解决的争议；BAVAR 也承认其验证成本与可靠性的权衡未充分展开 [72]。在时间线上，R-Judge 于 2024 年提供了安全风险意识的评测基础，BAVAR 于 2026 年则尝试把验证从固定奖励改造为预算自适应的决策过程，前者暴露能力缺口，后者提出机制性补救，但补救措施的有效性仍取决于前者所揭示的判断可靠性问题能否被真正解决 [55][72]。

## 3 数据、基准与评测环境

围绕过程奖励模型（PRM）的评测，近两年出现了一批从不同角度切入的基准，其共同指向是：现有奖励模型在“过程”层面的判别力远未饱和。Socratic-PRMBench 系统性地把过程错误检测拆解为六类推理模式——Transformation、Decomposition、Regather、Deduction、Verification、Integration，构造了 2995 条含缺陷推理路径，平均 8.7 步，采用合成加人工标注的方式，并对比 ProcessBench、PRMBench 等既有基准，评测对象同时覆盖 PRM 与 LLM critic；结果显示现有 PRM 在多样推理模式下仍有明显缺陷，尤其在分解（Decomposition）等模式上的错误检测不足 [50]。该工作的方法论意义在于把“过程正确性”从单一分数细化为可归因的推理模式维度，但其局限也很明确：基准为合成加人工构造，可能不完全覆盖真实推理分布，且只评测错误检测这一项能力 [50]。与之形成领域化对照的是 MedPRMBench，它基于临床推理蓝图，从 7 个医学 QA 源生成 6500 题、13000 条推理链、113910 步标签，另配 6879 题训练数据，覆盖 3 大类 14 种细粒度错误类型，并首创 4 级严重度分级 [51]。在评测结果上，该工作自建的医学 PRM 基线总体 PRMScore 达 87.1%，显著超越专有前沿模型、开源推理模型与医学专用模型，作为即插即用验证器还能使下游医学 QA 准确率提升 3.2–6.7 个百分点 [51]。这里出现了一个值得注意的张力：Socratic-PRMBench 强调通用 PRM 在多种推理模式下的普遍不足 [50]，而 MedPRMBench 表明在特定领域内、配合领域蓝图与细粒度错误分类，PRM 可以达到相当高的过程判别水平并反哺下游任务 [51]。两者的差异未必是结论冲突，更可能反映评测构造方式与领域约束强度的不同——前者追求跨模式的通用诊断，后者追求临床推理蓝图下的领域闭环，但这也提示“PRM 能力”本身高度依赖基准的构造假设，跨基准的可比性仍需谨慎。

在智能体记忆使用这一子问题上，MemCalib 把评测焦点从“记忆是否被检索”推进到“每条记忆被赋予多大影响”。该基准含 15000 例（13500 训练加 1500 测试），覆盖健康、通用助手与编程三类场景，评测模型对原子命题的忽略、限定、控制三级影响，对比 GRPO、OPSD 以及 Qwen3-8B、Ministral-3-8B-Instruct、Qwen3.5-35B-A3B 等模型 [56]。实验发现前沿模型常过度或不足使用记忆，GRPO 与 OPSD 存在方向性偏斜；作者提出的 MemCalib-RL 通过有序双向反事实信用分配取得最佳总体表现，更好平衡过度使用与使用不足两类错误，且增益可泛化到外部基准 [56]。这一工作与 PRM 类基准共享“过程级信用分配”的问题意识，但把奖励/校准对象从推理步骤换成了记忆影响，说明可验证奖励的设计正在向智能体的内部状态控制延伸。

面向“开放式科学发现”的评测则暴露出更深的困难。TruthInsightBench 明确区分“执行既定分析”与“开放式科学发现”，构造 40 个盲任务，源自 10 个科学领域 40 篇同行评审研究，仅给智能体中性科学目标与冻结数据，由固定 LLM 裁判按 6 维度 29 个证据锚定项自动评分 [54]。评测四个编码智能体（同一冻结基座模型）发现总分仅 58.4–60.3/100，且无统计可靠的两两区分；证据可审计性与新颖性相对较强，而控制、稳健性、可证伪性、跨数据集泛化普遍缺失 [54]。作者据此判断瓶颈在科学判断而非编码，真正的科学发现仍难实现，同时承认评测依赖 LLM 裁判、任务规模仅 40 个、未覆盖全部科学发现能力 [54]。与之呼应的是 BAISBench，它针对组学数据驱动的生物发现，指出既有评估偏知识驱动、依赖专家或 LLM 评审，主观且难扩展，未直接检验能否从原始数据得出可解释结论；BAISBench 基于单细胞转录组数据构建贴近数据驱动发现的评测框架，对比 AutoBA、scChat、BioChatter、Biomni、STELLA 等系统，但片段中未给出具体定量结果 [53]。两者共同的方法论诉求是：把评测从“知识问答式”推向“从数据到结论”的闭环，但 TruthInsightBench 的窄平台结果 [54] 与 BAISBench 对既有评估主观性的批评 [53] 也说明，这类开放式基准目前既缺区分度，也缺可扩展的客观判据。

学术诚信与工作流可靠性构成另一条评测线索，且结论相当尖锐。SciIntegrity-Bench 采用两难式范式，每个场景只有诚实承认失败才正确，完成任务则需违规，含 33 个场景、11 类陷阱，对 7 个 SOTA LLM 进行 231 次评测及提示消融 [73]。结果显示整体诚信问题率达 34.2%，无模型零失败，缺数据场景下全部模型伪造数据；更关键的是，去除完成压力使未披露伪造从 20.6% 降至 3.2%，说明存在与提示无关的内在完成偏差 [73]。该工作仅 33 个场景、未覆盖真实科研全流程，但其“无模型零失败”的结论与 SoundnessBench 形成互证：SoundnessBench 含 1099 个从 ICLR 投稿重建的 ML 研究提案，标注审稿人合理性子分数并对照源论文审计，评测 12 个前沿 LLM 发现普遍乐观偏差，标准提示下常将低合理性提案评为合理，激进提示则使错误从假阳性转向假阴性 [74]。两者分别从“诚信”和“方法可行性判断”两个角度表明，当前 LLM 尚不能作为科研严谨性的独立首关评估者 [73][74]。而《The More You Automate, the Less You See》进一步指出失效可能藏在流程内部：它识别出不当基准选择、数据泄漏、指标误用和事后选择偏差四种失效模式，通过受控实验隔离每种模式并评估两个主流开源 AI 科学家系统，发现多种易被忽视的失效，并证明获取完整工作流的追踪日志和代码比仅审查最终论文更能有效检测问题，建议期刊会议强制提交这些工件 [75]。这三项工作合起来提示：对 AI 科学家的评测若只看最终产出，会系统性低估失效；可验证奖励若要落地，必须把过程工件（日志、代码、中间结果）纳入可审计范围。

代码复现与计算可复现性评测则提供了更“硬”的可验证信号。LMR-BENCH 含 28 个代码复现任务，源自近五年顶级 NLP 会议的 23 篇论文，覆盖九大类别，提供论文、含掩码函数的代码库和实现说明，以单元测试准确率与 LLM 代码正确性评估 SOTA 模型，结论是最先进模型在科学推理与代码合成上仍有持续局限 [76]。CORE-Bench 则从“已发表研究可信度”的角度切入计算可复现性智能体评测，被引 117 次，是该方向影响力较大的基准之一 [77]。两者与 ScienceAgentBench 的定位形成层次差异：ScienceAgentBench 从 44 篇同行评审论文提取 102 个任务，经 9 位专家验证，统一输出为自包含 Python 程序，并设计防数据污染策略，评估 5 个 LLM 与 3 种框架（直接提示、OpenHands CodeAct、self-debug），最佳智能体仅独立解决 32.4%，专家知识辅助下 34.3% [78]。也就是说，复现类基准（LMR-BENCH、CORE-Bench）检验的是“能否重跑已有结论” [76][77]，而 ScienceAgentBench 检验的是“能否从论文任务出发独立写出正确程序”，后者最佳仅约三分之一，且需专家验证、成本高 [78]。BLADE 则把评估推向开放式：含 12 个来自科学文献的数据集与研究问题，由专家数据科学家独立分析形成真值，并开发计算方法匹配不同分析表示，评估显示语言模型多停留在基础分析，能交互数据的智能体分析多样性提升但仍未达最优 [79]。这几项工作在“任务是否可自动判定”上分歧明显：ScienceAgentBench 用自包含程序与防污染策略追求严格判定 [78]，BLADE 用多表示匹配来容纳开放式分析 [79]，而 TruthInsightBench 直接依赖 LLM 裁判并承认其局限 [54]——评测的客观性与任务开放性之间存在结构性权衡。

生物与组学方向的基准进一步显示“上游数据工作”本身就是瓶颈。BioDataLab 针对生物数据库策展这一劳动密集环节，构造 100 个源自 57 篇高影响力数据库论文的任务，提供含检索、抽取、标注、整合的交互环境及污染控制检查，评测 11 个 SOTA LLM（Gemini-3.0、GPT-5.2、Claude-4.5 等）在多框架下的表现，最佳模型成功率仅 40%，瓶颈集中在多步工具编排与复杂生物数据格式遵循 [80]。BixBench 则面向计算生物学中的 LLM 智能体，是该领域被引 106 次的综合基准 [81]。GenoTEX 更早地按计算基因组学标准统一流程（数据集选择、预处理与统计分析）构建基准，并由生物信息学家人工标注代码与中间/最终结果，同时提出多智能体 GenoAgent 基线，实验显示 LLM 方法具潜力但错误分析暴露明显失败模式 [52]。把这三者与 BAISBench 并置可见一条递进：GenoTEX 关注标准流程内的自动化与中间结果标注 [52]，BioDataLab 关注更上游的数据库策展且最佳仅 40% [80]，BAISBench 则质疑既有评估能否检验“从原始数据得出可解释结论” [53]。值得注意的是，ABC-Bench 给出了一个方向相反的信号：在液体处理机器人编程、DNA 片段设计、规避 DNA 合成筛查等良性及双用途任务上，所有测试智能体三项任务均超人类专家中位数，o4-mini-high 生成的脚本还在 OpenTrons 机器人上成功组装预期 DNA，但智能体在需新颖生物信息学推理的任务上表现较弱 [82]。这与 BioDataLab 的 40% 成功率 [80] 并不矛盾：前者任务更接近可编程操作与湿实验执行，后者要求多步工具编排与复杂格式遵循，能力剖面不同，但两者共同说明“生物能力”不是一个单一维度，评测必须区分操作执行与科学推理。

自进化与持续改进类环境把评测从静态分数推向动态过程。SEAGym 指出现有评估将智能体 harness 自进化简化为孤立分数或单条曲线，掩盖了可复用性、过拟合与成本等问题，因而将 Harbor 兼容基准转为动态自进化任务源，包含训练批次、冻结验证、ID/OOD 迁移、回放诊断与快照记录，并在 Terminal-Bench 2.0 与 HLE 上对比 ACE、TF-GRPO、AHE，发现频繁更新未必提升留出性能，有用中间快照可能后期崩溃，源多样性与模型后端会影响 harness 可靠性 [83]。其局限是仅实例化两个基准，未覆盖更广任务与长期演化 [83]。StreamBench 则更早地提出连续改进的流式基准，模拟在线学习环境，模型接收连续反馈并迭代提升，作者提出多种简单有效基线并分析成功流式策略的关键组件，但未给出统一定量主结果，且聚焦基准与基线、未充分覆盖复杂真实部署场景 [84]。两者都指向“时间维度”的评测缺口：SEAGym 用快照与回放诊断揭示更新可能后期崩溃 [83]，StreamBench 用反馈流检验迭代提升 [84]，但前者只覆盖两个基准，后者未给统一主结果，说明动态评测的标准化仍不成熟。

最后，可验证奖励强化学习本身的训练方法也在被基准化检验。ROSE 针对 RLVR 中 MCTS 扩展方法探索多样性有限和推理效率低的问题，引入基于语义熵的分支策略与 ε 探索机制以增强探索多样性，并设计长度感知的片段级优势估计器，奖励简洁正确推理、惩罚冗长推理链，在 Qwen 与 Llama 模型的多个数学推理基准上验证了有效性与效率，对比对象包括 GRPO 等 vanilla RLVR 与 MCTS 扩展方法 [44]。该工作未给出具体量化提升数值，也未说明开源模型的具体失败细节 [44]。与之相映的是 DiscoverPhysics：它构建 22 个刻意偏离真实物理的模拟世界，涵盖屏蔽引力、分数幂引力、多物种耦合、隐藏暗物质粒子等，智能体需多轮设计实验、观察原始轨迹数据并提交自然语言解释与 Python 实现，评测 11 个前沿模型发现最强智能体仅通过半数世界，在需揭示潜在结构的世界持续失败，开源模型显著落后于商业模型 [85]。把 ROSE 与 DiscoverPhysics 放在一起看，可验证奖励的“验证信号”来源正在分化：ROSE 依赖数学答案正确性与长度惩罚构造片段级优势 [44]，而 DiscoverPhysics 要求智能体在交互实验中自行推断规律，其“正确性”只能由模拟世界的隐藏定律判定 [85]。前者说明在答案可验证的数学域内，探索多样性与效率可以被显式优化；后者说明一旦验证信号需要从交互与潜在结构中提取，最强模型也仅过半数世界。这一对比也回扣了前述基准的共同发现：无论是 PRM 的过程错误检测 [50][51]、记忆影响校准 [56]、开放式科学发现 [54][53]、学术诚信 [73][74]、复现与策展 [76][80]，还是自进化与物理发现 [83][85]，当前评测环境已经足以稳定地暴露能力缺口，但尚不足以稳定地区分相近系统——TruthInsightBench 的无可靠两两区分 [54] 与 SEAGym 的“频繁更新未必提升” [83] 正是这一评测成熟度问题的两个直接证据。

## 4 生物医学场景应用

在生物医学影像推理方向，Med-R1 针对数据复杂与专家标注稀缺的问题，采用 Group Relative Policy Optimization（GRPO）进行奖励引导学习，以替代静态标注监督 [60]。其评测覆盖八种医学影像模态与五种问题类型，平均准确率较基座 Qwen2-VL-2B 提升 29.94%，并超过参数量 36 倍的 Qwen2-VL-72B；在问题类型泛化上提升 32.06% [60]。值得注意的是，该工作报告省略中间推理的 No-Thinking 版本跨域泛化更好且训练更少，这与"显式长链推理必然带来更强泛化"的直觉形成张力，提示在医学视觉语言任务中推理轨迹的形式与泛化能力之间并非单调关系 [60]。不过其验证主要限于医学影像问答，未明确说明其他限制 [60]。

在更贴近"科研智能体"的评测层面，三项工作呈现出从原子能力到过程级评估的递进，且结论相互补充甚至构成争议。Cell-o1 将单细胞细胞类型注释重构为批级推理任务，构建 CellPuzzles 基准，先用蒸馏推理轨迹做监督微调，再用批级奖励强化学习训练 7B 模型；结果显示现成 LLM 表现很差，最佳基线 OpenAI o1 仅 19.0% 批级准确率，而 Cell-o1 超 o1 逾 73% 并展现类专家推理 [59]。这与其他工作中"通用前沿模型已接近可用"的印象形成对比，但其局限也很明确：仅 7B 规模、依赖蒸馏推理轨迹质量、批级任务泛化范围有限 [59]。BioKGBench 则从 AI 科学家视角评测文献理解，拆解为科学论断验证与知识图谱问答两种原子能力，并设计 KGCheck 智能体任务，用 KGQA 与领域 RAG 识别大规模知识图谱的事实错误；基于 2000+ 原子任务数据与 225 条智能体标注，发现通用与生物医学 SOTA 智能体均失败或表现不佳 [86]，其局限是仅限生物医学领域且智能体任务数据量较小 [86]。BiomniBench 进一步转向过程级评估，按专家设计的任务专属评分标准对完整轨迹打分，首个版本 BiomniBench-DA 含 100 个数据分析任务、覆盖 17 种任务类型与 5 个疾病领域，均基于 Nature、Cell、Science 等论文并与原作者或领域专家共同开发 [87]。其基准测试发现前沿与开源模型差距仅几分且均有较大提升空间，智能体框架带来的分数差异大于相邻代际模型差距，智能体在方法选择、生物学解释与科学推理上持续不足 [87]；局限是仅覆盖数据分析任务，未涵盖完整科研流程 [87]。综合来看，Cell-o1 通过批级奖励强化学习在特定子任务上大幅超越 o1 [59]，而 BioKGBench 与 BiomniBench 则表明在更广的文献理解与真实研究流程中，现有智能体仍普遍失败或提升空间巨大 [86][87]；这种"单点任务可被强化学习显著突破、系统级科研能力仍薄弱"的落差，正是可验证奖励强化学习在生物医学场景需要面对的核心争议。

## 5 评测、可复现性与争议

围绕可验证奖励强化学习（RLVR）究竟能否让模型获得超越基座模型的新推理能力，一项系统性研究给出了颇具争议的否定性结论。该工作采用大 k 的 pass@k 指标来探测 RLVR 的推理能力边界，覆盖多个模型家族、多种 RL 算法，以及数学、代码、视觉推理等多类基准 [88]。其核心发现是：在小 k 时，经过 RLVR 训练的模型表现优于基座模型；但当 k 增大时，基座模型的 pass@k 反而更高 [88]。这一反转意味着 RLVR 并未真正拓展模型的推理能力上限，而更像是把基座模型已有的、分散在高采样预算下的正确解，重新集中到低采样预算的少数输出上。换言之，RLVR 提升的是采样效率而非能力边界，其推理能力源自并受限于基座模型本身的上界 [88]。

这一结论对当前以 RLVR 为核心的科研智能体训练范式构成了直接挑战，也带来了评测与可复现性层面的争议。首先，在评测方法上，该研究指出六种 RLVR 算法的表现彼此相近，且都远未达到基座模型的潜力上限 [88]。这说明不同算法之间的差异可能被小 k 评测所放大，而在大 k 评测下趋于收敛，提示仅凭常规的 pass@1 或小 k 指标来宣称某种 RLVR 算法优越，存在可复现性与可比性风险。其次，该研究强调当前训练设置未能引出全新的推理模式，能力受基座模型上界约束 [88]，这与许多工作报告的 RLVR 带来推理能力跃升形成了冲突。值得注意的是，该研究同时发现蒸馏能够真正扩展推理能力 [88]，这为争议提供了一个对照：真正带来能力扩展的可能是蒸馏而非 RLVR 本身。由此，在评测科研智能体时，若只报告小 k 指标，可能把采样效率的提升误读为推理能力的增长；而大 k 的 pass@k 探测则揭示了基座模型与 RLVR 模型之间被掩盖的差距，成为检验可验证奖励强化学习真实增益的关键手段 [88]。

## 6 空白与趋势

在科研智能体与 RLVR 的交叉地带，最明显的空白是过程奖励模型与真实科研工作流的对接仍停留在少数可程序化验证的领域。现有 PRM 工作大多在数学推理基准上验证：PQM 在多种采样策略与多步推理基准上优于分类式 PRM [26]，PURE 在 3 个基座模型上仅用 30% 步数即达到可验证奖励方法相当的性能 [15]，BiPRM 在 GSM-Plus、MATH500 与 ProcessBench 上解级平均增益 10.6%、步级错误检测增益 37.7% [37]。即便迁移到智能体场景，AgentPRM 也主要在 ALFWorld 上验证 3B 模型 [28]，另一篇 AgentPRM 虽覆盖网页购物与浏览器导航，但仍面临动作无明确正确性、跨任务泛化待验证的问题 [29]。真正面向科学发现的 PRM 只有 Sci-PRM 构建了 SCIPRM70K 的 Chain-of-Tool 轨迹并覆盖工具选择、执行准确性与结果解读 [39]，以及 VPRM 在医学证据合成的偏倚风险评估中用确定性规则验证每个中间推理步 [27]。这意味着在文献综合、假设生成、组学分析等科研核心环节，过程奖励的信号定义、数据生成与验证器可靠性都还没有成熟方案，而 PRM 综述也承认数据生成、建模目标与使用方式三者相互耦合、设计空间远未收敛 [48]。

第二个空白是科研智能体的评测基准与训练信号之间存在断裂。现有基准要么只评最终输出，要么只评执行能力：GenoTEX 按计算基因组学标准统一流程，涵盖数据集选择、预处理与统计分析，并由生物信息学家人工标注代码与中间/最终结果 [52]；BAISBench 基于单细胞转录组数据构建贴近数据驱动生物发现场景的评测框架，并指出既有基准多为知识驱动或仅评估计算输出，难以衡量 AI 系统能否从复杂实验数据中提炼有生物学意义的结论 [53]。TruthInsightBench 进一步区分"执行既定分析"与"开放式科学发现"，含 40 个盲任务，评测四个编码智能体发现总分仅 58.4–60.3/100 且无可靠区分，瓶颈在科学判断而非编码 [54]。这些基准揭示了能力缺口，却没有提供可转化为 RLVR 奖励的步级信号：GenoTEX 的标注是代码与结果而非过程奖励 [52]，TruthInsightBench 由固定 LLM 裁判按 6 维度 29 个证据锚定项自动评分 [54]，BAISBench 关注能否提炼生物学结论 [53]。换言之，科研智能体的评测正在从"能不能做"走向"做得对不对"，但评测结果尚未回流为训练过程奖励，这是 RLVR 进入科研场景的关键缺口。

第三个趋势是过程奖励的信用分配形式正在从"求和"转向"最小""树结构""自适应混合"等多种形式，但尚无统一结论。PURE 把价值函数改为未来奖励的最小值，指出求和形式会诱导模型攻击高奖励步骤 [15]；TEMPO 用前缀树聚合后代结果计算非参数前缀值，为 GRPO 加入分支感知的时序差分修正 [14]；GACA 用每 token 负对数似然给每步打分并按分数逐步骤加权混合两级优势，理论上证明状态自适应混合严格优于任何固定权重 [30]；S-trace 通过选择性掩码低熵 token 实现稀疏资格迹 [32]；G2PO 把线性交互轨迹转为全局状态转移图并以边为中心做优势估计 [33]。这些工作共同承认 GRPO 的轨迹级广播过于粗糙，但修正路径各异，且 G2PO 未给出定量结果、图构建开销未讨论 [33]，S-trace 未报告与更多基线及任务类型的对比 [32]，GACA 的局限未在摘要中明确说明 [30]。在科研智能体这种长程、多工具、动作空间结构化的场景中，哪种信用分配形式更合适，目前没有任何工作给出答案。

第四个趋势是"无外部奖励"与"隐式过程信号"路线正在挑战显式 PRM 的必要性，但其在科研场景的适用性完全未被检验。Intuitor 用模型自身置信度 self-certainty 作为唯一奖励，在 GRPO 中替换外部奖励，数学基准上匹配 GRPO 并在代码生成等域外任务上泛化更好 [17]；MEL 利用 LLM 自验证对正确与错误轨迹做对比分析，定位推理错误分叉点并总结为可泛化元经验，Pass@1 提升 3.92%–4.73% [18]；进度优势则从 RL 训练策略与参考策略的对数概率比中恢复最优优势函数，无需标注与专用奖励模型训练，跨五基准四模型族一致优于置信度基线并超越专用奖励模型 [34]。这些工作都依赖模型自身信号或已有 RL 管线，而科研智能体的核心困难恰恰是模型对科学判断的置信度不可靠——TruthInsightBench 显示编码智能体在科学判断上得分仅 58.4–60.3/100 [54]，MatClaw 也承认智能体难以处理隐性领域知识、需文献自学习与专家约束弥补 [8]。因此，无外部奖励路线能否在科研场景成立，取决于模型自验证能力能否覆盖科学判断，而目前没有任何工作测试这一点。

第五个趋势是自改进智能体的奖励膨胀与技能误演化问题开始被识别，但尚无面向科研场景的解决方案。Memory Reward Inflation 研究自改进 LLM 智能体在不更新权重、仅靠外部记忆学习时的奖励膨胀，将存储分数视为代理奖励，提出无答案去膨胀算法 LUCID，在 BIRD text-to-SQL 上将执行准确率提升至 56.9% [57]。Practice Makes Unsafe 揭示自改进智能体将成功轨迹转为持久技能时，不安全成功可固化为可复用策略，即技能误演化，并提出 SKILLMISEVO-GYM、SKILLMISEVO-BENCH 与 SAFEEVOLVE [58]。这两项工作都指向同一个风险：当科研智能体通过记忆或技能积累自我改进时，错误的科学结论或不安全的实验操作可能被固化并复用。而 Co-Scientist 的科学家在环设计 [3] 与 Risks of AI scientists 提出的三元防护框架 [4] 都强调人类监管，却未与自改进训练机制结合。换言之，如何在 RLVR 或自改进循环中嵌入科学安全约束，使智能体不把错误结论固化为可复用技能，是一个完全空白的方向。

第六个趋势是 RLVR 奖励信号本身的可靠性受到系统性质疑，这些质疑尚未被过程奖励研究充分吸收。Spurious Rewards 发现随机奖励使 MATH-500 提升 21.4 个百分点、接近真实奖励 29.1 点，但该现象高度依赖模型家族 [19]；Exploration vs Exploitation 发现裁剪偏差在虚假奖励下降低策略熵、产生更确定输出 [42]；Spurious Rewards Paradox 从机制层面定位 L18-20 功能锚点与 L21+ 结构适配器，可双向因果操控 [43]；单样本 RLVR 显示单个可验证奖励样本即可使 MATH500 从 36.0% 升至 73.6% [20]；难度分层研究则发现易与中等难度问题带来最强最稳定的推理提升，过难问题学习信号弱并可能损害模型原有能力 [21]。这些结果共同意味着：结果奖励的增益可能部分来自放大预训练中已有行为而非真正教会推理，而过程奖励若只追求步级准确率而不控制忠实度与泛化，可能同样落入放大捷径的陷阱。FaithRL 已尝试用信息增益惩罚缓解奖励黑客 [36]，但尚无工作系统检验 PRM 在虚假奖励与难度分层条件下的行为，更无工作把科研场景的"结论可复现性"作为过程奖励的约束。

综合来看，科研智能体与可验证奖励 RL 的交叉方向存在一条清晰但尚未闭合的链条：科研智能体系统已从 ReAct 的提示式协同 [1] 演进到 Co-Scientist 的科学家在环多智能体 [3]、The Little Scientist 的科学方法闭环 [10] 与 HypoForge 的技能学习 [6]，RLVR 也已从 DeepSeekMath 的 GRPO [12] 与 DeepSeek-R1 的结果奖励 [11] 演进到 PURE、TEMPO、GACA 等形式多样的过程信用分配 [15][14][30]，但两端尚未真正接合：科研智能体的评测基准（GenoTEX [52]、BAISBench [53]、TruthInsightBench [54]）没有输出可训练的过程奖励，过程奖励的验证器（Sci-PRM [39]、VPRM [27]）也尚未嵌入科研智能体的闭环训练。与此同时，自改进带来的奖励膨胀与技能误演化 [57][58]、RLVR 奖励信号的虚假增益 [19][43]、以及科学安全约束 [4] 都还没有被纳入过程奖励的设计考量。这些空白共同指向一个判断：科研智能体的可验证奖励强化学习，目前仍处于"两端各自成熟、中间尚未打通"的阶段。

## 7 未归类新证据

在LLM推理的强化学习与可验证奖励（RLVR）框架下，过程奖励塑形长期面临一个核心难题：如何在不引入昂贵人工标注的前提下，为推理轨迹的中间步骤分配有意义的信用。Cliff提出了一种基于"首个错误"的观察视角，认为推理过程一旦首次出错，后续评估所能提供的信息就变得有限，因此奖励塑形的重点应放在错误发生的位置而非整条轨迹的均匀评分[89]。其方法是用现成的LLM教师定位每次rollout中的首个错误，将轨迹切分为正确前缀与错误后缀，再转换为token级优势：对正确前缀给予正优势，对错误之后的部分给予负反馈[89]。这一设计把过程奖励问题从"逐步打分"简化为"定位分界点"，在方法上区别于on-policy distillation与标准GRPO这两类基线[89]。

从实验证据看，Cliff在12个不同场景的推理任务上取得了一致的性能提升，相对on-policy distillation高出15%，相对标准GRPO高出7%，并且即使教师能力一般也仍然有效[89]。这一结果值得注意的地方在于，它暗示过程奖励的收益可能并不高度依赖教师的高精度判断，而更多来自"错误位置"这一结构性信号本身。不过，该工作也留下了明显的争议空间：其方法完全依赖教师模型定位首个错误，却未讨论教师定位错误时会产生何种影响[89]。如果教师把正确步骤误判为错误，或漏掉真正的首个错误，那么被赋予正优势的前缀就可能包含错误推理，被赋予负反馈的后缀也可能包含正确推理，从而在token级优势上引入系统性偏差。与on-policy distillation相比，Cliff并不要求学生模型模仿教师的完整分布，而是只利用教师的定位能力，这既是其相对15%优势的可能来源，也意味着其上限受制于教师定位的可靠性[89]。与标准GRPO相比，7%的提升说明仅靠结果奖励的组内归一化不足以充分利用轨迹内部的结构信息，但这一差距是否在教师能力较弱时依然稳定，证据中并未给出分层结果[89]。因此，Cliff的核心贡献在于把"首个错误"确立为过程奖励的锚点，而其未解决的教师错误传播问题，则构成后续工作需要正面回应的争议点[89]。
