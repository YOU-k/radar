# Registry 月度刷新建议 — 2026-10

## databases.md

- [新增] MIMIC-IV-ECG (Parquet 镜像) — MIMIC-IV 心电数据的 HF 镜像，便于 ML 直接加载 — 心血管 ECG 建模可用资源
- [新增] OmniVCBench — 虚拟细胞多模态推理基准，6077 条可溯源 QA — benchmark，可直接用于评估
- [新增] 单细胞共调控 ground truth 目录 — 35 样本预处理单细胞共调控基准数据集 — 方法评估用
- [新增] 人脑发育海马单细胞图谱 + AD 类器官基准 — 寿命跨度海马单细胞图谱，含家族性 AD 脑类器官对照 — 类器官组学项目直接可用
- [新增] 小鼠比目鱼肌高分辨空转图谱 — 健康/去神经单细胞与亚细胞异质性 — 公开空转数据
- [新增] 儿童癌症统一处理可变剪接图谱 — transcriptome-wide 统一处理剪接谱 — 公开数据可复用（非衰老方向）
- [新增] Agent Error Dataset — 5 万条智能体错误诊断对 — agent 后训练资源
- [新增] jepa-anything (Gen-Verse) — 跨域预测世界模型公开资源 — 方法储备

- [新增] NexuST — 空间转录组分层基础模型，4570 万细胞预训练 — ⭐⭐，可直接用
- [新增] LucaCell — 序列中心跨物种单细胞基础模型，8500 万细胞预训练 — ⭐⭐，可迁移
- [新增] Speciesformer — 跨物种保守细胞状态生成式虚拟细胞模型 — ⭐⭐，跨物种迁移相关
- [新增] DePass — 图学习配对单细胞与空间多组学整合 — ⭐⭐，工具可复用
- [新增] ResolVI — 空间转录组噪声与偏差校正 — ⭐⭐，可直接用
- [新增] spaGFM — 空间转录组可扩展图基础模型 — ⭐⭐
- [新增] ProteinJEPA — JEPA 用于蛋白语言模型预训练，19 任务验证 — ⭐⭐，代码可期
- [新增] PRAXIS-VirtualCell — 可编程可信虚拟细胞 agent 框架 — ⭐⭐，若开源可直接用

- [新增] P2P — 跨视图群体去噪的非配对单细胞扰动响应预测 — ⭐⭐，虚拟细胞核心任务
