在合作网络里主要提供**算法支持**，需要在多个领域保持活跃。

## 新增关注点（2026-09）：人群健康与多组学 AI

大规模队列 / 生物样本库（UK Biobank、All of Us、FinnGen、丹麦国家登记）上的 AI 建模，
尤其是：
- **生成式疾病轨迹模型**：如 Delphi（Nature 2025，Transformer 学 40 万 UKB + 190 万丹麦人 EHR，
  同时预测 1000+ 疾病风险、生成 20 年合成健康轨迹）、ALADYNOULLI（Nature 2026，贝叶斯生成模型
  把 EHR 与胚系遗传结合，348 病 × 3 队列找到 21 个可复现特征谱、诊断类别内的生物学亚型）
- **人群多组学 + 遗传整合**：血浆蛋白组 / 代谢组 / 甲基化在大队列上的建模，pQTL、多组学疾病预测、
  组学衰老时钟在人群健康上的落地
- **医学 / EHR 基础模型**、纵向健康建模、多病共病结构、队列间可复现性

这类工作与衰老建模高度互补（同样是「多模态 + 纵向 + 跨队列」），发在 CNS 及子刊
（Nature Medicine / Nature Genetics / Cell Genomics）的应打 8-10 分。

## 新增关注点（2026-09）：心血管疾病队列与临床转化

之后要处理 **ChinaHEART 队列**（中国大规模心血管病筛查/早筛人群队列，含问卷、体检、心电、
血生化、随访结局，后续可能有血浆组学/遗传数据）。关心：
- **心血管病风险预测与疾病轨迹**：大队列上的深度/生成式模型，相对 PCE / SCORE2 / China-PAR 等传统评分的增益，
  跨人群（尤其中国/东亚人群）的校准与迁移
- **心血管多组学**：血浆蛋白组（Olink/SomaScan）、代谢组、脂质组、多基因风险在冠心病/心衰/房颤/卒中上的预测与机制，
  孟德尔随机化找靶点
- **临床可落地的模式**：ECG / 影像 AI 与组学/EHR 联合、筛查—干预闭环、实用性随机试验、真实世界证据
- 中国人群的大队列工作（China Kadoorie Biobank、ChinaHEART、中国慢病前瞻队列）一律优先

## 新增关注点（2026-09）：类器官与模式生物的虚拟响应建模

- 类器官（含心脏/血管类器官、器官芯片）上的扰动实验 + 单细胞/多组学读出，预测药物/遗传扰动响应
- 模式生物（小鼠、斑马鱼、线虫、果蝇）上的扰动响应模型、跨物种迁移到人（如跨物种基础模型、同源映射）
- 与虚拟细胞方向的区别：关注的是组织/器官/个体层面的响应，而非细胞系

## 打高分的信号（7-10 分）

- 可以直接拿来用的：新发布的**数据集 / 数据库**（尤其多模态、衰老、单细胞、空转、蛋白组、甲基化）
- 可以直接部署或微调的**模型**（单细胞 foundation model、蛋白语言模型、aging clock、多模态整合方法）
- 多模态衰老建模的**方法学**（modality alignment、缺失模态处理、跨队列校正、增量学习/持续学习）
- 能进合作项目设计的思路：类器官 + 组学、扰动响应建模、cell painting + ML
- ML 底层新范式：JEPA / 世界模型 / 自监督表征 / 新的架构 idea（有代码更好）
- LLM agent 实质进展：self-improving / RSI / RLVR / fact-aware RL、agentic 科研工作流
- 大规模队列 / 生物样本库 / EHR 的生成式建模与疾病轨迹预测，人群多组学 + 遗传整合（见上）
- 心血管病大队列的 AI / 多组学风险预测与机制（CNS、Circulation、EHJ、JACC、Nature Cardiovascular Research
  级别的默认 ≥7 分），中国人群心血管队列工作
- 类器官 / 器官芯片 / 模式生物上的扰动响应建模与跨物种迁移
- 衰老生物学的 AI 基准 / 基础模型（如 LongevityBench 这类 Cell/Nature 级别的 benchmark）
- **CNS 及主要子刊**上凡与上述方向相关的原创论文，默认 ≥7 分：这些是必须知道的"大文章"，
  不因摘要没提数据可获取性就压分

## 打低分的信号（0-3 分）

- 营销稿、融资新闻、与上述方向无关的应用
- 我已经有成熟方案的老问题（如普通 bulk 差异表达流程）
